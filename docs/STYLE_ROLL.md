# Roll 串：抽取与保存

Roll 串用于从现有画师库抽取组合、有限出图并直接保存喜欢的配方。产品边界见[产品宪法](../VIBER_INTENT.md)，当前操作见 [README](../README.md)，维护约定见[产品决策记录](./PRODUCT_DECISIONS.md)。

## 当前工作流

| 环节 | 本项目行为 |
| --- | --- |
| 一轮出图 | 设置每串画师数与本轮张数，一次发起有限任务、逐张生成并保存；付费先确认整轮总费用。出图后留在图库，直接挑选保存。顶栏 Roll 按钮旁显示「张数 · 人数 · 预计费用」，完整设置按「仅本轮」与「记录默认」分组 |
| 画师来源 | 使用现有画师库的完整 Tag 词库，无需另建名单或预先收藏；缺样张的画师也可抽取。搜索支持画师 Tag、中文名与编号；画师库可多选后「在 Roll 中固定」，Roll 详情可带画师名跳回画师库 |
| 从风格串开始 | 记录管理或空记录页选择一条现有风格串，新建独立 Roll 记录。公共提示词以 `{style}` 替换原画师段，负面、模型、尺寸、参数、结构化角色与固定 Seed 保留；画师作为固定画师组，默认锁定原权重，也可关闭「保留原权重」直接重 roll。画师识别支持 `artist:`／`Artists:` 前缀和词库中的裸画师名；旧串权重按 0.1 取整，超 32 位 Seed 取低 32 位，缺失模型用默认模型，语法异常 Tag 跳过并提示。超过 64 位或编辑模型仍明确拒绝，不修改源风格串 |
| 创作控制 | Roll 按钮旁「本轮设置」直接调整画师数量、张数与最低／最高权重；默认 0.7～1.4，可在 0.1～3.0 内按 0.1 调整，相同上下限即固定权重。开始新一轮或保存配置后随记录保存，完整配置同步；新范围作用于后续抽取，旧配方不改。锁定必选画师及指定权重，排除暂不使用的画师，过滤重复组合 |
| 公共配置 | 每条记录保存完整提示词、角色、模型、尺寸、参数和固定 Seed。有候选后公共配置冻结，变更条件另建画风记录 |
| 抽取方式 | 默认全随机；可固定一组画师只随机权重（弹层：随机选择、重新选择、逐位替换、逐位踢出与再加一位、从画师库添加、手动输入），或统一权重只抽画师。固定权重等价于把最低／最高权重设为同一值，不另存数值。固定画师必须包含可用的锁定画师。也可只从有样张的画师抽取（图包或自建样张），显式锁定／指定的画师仍保留。从风格串带入的固定画师保留原权重，可在「本轮设置」重 roll；逐位替换会同步更新记录，其他画师权重不变 |
| 全局屏蔽 | 屏蔽名单跨记录生效，被屏蔽画师不再进入随机池；可在「本轮设置」或固定画师弹层维护、可随时取消。固定画师被屏蔽时抽取会明确报错 |
| 轮次记录 | 每轮保存当时的抽取条件（人数、权重范围、模式、固定画师），可在筛选面板回看并「沿用这轮条件」；快照随轮次一起不可改写。卡片编号旁标出所属轮次 |
| 浏览与管理 | 复用工坊工具栏、卡片、图片布局和原位多选；按画师 Tag、中文名、编号、状态和轮次筛选，按新旧排序。单项／批量保存、丢弃和恢复；回收站中的已归档候选可确认后永久清理，原图与已保存风格串保留。记录支持重命名、新建与可恢复收起；每条记录最多 240 个候选，界面显示剩余容量 |
| 继续未完成任务 | 「补齐剩余」只提交当前未关闭普通批次的未生成原配方；其他轮次缺图可选中后主动生成。关闭连续生成时明确显示本次只生成 1 张 |
| 资产闭环 | 图片进入正常历史，共用收藏与图片分享；满意候选保存为完整风格串（名称带记录、序号与主权重画师），或带完整配置送往实验室。未出图的候选不能保存 |

用户已明确取消画风对比、两两投票、Elo 排名、进化评选、自动权重测试、换 Seed 验证和手动逐项调权界面；相关界面、数据字段和执行算法已移除，不保留可选入口。保留「从已有风格串继续探索」：可保留原权重、重 roll 权重或逐位替换画师后继续出图，但不提供排名、评分、两两比较或自动进化。普通 Roll 不安排任何评价任务，也不以评分或评图模型决定抽取。界面统一使用「画风记录」「候选」「选择固定画师」「随机选择」「重新选择」「再加一位」，不再使用「实验」「组队」「抽卡」「补抽」等旧称呼。

## 数据与恢复

- 资料沿用 `/api/style-roll` 和既有私人 `settings`，按用户及记录 ID 隔离；不新增表、迁移文件或更改存储定位键。原有工坊备份覆盖记录与原图。
- 全局屏蔽名单单独保存在 `style_roll_blocklist_v1:<用户>`，与实验记录分开，不随记录删除或导出。
- 画师目录沿用完整分片读取与缓存，不受页面加载数量或手填条目上限影响。记录只保存锁定／排除等覆盖项与实际候选，不复制整份词库。目录失败明确提示并可重试，已有候选仍可查看和生成原配方。
- 旧 Roll 记录不再保留投票、冠军、旧进阶轮次、验证副本或早期候选字段的兼容处理：按当前结构严格校验，坏存档报错而不是以空记录覆盖。用户已清空本地 Roll 记录及其生成的图片，不保留迁移或恢复逻辑。
- 日常丢弃候选与记录使用可恢复状态收起；回收站中的已归档候选可由用户确认后永久清理，只移除候选与轮次引用，不删除历史原图或已另存风格串。保存携带版本号，冲突明确提示重新加载，不静默覆盖。
- 生成复用既有有限多配方后台任务，每项保留提示词、Seed 与历史来源；沿用同 Key 互斥、间隔、暂停、后台保存和费用上涨确认。失败／取消不重新抽串或自动重试，已有成果和原配方保留。
- 历史按记录来源 ID 与候选模块 ID 关联。优先使用首次匹配的原图；候选使用记录公共 Seed，固定 Seed 不受实验室的强制随机偏好影响。历史读取失败不当作尚未生成，避免重复消费。
- 切页不取消已提交任务；关闭／刷新行为遵循已有任务服务，不建立重启自动续跑任务。切 Key 不授权旧任务，后台暂停、费用补充授权与取消均由用户主动操作。
- 「存为风格串」保存实际生成参数并持久保存独立封面，后续编辑不反写记录。记录不提供独立 JSON 导出；完整备份使用工坊备份。

## 参考来源

一轮出图和画风库的创作思路参考 [sdnwls/nai-style-lab](https://github.com/sdnwls/nai-style-lab)，结合工坊既有功能独立实现，未复制其代码、原图或画师数据集。该项目以遗传式探索和两两对比为核心，本项目只取「从词库抽组合、有限出图、挑选保存」的体验，其对比、排名与进阶流程均未保留。

## 维护入口

- `services/styleRoll.ts`：资料校验、画师规则、三种抽取方式与全局屏蔽校验。
- `services/styleRollSeed.ts`：从风格串提取模板、固定画师与原权重，以及替换／重 roll 权重的覆盖项同步。
- `services/styleRollWorkflow.ts`：普通有限批次与轮次条件快照。
- `services/styleRollApi.ts`、`styleRollGeneration.ts`：记录、屏蔽名单、历史及既有后台生成的接缝。
- `services/styleRollWorkspace.ts`：图库范围、搜索排序与补图资格。
- `components/StyleRollPage.tsx`、`components/roll/`：图库、详情、记录管理、原位多选、配置、从风格串开始与固定画师弹层。
- `worker/routes/styleRollRoutes.ts`：私人资料验证与并发版本检查。
- `tests/services/styleRoll*.test.ts`、`tests/components/StyleRoll*.test.tsx`、`tests/worker/styleRollRoutes.test.ts`：当前有限出图、抽取规则及存储边界的合成资料回归；导航和多语另有对应集成覆盖。

工程测试不消费真实额度，不读取私人资料作为夹具。
