# Roll 串：抽取与保存

Roll 串用于从现有画师库抽取组合、有限出图并直接保存喜欢的配方。产品边界见[产品宪法](../VIBER_INTENT.md)，当前操作见 [README](../README.md)，维护约定见[产品决策记录](./PRODUCT_DECISIONS.md)。

## 当前工作流

| 环节 | 本项目行为 |
| --- | --- |
| 一轮出图 | 设置每串画师人数范围与本轮张数，一次发起有限任务、逐张生成并保存；付费先确认整轮总费用。出图后留在图库，直接挑选保存。顶栏 Roll 按钮旁显示「张数 · 人数 · 预计费用」，完整设置按「仅本轮」与「记录默认」分组 |
| 画师来源 | 使用现有画师库的完整 Tag 词库，无需另建名单或预先收藏；缺样张的画师也可抽取。搜索支持画师 Tag、中文名与编号；画师库可多选后「在 Roll 中固定」，Roll 详情可带画师名跳回画师库 |
| 画师样张 | 管理弹窗与画师库共用封面及图片显示偏好，瀑布流按真实预览比例贴合图片；右侧为偏好、生成、版本，左侧为屏蔽和单页删除，多图可左右翻页。辅助操作按悬停、键盘聚焦或触屏长按显露，点按图片仍锁定画师；样张配置、费用确认与后台归档共用画师库链路 |
| 创作控制 | 每串人数范围包含固定项，默认 4～4 位；上下限相同即固定人数；本轮张数有限。权重默认 0.7～1.4，在 0.1～3.0 内按 0.1 调整，上下限相同即统一权重。人数范围、固定 Tag、权重、偏好设置与样张过滤在开始一轮或保存配置后随记录保存，只影响后续抽取 |
| 公共配置 | 普通新建记录使用推荐公共正负词与默认参数，不隐式继承当前记录；推荐质量、细节增强、皮肤材质、景深、光照、年份、背景与 `{style}` 放在公共栏，独立角色栏（`characterPrompt`）只保留人物和姿态描述，可分别编辑并按记录保存。所有原词保留，生成时仍按模板位置合入全局正向。新版分栏仅用于新建或主动套用推荐，已有记录与自定义预设原样保留；打开旧默认记录不自动升级模板。另可维护多套命名的自定义质量预设，包含完整公共正／负词、`characterPrompt` 和 `NAIParams`（模型、尺寸、步数、CFG、采样器、Seed、质量／UC、结构角色等）；推荐预设只读。预设不包含抽取人数、画师、权重与候选。套用只复制到当前草稿，保存 Roll 配置后生效；预设另存、更新或删除不回写已保存记录或作品、不触发生图。已有候选仍冻结，当前配置可另存为新预设；不自动创建自定义默认项，不提供导入／导出 |
| 候选续 Roll | 从当前候选继续 Roll 时固定其画师 Tag，并明确沿用所属记录的公共配置与 Seed |
| 随机流程 | 在可满足锁定与偏好保底的人数范围内逐串随机人数，再补齐剩余 Tag，为全部 Tag 独立随机权重。池不足以满足上限时停止，不偷偷缩小范围；样张过滤只限制随机补位，明确固定的 Tag 仍保留 |
| 画师管理 | 图片占主区，顶栏搜索和分类筛选，偏好参数放在按钮旁的小弹出卡片，打开不挤动图片；卡片复用图库动效，图片和名称复用角色卡布局与全局信息栏偏好。独立弹窗展示样张或空封面；点封面锁定 Tag，与画师库共用 Tag 状态，左上屏蔽、右上爱心表示偏好。屏蔽解除锁定但保留卡片，跨记录生效；样张过滤由用户勾选。没有共用悬浮分享菜单，可搜索、筛选固定／偏好／屏蔽，以及已收录／未收录、已生成／未生成；按热度、名称、收录串数与生成图片数升降序排列，卡片显示当前收录与生成数，浏览条件不改变抽取概率；保留手动粘贴入口，也可从本地最新风格串（含无类型旧记录）选择封面／名称、多选提取正向中实际启用的画师 Tag（含启用模块、主体与角色），默认勾选可加入项并可全选、取消全选或逐项调整。提取去重，已有固定项保留，屏蔽／排除项不可绕过；超人数上限只提示调整，不自动删除 Tag 或改变人数。确认仅合并固定 Tag，不带源权重、公共提示词、模型、Seed、参考，不修改原串或生图；取消不改列表 |
| 偏好抽取 | 爱心与收藏库画师来源同步，无样张也可收藏 Tag。倍率默认 1，用滑条拖动或数字框精确输入，常用 1～100 倍、步进 0.1；更大值扩展滑条上限，不截断旧值。保底默认 0，由用户修改；先补足偏好保底，再按相对倍率抽取。已锁定偏好计入保底，过滤后不足或超出人数上限就停止，不随机补齐；倍率与提示词权重分开 |
| 轮次记录 | 新快照保存人数范围、权重范围、固定 Tag、偏好倍率／保底和样张过滤，不写模式；回看与沿用条件不自动出图，当前偏好名单跟随收藏。旧快照不可改写 |
| 浏览与管理 | 复用工坊工具栏、卡片、图片布局和原位多选；按画师 Tag、中文名、编号、状态和轮次筛选，按新旧排序。「已出图但未保存」只含有图片且未关联风格串的候选。详情上一张／下一张遵循当前筛选、轮次与排序，首尾禁用对应方向；候选保存后若离开当前结果，接续显示下一项、没有下一项则显示前一项，结果为空时收起详情。单项／批量保存、丢弃和恢复；批量逐项继续并显示成功数量、失败编号与原因，重试只处理失败与未处理项且不重复创建成功项。保存关联遇到并发版本变化时先回读最新记录；无法确认时暂停后续项目并保留未处理项，可重试待保存项。回收站中的已归档候选可确认后永久清理，原图与已保存风格串保留。记录支持重命名、新建与可恢复收起；每条记录最多 240 个候选，界面显示剩余容量 |
| 继续未完成任务 | 「补齐剩余」只提交当前未关闭普通批次的未生成原配方；其他轮次缺图可选中后主动生成。关闭连续生成时明确显示本次只生成 1 张 |
| 资产闭环 | 图片进入正常历史，共用收藏与图片分享；满意候选保存为完整风格串（名称带记录、序号与主权重画师），或带完整配置送往实验室。未出图的候选不能保存 |

用户已明确取消画风对比、投票排名、进化评选、自动权重测试、换 Seed 验证和手动逐项调权界面，不保留可选入口。Roll 只有一个随机流程，固定画师与权重范围是可选约束，不再拆模式或开随机抽卡页面；画师管理使用独立样张弹窗，不产生评价任务。

## 数据与恢复

- Roll 记录沿用 `/api/style-roll` 与私人 `settings`，按用户及记录 ID 隔离，不新增表或改变存储定位键。质量预设使用 `style_roll_preset_v1`，同样按用户和记录 ID 保存，修订冲突拒绝覆盖；工坊完整备份覆盖记录、预设与原图。无需迁移或修改 binding。
- 现存三模式记录仍可读取：旧固定模式及锁定覆盖项作为固定 Tag，旧人数范围继续保留；仅旧固定组超出人数时补足上下限；开始新一轮或主动保存后使用统一结构，不批量改写存档。既有记录、候选、轮次快照与图片保持原样。该兼容只用于仍在使用的三模式记录，不恢复此前明确废弃的对比资料。
- 全局屏蔽名单单独保存在 `style_roll_blocklist_v1:<用户>`，与实验记录分开，不随记录删除或导出。
- 画师目录沿用完整分片读取与缓存，不受页面加载数量或手填条目上限影响。记录只保存锁定／排除等覆盖项与实际候选，不复制整份词库。目录失败明确提示并可重试，已有候选仍可查看和生成原配方。
- 旧 Roll 对比资料不再兼容投票、冠军、旧进阶轮次、验证副本或早期候选字段：按当前结构严格校验，坏存档报错而不是以空记录覆盖。已废弃的对比资料按用户决定清空；现有 Roll 记录、候选与图片保持原样，不批量回写或迁移。
- 日常丢弃候选与记录使用可恢复状态收起；回收站中的已归档候选可由用户确认后永久清理，只移除候选与轮次引用，不删除历史原图或已另存风格串。保存携带版本号，冲突明确提示重新加载，不静默覆盖。
- 生成复用既有有限多配方后台任务，每项保留提示词、Seed 与历史来源；沿用同 Key 互斥、间隔、暂停、后台保存和费用上涨确认。失败／取消不重新抽串或自动重试，已有成果和原配方保留。
- 历史按记录来源 ID 与候选模块 ID 关联。优先使用首次匹配的原图；候选使用记录公共 Seed，固定 Seed 不受实验室的强制随机偏好影响。历史读取失败不当作尚未生成，避免重复消费。
- 切页不取消已提交任务；关闭／刷新行为遵循已有任务服务，不建立重启自动续跑任务。切 Key 不授权旧任务，后台暂停、费用补充授权与取消均由用户主动操作。
- 「存为风格串」保存实际生成参数并持久保存独立封面，后续编辑不反写记录。记录不提供独立 JSON 导出；完整备份使用工坊备份。

## 参考来源

一轮出图和画风库的创作思路参考 [sdnwls/nai-style-lab](https://github.com/sdnwls/nai-style-lab)，结合工坊既有功能独立实现，未复制其代码、原图或画师数据集。该项目以遗传式探索和两两对比为核心，本项目只取「从词库抽组合、有限出图、挑选保存」的体验，其对比、排名与进阶流程均未保留。

## 维护入口

- `services/styleRoll.ts`：资料校验、统一随机抽取、固定 Tag 与旧记录读取。
- `services/styleRollSeed.ts`：画师名规范化与外部图库的画师 Tag 识别。
- `services/styleRollWorkflow.ts`：普通有限批次与轮次条件快照。
- `services/styleRollApi.ts`、`styleRollGeneration.ts`：记录、屏蔽名单、历史及既有后台生成的接缝。
- `services/styleRollWorkspace.ts`：图库范围、搜索排序与补图资格。
- `components/StyleRollPage.tsx`、`components/roll/`：图库、详情、记录管理、配置、画师管理弹窗及共用范围控件。
- `worker/routes/styleRollRoutes.ts`：私人资料验证与并发版本检查。
- `tests/services/styleRoll*.test.ts`、`tests/components/StyleRoll*.test.tsx`、`tests/worker/styleRollRoutes.test.ts`：当前有限出图、抽取规则及存储边界的合成资料回归；导航和多语另有对应集成覆盖。

工程测试不消费真实额度，不读取私人资料作为夹具。
