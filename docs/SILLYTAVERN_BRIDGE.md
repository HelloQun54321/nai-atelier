# 智慧姬同步（SillyTavern / st-chatu8 桥接指南）

本项目内置双向桥接机制与专属酒馆扩展（`sillytavern-extension/npm-bridge`），对接 SillyTavern 生图插件 [st-chatu8](https://github.com/damoshen123/st-chatu8)，让酒馆 RP 角色扮演与工坊精细调参共享风格串、Vibe 与历史原图。

## 安装与更新连接器

1. 在工坊打开 **「全局设置 → 同步与网络访问 → 酒馆同步」** 并开启智慧姬同步或柏宝绘同步总开关（默认关闭）。
2. 工坊会自动探测本机常见的 SillyTavern 路径（如 `D:\SillyTavern`、`C:\SillyTavern` 等），点击 **「一键安装 / 更新扩展」** 即可写入酒馆扩展目录；跨机或容器部署可点击 **「导出离线 ZIP 安装包」** 手动解压至 `SillyTavern/public/scripts/extensions/third-party/npm-bridge/`。
3. 安装或升级连接器后，**刷新已打开的 SillyTavern 网页**即可生效。

## 同步范围与规则

| 资产类型 | 同步方向 | 规则说明 |
| :--- | :--- | :--- |
| **风格串与封面** | 工坊勾选发送 ／ 酒馆全量接收 | 工坊仅发送主动勾选加入「待同步」的 V4.5／V5 风格串及封面；酒馆侧新增或修改的风格串自动同步回工坊 |
| **永久 Vibe 与组合** | 双向同步 | 按原图二进制 SHA-256 去重，兼容不同导出器的编码格式，组合结构以 st-chatu8 为准 |
| **生成历史原图** | 酒馆 → 工坊 | 直接在工坊历史页索引酒馆原图路径（跳过缩略图），**零重复磁盘占用** |

## 日常使用流程

1. 在工坊「风格串」页点击顶栏 **「智慧姬同步」**（手机端位于筛选菜单）：
   - **挑选风格串**：筛选并勾选要发往酒馆的配方，点击「加入待同步」；
   - **待同步**：展示等待酒馆接收的任务，失败项显示具体原因并支持重试；
   - **同步记录**：酒馆成功落盘正文与封面后自动归入记录。
2. 切回 SillyTavern 页面即可自动触发同步，也可在酒馆右上角扩展面板找到「智慧姬同步」点击 **「立即同步」**。
3. 若在酒馆中删除了某条已同步风格串，下次核对会标记为「智慧姬中已移除」，保留工坊本地原件且不再自动重发（需再次发送可手动重新加入）。

## 拼车公共队列互通

工坊的「多人拼车公共队列」采用与 st-chatu8 相同的 NovelAI Key SHA-256 指纹握手协议，两边客户端填入同一队列地址即可平滑共用排队顺序。
