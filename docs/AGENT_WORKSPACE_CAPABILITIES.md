# Agent 业务、工作区与文件能力覆盖

最近覆盖复核：2026-10-30。以 2026-10-21 的业务工具扩展（`6f5bc23b`）为基线，补齐之后新增功能，并按用户最新意图校准为直接业务优先。能力等价不等于模拟人的点击顺序：资料读取和业务操作优先调用结构化工具及共用服务，不依赖页面打开、目录展开或卡片加载。当前页面只提供所指对象与未保存现场，控件操作是必要辅助。成功依据实际数据与执行回执，不能仅凭点击或任务发起。

## 直接目录业务

`list_directories`／`get_directory_members` 分页读取真实目录、父子关系、路径及成员归属；`create_directory`／`update_directory`／`set_directory_memberships` 直接创建、改名、移动和增减指定关系；`request_delete_directory` 沿用危险操作确认，执行时重新读取目录。六个独立 scope：

| scope | 实际资料 |
| --- | --- |
| chains | 风格串文件夹与多归属 |
| artists | 画师用户分组，Roll 选画师共用 |
| characters | 词库角色和自定义角色分组，成员身份分别为 catalog／custom |
| prompts | 提示词片段目录，兼容旧片段默认归属 |
| combinations | 组合分类树及自定义标签身份，包含已有空分类和旧标签投影 |
| inspirations | 收藏夹与图片多归属 |

每页／每批最多30项，按实际 `nextOffset` 续读；长字段明确 `partialFields` 并可按 JSON 字符游标读全。片段和组合分别使用自身关系更新接口，只写指定归属，保留正文、参数和未涉及标签；目录版本或条目快照冲突明确失败，不重放旧整树。部分完成回传准确范围，大操作回执以本轮最多4份的私有 Map 暂存，`resultId` 可续读完整 JSON，跨轮过期。普通组合改名遇到既有分类拒绝，不隐式合并。写后只刷新相关页面资料，不导航或重设当前筛选。

## 画布与创作状态

`get_image_edit_state` 返回实际画布尺寸、蒙版、聚焦重绘选区、扩图和忙碌／生成准备状态。`edit_image_canvas` 修改真实画布与现有撤销栈，不创建独立的模拟画板。

- 蒙版：矩形、椭圆、多边形、连续笔刷、擦除、清空、反转、撤销／重做；坐标为实际像素。
- 聚焦重绘：设置实际选区，绘制只改选区内的像素，保留外部原有蒙版。
- 底图：使用当前界面的 contain／crop／stretch 规范化方式。
- 扩图：先设置四边 64px 倍数，再应用到真实底图与蒙版；回执等待解码和草稿稳定。
- 全屏：沿用当前编辑画布；其他前景弹窗出现时不执行后台画布命令。
- 原生观察：`inspect_current_page_image` 将实际可见图片或当前底图交给当前模型；模型未支持图片输入时明确拒绝，不启动另一视觉模型。
- 目标同步：运行中切换作品、实验室模式或生成模型同步当前目标与工具说明；旧目标确认取消，返回时可恢复未应用草稿，手动变化优先。

画布命令不会生成图片，也不会消耗 Anlas。生成沿用实际界面的业务流程，确认要求跟随当前助手权限。

实验室模型视图将旧全局负面与角色分栏编译为完整正文，原资料不因读取而改写；未改字段及来源保留原存储，实际编辑后按页面输入规则应用，撤回／重做恢复原始内容与来源。全局 base／subject 及前后置模块继续保持身份，图片编辑应用与生成按 base → pre 模块 → subject → post 模块编译。

页面操作提交同一作品／模式的提示词改动后，先同步实际工作草稿，再沿用业务工具的缺失 Tag 补译与保存流程；只读、打开编辑框和切换作品不触发补译，页面结果不冒充尚未应用的草稿。

## 对话内 @ 引用角色库

创作助手输入框支持输入 `@` 调出角色库候选（方向键移动、Enter／Tab 选择、Esc 收起，触屏可直接点选），候选同时包含自定义角色与词库角色；选择后输入框插入 `@角色名` 并显示可移除的引用标签。引用只作为本轮运行上下文交给助手：自定义角色带名称、角色提示词、负面词和描述，已有个人配方的词库角色沿用该配方，其余词库角色带英文 Tag、中文名与条目数，需要更多特征时助手再调用 `search_character_catalog` 查本地目录。可直接引用的数量跟随当前草稿模型支持的角色槽上限（官方同步值：V5 为 32、V4／V4.5 为 6），达到上限后不再新增并提示；切换模型后超出部分在发送时只保留前 N 个。聊天正文只保留 `@角色名`；引用元数据随该条用户消息保存，仅供标签显示、编辑重发与继续时恢复，不进入正文，也不改动实验室草稿、角色库或生成参数。发送后随输入清空，切换会话不保留未发送的引用。历史消息显示引用标签；正文删掉 `@名称` 时同步移除引用。运行上下文明确「引用已由用户选定」，助手不再重复搜索同名角色，只有资料确实缺少会改变结果的特征时才查目录。
补全按输入片段实时联想：自定义角色按名称、角色 Tag、描述匹配并让名称命中优先，词库角色支持中文名、英文 Tag 与作品名；英文忽略空格（hutao → hu tao），命中片段高亮，仅提示词命中的自定义角色降权到词库之后。不做拼音匹配；面板打开时预热角色词库，减少首字等待。

## 按对话保存的提示词版本

`list_prompt_versions` 查询当前对话的版本摘要，`read_prompt_version` 按 JSON 游标读全旧稿，`restore_prompt_version` 核验目标与当前内容后恢复。运行只绑定当前对话，不能通过工具参数选择其他对话。版本写入原会话文件的兼容字段，不依赖模型上下文或摘要记忆，没有固定份数裁剪；相邻相同原稿去重。

暂存草稿、实际页面提示词编辑和资料库提示词更新都先保存原稿，再执行修改；恢复前也保存当前稿，备份失败就停止。版本保留全局／角色正负提示词、模块及顺序／启停、旧分栏、来源和提示词变量，不把图片、氛围参考、密钥或生成参数当作提示词版本。暂存稿恢复仍沿用当前应用策略，回执区分暂存与页面已应用；资料库更新核验条目版本，写后回读真实内容。遇到未记录的手改、目标不符或并发更新时拒绝覆盖，不凭记忆重写或自动重试业务。

关闭重开、摘要、改名与编辑旧消息保留旧稿；清空或删除对话同时清除其版本。这是对话内的修改记录，独立资料备份仍沿用项目原备份功能。恢复后继续原有静默 Tag 补译与保存流程，不新增独立模型调用。

## 本地文件、图片转用与导出

| 工作流 | 实际路径 |
| --- | --- |
| 浏览电脑创作文件 | `list_local_files` 分页列出图片、JSON、`.naia`、`.naiv4vibe`、`.naiv4vibeBundle` 和子目录；普通列表不递归 |
| 本地文件导入 | `attach_local_files` 按真实路径读取文件，经当前对话与 Key 的不透明令牌交给实际上传入口 |
| 批量文件夹 | 保留相对路径；最多 8 层、200 个文件、合计 128 MB；跳过符号链接、拒绝受保护目录 |
| 图片转用 | 页面原图暂存到当前标签页，再粘贴到实际图片上传入口；使用原始字节，不把缩略图当原图 |
| 页面导出 | Agent 操作期间捕获页面实际创建并下载的 Blob，保留最近 4 份记录；每份最多暂存 30 MB，超限返回 `available:false` 与错误，不冒充指定目录保存成功 |
| 指定目录保存 | `save_page_export_to_folder` 保存真实图片、JSON、`.naia`、Vibe／Vibe 组合或 ZIP 副本，返回绝对路径，同名加编号 |

“文件已交付上传入口”仅表示真实文件到达控件。是否导入、编码、保存成功，需要继续核对窗口通知、实际列表或业务收据。导出暂存随标签页刷新失效；未产生实际导出副本时不能声称已保存。图片转用使用标签页内暂存，不监听或修改系统剪贴板。

所有助手文件读写仍受单文件 30 MB 限制；页面原有大分享包导入／导出能力不等于助手文件桥容量。独立 Android 限于 `/documents`，局域网使用运行工坊的电脑文件系统。`get_agent_capabilities` 返回实际平台、文件根、收集器可用性和当前模型的工具／图片能力；未确认的能力标记 unknown。

沿用只读／标准／完全访问三档权限。只读禁止导入、画布修改和落盘；标准首次写入指定目录仍确认，完全访问可按请求自动创建目标目录。完全访问同时授权生图及其费用，无需再次确认；标准权限保留生图确认，编码和危险操作继续确认；不提供任意文本编辑、终端命令或电脑其他应用控制。`local-data` 没有开放到本地文件接口。

## 新组件的工程约定

- 真正窗口使用 `role="dialog"` 与名称；菜单使用 `role="menu"`，触发控件提供 `aria-expanded`／`aria-haspopup`。非模态详情与筛选继续登记前景范围。
- 选中、勾选与展开使用 ARIA 状态；输入有 label／aria-label；重复资产控件用 `data-agent-object` 标识所属对象。
- 私人字段用 `data-agent-private`，Agent 自身界面用 `data-agent-surface`。需要用户最终确认的按钮使用 `data-agent-action="business"`，不能根据普通按钮名称误封整个工作流。
- 只读可点击的浏览入口必须在目标自身标记 `data-agent-action="browse"`；目录浏览的原生下拉也按此标记。标记不向子控件继承，不标记会修改资料的选择器或批量选择卡片，`business` 及私密区域仍优先拒绝；按钮名称、角色与 `aria-haspopup` 不授予只读点击权限。
- 通知使用 `role="status"`／`role="alert"` 或 `data-agent-notification`，异步过程提供真实 `aria-busy`。
- Canvas 状态用 `data-agent-canvas-state` 参与页面版本；非 DOM 操作通过当前可见范围注册结构化命令。全屏画布通过同一 `data-agent-command-scope` 关联原编辑器。
- 需要自由拖动／双击的区域显式标记可用动作；不要给任意容器暴露脚本执行能力。
