# Agent 页面与文件能力覆盖

本轮全局审查与实现：2026-10-04。目标是让用户在工坊中正常使用的界面与创作操作，都有真实页面读取或业务工具入口。确认成功必须依据实际状态、通知或文件结果，不能仅凭“已发出点击”。

## 页面覆盖

| 范围 | Agent 的入口与实际行为 |
| --- | --- |
| 风格串、角色、画师、AITag、Pixiv、Danbooru、灵感、历史 | 读取当前页、按名称寻找卡片、筛选和分页；打开详情后优先读详情；关闭后恢复列表 |
| 筛选、详情菜单、标签候选、灵感板编辑、上传与批量导入窗口 | 识别前景弹窗／浮层，读取真实选项、选中状态和输入；按当前页面版本操作，过期编号拒绝 |
| 全局设置 | 普通设置可读写；保管箱条目、密钥输入与 Agent 自身权限／模型菜单不进入可操作范围 |
| 操作回执 | 带全局通知、当前可用命令和导出副本；区分目标匹配、收到结果、发生变化、未检测到变化 |
| 隐藏上传入口 | 窗口可见时读取文件格式、是否多选／文件夹及对应名称，使用本地文件桥交付真实 FileList |
| 重复控件 | 带所在卡片、Vibe／参考槽和字段上下文；复用原有按钮、下拉、勾选、悬停与键盘交互 |
| 拖动与双击 | 对侧栏宽度、历史大图、扩图摆放等已标记区域执行实际 Pointer／Mouse 事件；排序与角色定位也可使用已有按钮和坐标字段 |
| 生图、编码、删除和清空确认 | 可读取后果并请求操作；保留用户确认，不能通过普通页面点击代替用户批准 |

## 画布与创作状态

`get_image_edit_state` 返回实际画布尺寸、蒙版、聚焦重绘选区、扩图和忙碌／生成准备状态。`edit_image_canvas` 修改真实画布与现有撤销栈，不创建独立的模拟画板。

- 蒙版：矩形、椭圆、多边形、连续笔刷、擦除、清空、反转、撤销／重做；坐标为实际像素。
- 聚焦重绘：设置实际选区，绘制只改选区内的像素，保留外部原有蒙版。
- 底图：使用当前界面的 contain／crop／stretch 规范化方式。
- 扩图：先设置四边 64px 倍数，再应用到真实底图与蒙版；回执等待解码和草稿稳定。
- 全屏：沿用当前编辑画布；其他前景弹窗出现时不执行后台画布命令。
- 原生观察：`inspect_current_page_image` 将实际可见图片或当前底图交给当前模型；模型未支持图片输入时明确拒绝，不启动另一视觉模型。
- 目标同步：运行中切换作品、实验室模式或生成模型同步当前目标与工具说明；旧目标确认取消，返回时可恢复未应用草稿，手动变化优先。

画布命令不会生成图片，也不会消耗 Anlas。生成沿用实际界面的业务流程与用户确认。

## 本地文件、图片转用与导出

| 工作流 | 实际路径 |
| --- | --- |
| 浏览电脑创作文件 | `list_local_files` 分页列出图片、JSON、`.naiv4vibe` 和子目录；普通列表不递归 |
| 本地文件导入 | `attach_local_files` 按真实路径读取文件，经当前对话与 Key 的不透明令牌交给实际上传入口 |
| 批量文件夹 | 保留相对路径；最多 8 层、200 个文件、合计 128 MB；跳过符号链接、拒绝受保护目录 |
| 图片转用 | 页面原图暂存到当前标签页，再粘贴到实际图片上传入口；使用原始字节，不把缩略图当原图 |
| 页面导出 | Agent 操作期间捕获页面实际创建并下载的 Blob，暂存最近 4 份，每份不超过 30 MB |
| 指定目录保存 | `save_page_export_to_folder` 保存真实图片、JSON、Vibe 或 ZIP 副本，返回绝对路径，同名加编号 |

“文件已交付上传入口”仅表示真实文件到达控件。是否导入、编码、保存成功，需要继续核对窗口通知、实际列表或业务收据。导出暂存随标签页刷新失效；未产生实际导出副本时不能声称已保存。图片转用使用标签页内暂存，不监听或修改系统剪贴板。

沿用只读／标准／完全访问三档权限。只读禁止导入、画布修改和落盘；标准首次写入指定目录仍确认，完全访问可按请求自动创建目标目录。所有档位都保留生图和危险操作确认；不提供任意文本编辑、终端命令或电脑其他应用控制。`local-data` 没有开放到本地文件接口。

## 新组件的工程约定

- 真正窗口使用 `role="dialog"` 与名称；菜单使用 `role="menu"`，触发控件提供 `aria-expanded`／`aria-haspopup`。非模态详情与筛选继续登记前景范围。
- 选中、勾选与展开使用 ARIA 状态；输入有 label／aria-label；重复资产控件用 `data-agent-object` 标识所属对象。
- 私人字段用 `data-agent-private`，Agent 自身界面用 `data-agent-surface`。需要用户最终确认的按钮使用 `data-agent-action="business"`，不能根据普通按钮名称误封整个工作流。
- 通知使用 `role="status"`／`role="alert"` 或 `data-agent-notification`，异步过程提供真实 `aria-busy`。
- Canvas 状态用 `data-agent-canvas-state` 参与页面版本；非 DOM 操作通过当前可见范围注册结构化命令。全屏画布通过同一 `data-agent-command-scope` 关联原编辑器。
- 需要自由拖动／双击的区域显式标记可用动作；不要给任意容器暴露脚本执行能力。

## 验收

前端 16 个文件、166 项定向测试通过；隔离临时副本网关 348 项通过；完整构建通过。浏览器使用实际 ImageEditPanel／Canvas 与合成图片验证：192×192 矩形实际改变 36,864 个像素，128×128 聚焦重绘选区只改变 16,384 个像素，撤销／重做、原生底图观察、全屏画布、四边扩图到 640×640、真实 FileList 上传、原图转用、JSON 导出及拖动均取得实际结果。

验收未调用收费模型或生图接口，未读取或改写私人数据。自动化回归与组件验收建立当前实现的覆盖依据；无法据此保证未来新增的任意组件自动拥有完整操作语义，应继续遵循上述约定。
