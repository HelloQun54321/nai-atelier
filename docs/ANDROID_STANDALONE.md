# 独立 Android APK

## 使用与交付范围

首次交付范围为完整工坊：四种创作模式、资源图库、Agent 与按需下载的本地反推。应用共用 React 手机界面，在手机本地执行 Worker 资料路由，以原生 SQLite、文件、网络和 ONNX Runtime 提供独立运行能力，无需电脑、Termux 或自建服务器。NovelAI 生图和 Agent 模型仍使用各自的联网服务与用户凭据。

要求 **Android 8.0+、64 位 ARM 手机**，并保持 Android System WebView 更新。签名安装包生成在 `release/NAI-Atelier-<package.json 版本>-android-arm64.apk`，公开发布另行执行；首份包实测约 **23 MB**（十进制，不含词库或反推模型）。

安装后在设置配置自己的 NovelAI Key；四模式、风格串、角色、灵感、历史和外部图库沿用现有工作流。在「生图偏好与实验室」按需下载反推模型，在「数据与维护」下载补全词库、设置缩略图缓存或导出完整备份。独立工坊与电脑工坊各自保存资料，尚未提供自动跨设备同步或电脑完整数据迁移。

新构建 APK 的显示版本从 `package.json` 读取，只跟随电脑端迭代；Android 修复使用 `android/gradle.properties` 的独立安装构建号递增。此前交付的显示版本 1.50.0、构建号 **1051001** 是一份已有安装包的记录，不表示当前源码或新 APK 仍为该版本。同签名且构建号更高的 APK 可覆盖安装并保留资料，无需卸载；电脑迭代不会自动重新构建或发布手机安装包。

图片操作继续长按约 450ms 原位显露，移动手指、开始双指手势或滚动时取消长按；图片不会同时弹出系统保存菜单，输入框仍可选择文字。详情图片点按进入大图，支持双指连续缩放、双击触点放大／复原、放大后单指拖动、双击按住纵向调节缩放；有多张图片时，仅适应窗口状态横滑翻图。返回只关闭当前大图，恢复原详情位置。

## 存储与备份

| 内容 | 保存方式 | 空间与清理规则 |
| --- | --- | --- |
| 资料、历史索引、预算、设置 | 应用私有 SQLite，事务写入 | 长期资料，不作为缓存清理 |
| 历史、灵感、Vibe、角色参考与封面原件 | 私有文件，SHA-256 内容寻址 | 完全相同的原件只存一份，全部独立引用删除后才释放文件 |
| NovelAI Key 与 Agent／Pixiv 凭据 | Android Keystore 加密 | 不把明文 Key 写进浏览器存储，不随 APK 分发 |
| 缩略图 | WebP 与已有 IndexedDB 缓存 | 默认上限 100 MB，可关闭或改为 25／50 MB；清理不影响原图 |
| 词库与目录索引 | 显式下载后生成缓存 | 全部分片完成才切换版本，失败保留原来的完整词库 |
| 反推模型 | 原生 CPU 推理，模型下载至缓存 | 按固定 revision、大小与 SHA-256 验证，支持续传、暂停和单独删除 |
| Agent 会话、任务与审计日志 | 私有文件 | 随完整备份保存，沿用确认、费用与 Key／会话归属规则 |

最小 WD ViT V3 的模型文件为 **378,536,310 字节**，另有约 0.31 MB 词表；下载后空间不计入 APK，运行内存需求高于文件大小。更大模型沿用共用管理入口，应由手机自身内存决定是否下载。系统在存储紧张时可能回收应用缓存，词库或模型届时需要重新下载，原始创作资料保留。

**卸载 APK 会删除手机的应用私有资料。** 换机、卸载或重置前，请在「数据与维护」设置至少 8 位备份密码并导出 `.naiatelier` 文件到系统目录或外部存储。备份包含数据库、原图、设置、Key、Agent 会话和 Pixiv 凭据，不含缩略图、词库和模型；丢失密码无法恢复。恢复先验证认证块、数据库与所有原图，再经用户确认替换工坊；失败或替换途中进程被结束时保留原工坊。数据库快照与加密流分块处理，避免把数 GB 原图整体放入内存；导出和恢复需要足够的暂存空间。

图片下载写入相册 `Pictures/NAI Atelier`；Android 8／9 使用系统文件选择器。复制使用原生图片剪贴板，接收应用决定是否接受图片粘贴；元数据清洗沿用共用分享流程。JSON、Vibe、ZIP、日志与备份通过系统文件选择器导出，实际写入成功后才显示完成。

## 平台取舍

- 生图、参考编码、费用结算与 Agent 路由从现有源码提取并共用，原生层负责网络与文件。官方常量在后台同步，启动不等待；失败保留完整快照并提示失效。保持单张创作与显式付费确认，不在返回前台时重放请求。
- 二进制和 SSE 逐块传输，取消传到实际请求；生成与模型请求期间启用 Android 前台任务服务，完成后退出。强制停止应用或厂商进程清理仍可能中断任务，重新打开不能自动重试付费请求。
- Agent 操作工坊资料、当前页面、草稿和模型；磁盘工具只开放应用内 `/documents` 创作目录，保护数据库与凭据。外部文件通过上传入口选择，导出通过系统选择器。Windows 全局剪贴板监听、电脑目录、SillyTavern 本机桥与 EXE 更新属于电脑功能。
- Pixiv 支持刷新令牌与浏览器登录，手机用 `pixiv://account/login` 回调返回；网络或登录验证由对应站点决定。联网使用手机自身网络／VPN，不复用电脑代理环境。
- AITAG JSON 使用系统 Chromium 与共用站点请求头，避免普通原生 HTTP 的站点兼容性差异；图片和其他服务仍使用原生流传输。只开放既有公开接口，不装入桌面代理或附加网络库；网站验证、拒绝和网络失败仍保持真实状态，不关闭证书验证。
- 不打包 Node、Wrangler、workerd、桌面图像库或模型，仅保留 ARM64 原生库，发布开启 R8 和资源压缩。安装包不包含开发者私人数据。

## 构建与验证

需要 Node.js 22+、JDK 21、Android SDK 36 与 Build Tools 36.0.0，使用 `JAVA_HOME` 和 `ANDROID_HOME` 指定位置；本机脚本默认复用 `.android-build/sdk` 与已安装的 Zulu 21。Gradle wrapper 与 Java 源码入库，SDK、构建物、签名和日志忽略入库。

```powershell
npm ci
npm run build:android          # ARM64 签名正式包
npm run build:android:debug    # 模拟器调试包
# 先启动隔离模拟器；真实手机不作为自动回归目标
$env:ANDROID_SERIAL='emulator-5556'
npm run test:android
# 单独验证 AITAG 公开接口，不提交账号或付费请求
$env:ATELIER_ANDROID_TEST='1'
$env:ATELIER_ANDROID_LIVE='1'
npm run test:gateway -- tests/integration/android-webview.test.mjs
Remove-Item Env:ATELIER_ANDROID_TEST,Env:ATELIER_ANDROID_LIVE
npm run test:gateway
npm run test:live-sync
```

首次正式构建生成并持续复用 `.android-build/atelier-release.jks` 与 `.android-build/signing.properties`；**两文件必须一并妥善备份**，丢失原签名将无法覆盖升级已有安装。同签名 APK 覆盖安装保留资料；调试签名与正式签名不能互相覆盖，日常使用请保留正式包。

验证覆盖隔离 Android 15 模拟器的 SQLite JSON／事务、原图去重、备份认证与恢复、中断恢复、ONNX CPU 合成模型；真实 WebView 的资料与原图、小图尺寸、原生 SSE、四模式普通／流式模拟请求、Agent 模拟模型输出和重启持久化。手机回归还核对 Pixiv PKCE 登录发起、320／360px 四模式排版、长按释放不误开详情、双击／双指缩放和抬指后连续平移；显式联网检查 AITAG 配置、在线列表、详情及图床图片。官方联网核对执行实际费用调用，不调用付费生图；前端分享与 Vibe 定向回归、电脑构建和原有后台回归保持可用。

尚未用真实手机验证厂商后台策略、完整 WD 模型的耗时／峰值内存，或用真实 NovelAI／LLM／Pixiv 账号发起收费请求和登录；这些不能由合成测试代替。具体 APK 签名、体积与校验结果随本地交付记录保存。
