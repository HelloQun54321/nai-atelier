# 画布：开发与页面方案

本方案依据本次用户讨论，目标是把透明角色、宽幅背景和其他素材在本地合成为可继续编辑的作品。电脑端完整编辑；入口为左侧边栏「工作区 → 画布」。不触发生图或费用。保留现有未提交改动和私人数据，不调整存储定位键、迁移或清理既有数据。

## 页面结构

- 顶部：工程名称与保存状态、新建/打开工程、导入/导出工程、导出 PNG/JPEG、送往实验室。工程列表可按需打开；自动保存失败需显示真实状态。
- 左侧工具栏：移动、矩形选区、多边形选区、自由套索、橡皮擦、恢复笔刷；导入图片和背景设置。选区支持复制当前图层、剪切、删除、复制合并内容及取消；非矩形选区与其外接矩形分别用于图层和画布剪裁。
- 中间：画布和周围工作区；背景为透明或纯色，图片背景作为可锁定图层。滚轮/按钮缩放、适配和平移只影响视图；画布范围外不绘制，但图层完整保留，图层列表可选中并复位画布中心。
- 右侧：图层列表，从上到下表示前后；新建空层、可见/锁定、重命名、排序、复制、删除；选中图层提供位置、尺寸、旋转、水平/垂直镜像、不透明度、恢复剪裁。导入图片默认新建图层，自动等比适配画布且保留原图。
- 底部：画布像素尺寸、预览缩放、当前选区及坐标。画布尺寸可输入，不设置产品固定上限；实际创建或导出失败时展示明确原因。

## 行为与数据

- `services/canvasTypes.ts` 是跨模块共享的工程协议：素材原图、画布尺寸、图层变换、可恢复剪裁多边形和可恢复擦除蒙版均跟随工程保存；选择框与撤销栈属于当前会话。图层本地原点变换顺序为平移、旋转、缩放。画布剪裁仅改变画布边界与图层位置，绝不丢弃画布外内容。
- 每次完整操作形成一次撤销记录；包含移动、图层修改、剪裁和笔画。保存后重开不要求恢复操作历史，但保留原图、剪裁与可恢复擦除结果。
- 工坊内工程使用现有 D1 settings 和 R2 对象的独立键，通过应用 API 持久化；复用现有数据库和 bucket，不修改 schema、存储定位键或本地文件结构。工程文件可导出并导入，带齐素材与编辑数据；不依赖原始文件路径或浏览器缓存。自动保存串行、显示成功/失败，切换工程前处理待保存内容。
- 素材本地上传/拖放/粘贴；从历史选择原图时使用实际原图，不带入或改写其生成参数。合成图以用户主动操作发送给图生图、局部重绘或扩图，仅作为底图，不发起请求或覆盖其他模式的文本参数。
- PNG 保留透明；JPEG 对透明部分显式填白。图片和工程文件导出只由用户触发。

## 并行分工与验收

1. 核心图形服务：渲染、坐标变换、图层素材、三种选区、非破坏性裁剪、橡皮擦/恢复、选区复制。修改限定 `services/canvasEngine.ts` 与对应测试。
2. 持久化：工程存取 API、工坊工程服务、导入导出和针对性测试。修改限定新文件和 `worker/index.ts` 的路由接线；不得操作真实私人数据或迁移 schema。
3. 界面组件：工具栏、属性与图层面板，以受控属性与回调连接，不接管全局路由、主画布或持久化。修改限定 `components/canvas/` 和对应测试。
4. 主代理：独立画布工作区、侧边栏及 Atelier 流转、操作历史和手势、整合、实际浏览器验证与必要文档。

验收覆盖：透明人物和风景合成；移出画布再移回；图层顺序与锁定；三类选区的当前层与合并复制；旋转/镜像后的擦除和恢复；两种剪裁以及保存重开后恢复；工程导入/导出；PNG 透明和 JPEG；发送至三种编辑模式而不生图；异常与大尺寸按真实结果提示。测试与浏览器验证使用独立测试资料，不触碰用户真实工坊数据。
