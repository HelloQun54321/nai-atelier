## 已确认摩擦（按优先级）

### P0 — 分类栏「使用提示词」用途错位 ✅ 已修（2026-11-01）

- **现象：** 点角色页「人物设定」栏工具条上的「使用提示词」，弹窗标题／筛选却是「当前栏：外貌与身体」；`aria` 树上该钮也常排在错误栏旁。  
- **影响：** 无法靠 UI 把身份片段可靠填进人物设定；只能手写或绕路。  
- **修复：** 分类栏标题旁就地挂 `PromptLibraryFieldActions`（不再经 textarea portal 错绑）；同屏只保留一个取用／收录弹层。

### P0 — 「保存并继续」串用途 Tag ✅ 已修（2026-11-01）

- **现象：** 粘贴收录连续写多条片段时，用途按钮状态会带到下一条；汉服曾叠成外貌+服饰，琵琶叠成外貌+服饰+物品。  
- **影响：** 用途锁定取用时候选错乱或「没有此用途的片段」。  
- **修复：** 「保存并继续」清空用途 Tag，仍保留目录分类与自由标签。

### P1 — 物品道具默认不可见

- **现象：** 角色默认栏无「物品与道具」；琵琶只能塞进「补充」，或先「更多 → 添加」。  
- **影响：** 「设定 + 发型 + 服饰 + 手持物」这条组合路径不顺手。

### P1 — 风格串送进实验室后角色脏稿

- **现象：** 从收藏风格串「发送到实验室」会带入原串角色整段（本轮为沈砚秋长正文进补充等）。  
- **影响：** 要验证新片段拼接时，必须先清空角色／补充，否则图里混进旧人设。

### P1 — 取用弹层与底层卡片叠层

- **现象：** 实验室打开「使用提示词」时，无障碍树仍大量露出提示词库／风格串卡片；脚本易点到底层「删除」误删条目。  
- **影响：** 弹层应锁焦点并挡住底层危险操作。  
- **复现升级（00:15）：** 库内一度只剩马尾／汉服／琵琶；2B、A2、西域舞娘服整组消失（此前已写入），高度像叠层误点删除。已用粘贴收录按单用途重建。

### P1 — 取用弹窗可叠多层

- **现象：** 连续点不同栏的「使用提示词」会留下多个未关弹层（本轮曾同时两个搜索框／关闭钮）。  
- **影响：** 挡操作、易误点底层。

### P0 — 组合保存丢掉「补充」栏 ✅ 已修（2026-11-01）

- **现象：** 从角色 1 收录「组合（保存已分栏内容）」时，人物设定／外貌／服饰都进了「验证-2B马尾汉服琵琶」，但「补充」里的琵琶正文未出现在组合详情与取用预览。  
- **影响：** 用户以为的「2B+马尾+汉服+琵琶」配方实际缺第四块；库页送到实验室也无法补回琵琶。  
- **修复：** `workspacePicks`／快照读写纳入角色 `prompt` 与全局 `extra`；取用写回补充落点。

### P1 — 风格串 `1girl, solo` 压过多人构图

- **现象：** 多角色请求里两槽 caption 都正确，但全局 `input` 仍带收藏风格串的 `1girl, solo`；成图多张仍以单人 2B 为主。  
- **影响：** 分栏／多角色拼接本身没丢，视觉验收却像「第二人没生效」。

### P1 — 分类栏「使用提示词」进不了组合 ✅ 已修（2026-11-01）

- **现象：** 有用途锁定的分类栏取用只出片段；要回填整套配方必须去提示词库「组合」页点「送到实验室」。  
- **影响：** 「片段拼完 → 存组合 → 实验室一键取回」断在分类栏入口。  
- **修复：** 用途栏弹层保留片段／组合切换；组合整套写入当前角色或全局。
