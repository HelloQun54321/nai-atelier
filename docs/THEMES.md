# 制作和分享设计主题

在「全局设置 → 外观与画廊」调整强调色、密度、圆角、材质、字号、动效及图库效果；展开「自定义明暗配色」，可分别编辑浅色和深色版本。「控件、排版与玻璃细节」进一步开放字体、字重、几何、玻璃光学和过渡参数。修改实时预览，「另存当前主题」保存为新主题；已有自定义主题修改后可「保存修改」覆盖该主题，内置主题原件始终锁定，可另存修改后的副本。项目自带「NAI Atelier 默认」与「Cupertino Liquid Glass」，新安装即可选用，首次启动仍沿用原默认主题。

主题卡片展示已保存的外观。出现「当前外观已修改」时，可保存或「导出当前外观」；卡片导出与「导出全部」始终导出已保存的内容。重置外观保留主题库、生图偏好和实验室布局；删除当前主题会真正恢复默认外观。

## 从示例开始

下载[暖纸示例](../public/themes/warm-paper.json)，在主题区点「导入」选择文件，也可直接拖入主题区。示例同时提供米白浅色版和暖棕深色版，可在界面调整后另存、导出并分享。导入会生成新 ID，重名自动加编号，不覆盖已有主题；内置主题导出后可作为普通主题导入。

也可以用文本编辑器修改示例。当前文件格式为：

```json
{
  "version": 3,
  "presets": [
    {
      "name": "我的主题",
      "accentColor": "#b96e2b",
      "themeMode": "system",
      "palette": {
        "light": { "canvas": "#f5ecdc", "panel": "#fffbf3", "text": "#3d3025" },
        "dark": { "canvas": "#211c19", "panel": "#352c25", "text": "#f5e8d3" }
      }
    }
  ]
}
```

## 字段

`name` 必填，最多保留 30 个字符；其他字段缺省时使用默认值。颜色必须是六位十六进制形式，如 `#fff4dd`，支持大小写。文件导出不携带生图、密钥、语言或图库列数设置。

| 字段 | 允许值 | 默认值 |
| --- | --- | --- |
| `accentColor` | 六位十六进制颜色 | `#0ea5e9` |
| `themeMode` | `light`、`dark`、`system` | `system` |
| `density` | `comfortable`、`standard`、`compact` | `standard` |
| `corners` | `soft`、`standard`、`sharp` | `standard` |
| `surfaces` | `solid`、`translucent` | `solid` |
| `motion` | `full`、`reduced`、`off` | `full` |
| `fontScale` | `small`、`standard`、`large` | `standard` |
| `galleryFrostedCaption` | 布尔值 | `true` |
| `galleryHoverFloat` | 布尔值 | `true` |
| `gallerySelectionFocus` | 布尔值 | `true` |
| `palette` | 分别配置 `light`／`dark`；字段见下表 | 原有默认配色 |
| `details` | 高级外观对象；字段见下表 | 跟随基础外观 |
| `background` | 本地背景图片与显示参数；见下节 | 无图片，使用 `canvas` 颜色 |

| 配色字段 | 控制范围 |
| --- | --- |
| `canvas` | 工作区背景 |
| `sidebar` | 侧栏背景 |
| `toolbar` | 工具栏和导航背景 |
| `panel` | 弹层、面板和中性控件的表面基色 |
| `text` | 正文及主要文字 |
| `mutedText` | 次要文字 |
| `border` | 面板边框 |

明暗版本和各个颜色均可只填写需要改变的部分，其余保持对应版本的默认值。输入框、卡片等已有中性色阶从面板与文字颜色派生，透光材质与阴影也跟随配色；强调色上的文字／图标会选择可辨认的前景色。正文和次要文字仍尊重作者填写的颜色，编辑器会提示正文与面板对比度过低的组合。

## 工作区背景 `background`

在「个性化 → 工作区背景」选择 PNG、JPEG 或 WebP 图片，可铺满、完整显示或平铺图案，并调整显示强度；平铺时可调整图案大小。背景只在全局独立底层铺一次并柔化，侧栏、工具栏、各页面和浮层透出同一环境；不额外压低显示强度，不对文字、控件、作品或编辑画布加滤镜，背景设置与主题缩略图也显示柔化效果。减少强度时用当前明暗版的 `canvas` 色压低背景存在感，背景可分别编辑浅色和深色版本，切换编辑目标不必改变当前界面模式。

当前工作区背景按「预设 ID × 浅色／深色」独立保存在本端，不随重新应用预设清空，也不计入主题已修改状态。主题卡片分别预览两套背景；主题保存、共享和导出不携带本端背景覆盖。旧主题文件的单一 `background` 继续读取和往返导出，作为没有本端覆盖时的兼容回退；已有本端单背景会保留到当前预设的两个版本，不删除旧图。Cupertino 自带白天雾蓝光场和夜间星空海面两张配套壁纸；选择「移除背景图片」只禁用当前版本，选择「恢复默认背景」恢复配套图片。上传上限 20 MB，最长边缩至最多 1920px，转换为 WebP 并去掉原图元数据；压缩后的 data URL 最多 1,000,000 个字符，超过时明确报错并保留原背景。浏览器存储不足时不替换当前背景并显示错误，可另选较小图片。原图不进入作品库，不修改原文件。

`background` 仅允许以下字段；缺少整个对象表示没有背景图片。旧文件继续读取，较旧程序需要更新后才能导入带背景的新文件。

| 字段 | 允许值 | 缺省值 |
| --- | --- | --- |
| `image` | 必填，PNG／JPEG／WebP 的 base64 data URL；另仅允许项目配套的 `/themes/wallpapers/cupertino-day.webp` 与 `/themes/wallpapers/cupertino-night.webp` 路径，不接受其他地址、SVG、脚本或任意 CSS | 无 |
| `fit` | `cover`（铺满）、`contain`（完整显示）、`tile`（平铺） | `cover` |
| `opacity` | 0～1 的数字，背景显示强度 | 1 |
| `tileSize` | 32～1024 的整数，平铺单元宽度，px；比例保持不变 | 128 |

玻璃基色与背景分别控制：中性玻璃可以把 `sidebar`、`toolbar`、`panel` 设为无偏色灰阶，通过透明度透出背景实际颜色，无需将表面染成某个固定环境色。背景图片沿用同一套明暗配色与材质规则。

## 高级外观 `details`

高级对象也可只填写所需字段。数字使用 JSON 数值，不附带单位，不接受字符串、`null` 或超出范围的值。默认保持基础主题；表中参考值对应编辑器占位值，填写后才作为覆盖。`details` 顶层为共用值，可在 `details.light`／`details.dark` 逐字段覆盖数字参数与 `accentColor`（六位颜色）；未填写的值继承共用设置。字体、材质、控件风格和曲线保持共用。编辑器通过「编辑范围」切换共用／浅色／深色，清除当前明暗覆盖后恢复继承。配色仍分别放在 `palette.light` 和 `palette.dark`。

| 字段 | 范围／允许值 | 单位与作用 |
| --- | --- | --- |
| `fontFamily` | 本机字体名称及回退列表，最多 220 字符 | 如 `system-ui, sans-serif`；可用字母、数字、中文、空格、逗号、引号、下划线和连字符；不允许 URL、CSS 语句或下载字体 |
| `fontSize` | 14～20，参考 16 | px，根字号；现有 rem 字阶随之缩放 |
| `strongWeight` | 400～800，参考 600 | 标题与强调文字的字重，覆盖现有 semibold／bold／extrabold；取决于本机字体可用字重 |
| `lineHeight` | 1.2～1.8，参考 1.5 | 正文继承行高；已有专用行高的控件保留其设置 |
| `letterSpacing` | -0.04～0.08，参考 0 | em，正文继承字间距 |
| `iconStroke` | 1～2.5，参考 1.8 | Lucide 图标线宽；不替换图标集合 |
| `controlHeight` | 32～48，参考 40 | px，共用按钮、页签、筛选与单行输入／选择器；触屏不小于 44px |
| `controlRadius` | 0～999，参考 12 | px，共用控件与普通圆角按钮；999 可形成胶囊，导航条目圆角不超过 14px，图上圆形操作保留其语义 |
| `panelRadius` | 0～36，参考 16 | px，公共面板、设置和操作窗口 |
| `cardRadius` | 0～32，参考 16 | px，媒体卡片；多行输入圆角不超过 16px |
| `spacing` | 0.2～0.3，参考 0.25 | rem，Tailwind 间距基准，影响 padding／gap 等相应工具类 |
| `toolbarHeight` | 44～72，参考 56 | px，共用工具栏基准高度，顶部安全区另加 |
| `chromeInset` | 0～16，参考 0 | px，桌面玻璃侧栏与工具栏的外留边；手机玻璃导航使用适合触控的固定悬浮留边 |
| `material` | `frosted`、`glass` | 磨砂或带边缘高光、背景折射与交互光照的玻璃；仅在 `surfaces: "translucent"` 时启用 |
| `blur` | 0～40，参考 22 | px，玻璃／磨砂背景模糊 |
| `saturation` | 100～200，参考 130 | %，背景饱和度 |
| `opacity` | 0～1，参考 0.85 | 表面不透明度，1 为完全不透明；太不透明会遮住折射效果 |
| `globalOpacity` | 0～1，可选 | 全局不透明度滑条，统一覆盖导航、工具栏、弹窗、详情与通用内容表面的分层不透明度，嵌套填充按比例变薄；不改变文字／作品透明度，也不影响独立的实验室编辑面。支持明暗覆盖，缺省保留旧分层值；清除全局覆盖恢复继承 |
| `sidebarOpacity`、`toolbarOpacity`、`panelOpacity` | 0～1 | 分别控制侧栏、工具栏和弹窗的透明度，缺省继承 `opacity` |
| `labEditorOpacity` | 0～1 | 只控制实验室左侧连续编辑面，设置中以 0～100% 滑条实时调节；支持共用、浅色／深色覆盖，随主题保存与分享。旧主题深色缺省 0.6，浅色保留原面板不透明度的一半 |
| `borderOpacity` | 0～1 | 玻璃和填充控件的边框强度 |
| `controlShadow` | 0～1 | 填充式中性按钮的阴影强度 |
| `controlStyle` | `outlined`、`filled` | 描边沿用基础控件；填充提供柔和按钮、分段选择、导航选中态和输入焦点，语义色不变 |
| `highlight` | 0～1，参考 0.5 | 玻璃边缘与交互高光强度 |
| `shadow` | 0～2，参考 1 | 公共面板与玻璃导航的阴影强度 |
| `refraction` | 0～24，参考 0 | px，玻璃边缘下的背景位移；0 为关闭，仅支持 SVG 背景滤镜的浏览器生效 |
| `duration` | 100～400，参考 180 | ms，共用控件过渡与窗口入场时长 |
| `motionCurve` | `smooth`、`spring` | 平滑或轻微回弹的过渡曲线，不是物理弹簧模拟 |

基础偏好仍有明确优先级：`fontScale` 在高级根字号上按 15/16、1、17/16 缩放；`density` 以 0.9、1、1.1 缩放高级间距、控件和工具栏高度。选择基础圆角会清除共用及明暗版本的三个高级圆角覆盖，重新应用已保存主题可恢复。修改基础强调色会清除两套版本强调色覆盖，避免操作被隐藏覆盖；高级编辑器仍可单独设置。实色材质关闭玻璃；减少／关闭动效和系统减少动效设置优先，不播放按压缩放或鼠标光照追踪。触屏与窄屏保持至少 44px 的共用控件命中高度。

玻璃用于侧栏、工具栏、导航和公共弹层，内容卡片继续保留清晰表面；鼠标追光限于中性按钮的小范围反光、侧栏与工具栏的弱反射，大面板及内容区仅保留固定高光；嵌套的设置／操作窗口不重复堆叠玻璃。玻璃／磨砂设置窗口由外框统一承担材质，正文不再铺实色画布，玻璃窗口使用轻遮罩保留背景颜色、减少透明度时恢复较强遮罩；六个设置分类及其嵌入模块（密钥、预算、实验室、助手、隐私和维护）的中性内容分组通过 `appearance-group` 共用薄透底色，已有面板及主题卡片沿用同一规则；选中态保留强调色，开关滑块、进度轨道、警告和成功色保留语义；玻璃输入框沿用面板基色，避免把带色画布染回控件。实色模式保留原有正文与分组底色。背景先模糊扩散，再在边缘窄带内折射，配合上亮下弱的玻璃边缘与近远两层投影；大表面的固定反光收在顶部 36px 内，其余区域由真实背景提供自然冷暖过渡，不铺整面低亮度灰阶渐变、不叠加人工噪点或磨砂纹理；边缘高光和真实背景透色保留。嵌套区域不重复叠加反光，普通工具按钮保持透明，悬停时出现小范围反光；追光独立绘制，不改变原有范围及强度。玻璃中的中性按钮常态透明，输入框、选择器和多行输入采用薄透底色，不额外堆叠背景模糊，也不以实色填充盖住所在表面的环境颜色；实色／磨砂控件保持原样，减少透明度和模糊不可用时输入恢复实色。SVG 折射只处理背景，不处理文字、图标、作品或 Canvas 内容。浏览器不支持背景 SVG 滤镜时保留普通玻璃模糊与高光；减少透明度或不支持模糊时使用实色表面。原生 Apple 材质、字体栅格化、连续曲率与 SF Symbols 不由 JSON 主题引擎复制，作者应在真实设备上微调。

共用工具栏与锚定菜单按实际尺寸和圆角生成背景透镜，长工具栏不会把折射边缘拉成宽色带；只在挂载、尺寸或主题变化时更新，不读取作品像素。中性按钮与主操作按钮共用薄表面反馈，保存／危险色保持原义；菜单内边距随内外圆角协调，紧凑菜单保留原间距。所有主题的共用菜单从触发位置展开，贴边避让和向上展开仍指向原按钮；玻璃材质进一步调整展开形态，缩放期间保持普通玻璃、落稳后接回边缘折射，避免浏览器同时合成 SVG 透镜和缩放时的空白帧。`duration`／`motionCurve` 继续控制速度与曲线，减少／关闭动效及系统减少动效时停用。上述能力由组件和材质类型决定，与预设名称无关，旧格式无需增加字段。

透镜的滤镜区域与贴图尺寸均使用表面的实际像素尺寸，不使用按百分比拉伸的全局默认透镜；没有专用透镜的表面保留普通背景模糊。动态追光使用唯一、无滤镜、不接收点击的临时层，不修改玻璃节点的背景或追光属性；位置与圆角跟随命中表面，切换目标、离页、滚动、点击、键盘操作、焦点切换、视口变化和页面隐藏时清除，并取消待执行帧。玻璃／磨砂的画廊、实验室、统计、主题及中性内容卡片不加常态外描边；选择与键盘焦点继续使用各自的状态提示。

给其他 AI 制作苹果风格主题时，可直接复制[主题生成提示词](./THEME_AI_PROMPT.md)。项目自带 [Cupertino Liquid Glass](../public/themes/cupertino-liquid-glass.json)，包含两套配色及材质覆盖，选中作品聚焦、全图磨砂卡片与卡片悬停浮动均开启；内置参数与公开 JSON 共用同一份原件，支持直接选用、导出或另存副本。已有同名自定义主题保留。

## 可读性与预览

主题卡片每个预设占一整行，以完整工作区展示保存的浅色、深色整体效果：侧栏、四种创作模式顶栏、编辑分区、提示词、作品预览及生成操作一起呈现配色、几何和分层透明度。预览保持 960 × 600 的桌面构图并随可用宽度等比缩放，不在窄屏删减区域；卡片宽度达到 960px 时并排对照明暗，空间不足时上下排列。内部均为静态示例，不读取私人草稿、不执行请求或触发操作，点击卡片仍按原入口应用主题。普通中性按钮只使用弱顶缘反光，悬停及展开再增强；选中块使用稳定底色，导航与筛选的选中前景、背景共同优先于分组材质。

高级主题的常用操作与字段标签以 13px 相对字阶为下限，次要元信息保持独立；`strongWeight` 作为半粗体基准，粗体和特粗体分别增加 100／200，最高 900。玻璃顶栏不额外绘制固定渐变遮罩或向内容区延伸的色带；独立文字菜单至少使用 82% 面板色承托，其他窗口、导航和内容的既有透明度保持各自含义。配色编辑器分别检查正文、次要文字与面板及工作区背景的对比度；检查不代替复杂图片背景的实际观察。系统增强对比度和强制颜色优先于主题状态，提供明确的选中边界、焦点与禁用样式，作品和编辑画布不参与换色。

## 兼容与范围

支持版本 1、版本 2、版本 3，以及旧版的单主题对象／主题数组。新导出统一使用版本 3；未知版本、错误选项、错误颜色和不支持的字段会报错，整份文件不会部分导入。暖纸示例保留版本 2，验证旧格式可继续使用。旧文件缺少新字段时继续使用默认值。

主题基于现有布局和语义颜色制作，不执行 CSS、JavaScript，不加载远程字体、图片或代码。保存、危险与来源颜色、作品像素、安全模式和触控区域保留原有含义。电脑主界面、手机界面使用同一套主题；Windows 收集小窗采用单个 WPF 窗口，不做桌面取样。背景与主界面共用按预设、明暗版本解析的本端覆盖及默认资源，支持自选图片、显式移除、旧单背景回退、铺满／完整显示／平铺、背景强度和平铺尺寸；默认主题仍使用纯色。主题全局／侧栏不透明度、模糊、饱和度、玻璃折射、控件／面板圆角、边线和高光原样同步，不设独立材质参数、55% 承托下限或 14px 圆角上限。原生端按窗口实际尺寸和 DPI 合成图片，先模糊与饱和度，再沿与网页相同的圆角法线及位移强度折射边缘，中心内容不扭曲；折叠及明暗切换原位重算。整窗共用一层玻璃，按钮不重复模糊或折射背景；选中项采用沿用主题强调色与透明度的凸起玻璃滑块，反光、边线及轻阴影取自主题高光、边框强度与控件阴影，普通按钮仅在悬停时显露反光和亮边，移出／禁用／切回实色时清除。窗口内部保持不透明，主题透明度只控制主题色与背景图片的混合；文字对比不足时仅在相应字串后增加局部承托，不暗中提高整面透明度或替换主题文字色。自选图片不落盘，显示副本最长边 1280px，普通图片以 JPEG 85% 质量压缩，含透明通道的图片保留 PNG；原件和浏览器选择不改动。原生图片通过 stdin 传递，收集状态更新不重复携带图片，状态广播只带显示参数；图片缺失／损坏时保留画布底色，高对比度使用系统实色。固定尺寸、拖动、折叠、收集协议、不抢焦点与程序集源码缓存保持原约定。

主题库保存于当前工坊后端，Edge、内置浏览器和局域网手机访问同一工坊时共享列表；当前选用的主题、未保存的外观修改和其他设备偏好仍各自保存。打开设置或回到页面时重新读取共享列表；新增、覆盖保存、重命名和删除按单条主题操作，不以旧浏览器缓存替换整库。删除从所有浏览器的主题列表移除；发起删除的设备若正在使用该主题则恢复默认，其他设备保留当前外观，可另选或另存。

旧浏览器主题在首次打开设置时合入共享库，上传成功后才记住完成，原本地文件内容另留浏览器回退副本。相同 ID 不覆盖共享原件；发生冲突时保留旧版本副本，服务端记住来源，重试或其他旧浏览器不会把已迁入后删除的主题重新上传。加载失败保留本端缓存；写入失败保留草稿并提示重试，不显示保存成功。

共享主题复用 D1／Android SQLite 的既有 `settings` 表，使用 `appearance_preset_v1:` 和合入来源记录，不新增表或修改存储键。工坊完整备份随数据库保留主题；跨独立工坊分享仍使用 JSON 导入导出，独立 Android 不与电脑隐式同步。
## 材质覆盖约定

半透明主题下，所有主页面的顶栏及相邻状态行由 `WorkspaceChrome` 统一测量实际高度，滚动内容从其背后经过，首屏按同等高度留白。列表与实验室保持各自滚动容器，分类导航和手机分栏一并避让；桌面固定侧栏／详情留在顶栏下方，手机全屏详情沿用原边界。滚动区域的 `scroll-padding-top` 同时用于键盘定位、作品居中和返回目标判断；实色主题保留原布局，不增加滚动监听、追光或滤镜。

全局不透明度在「个性化 → 控件、排版与玻璃细节」顶部调节，数值越低越通透；当前苹果预设为 60%。全局覆盖只改变表面底色，实验室内隔离该变量，图片和文字保持清晰；减少透明度／高对比度仍优先。作品详情整卡使用透明内容容器，图片使用独立衬底，提示词和参数使用薄填充，不能把整张图文卡标为图片或额外叠一层实色。

实验室按已确认效果稿采用连续轻透编辑面：文生图与三种图片编辑模式均在左侧内容外使用唯一的 `lab-editor-surface`，从首栏（默认全局提示词）延伸到最后一栏；单层细轮廓包住全部编辑内容，各 `lab-module-section` 及标题透明，输入薄填充，内层不叠加卡片或背景模糊。编辑面独立使用 `labEditorOpacity`，在「个性化 → 控件、排版与玻璃细节」顶部调节；当前苹果预设深色 60%、浅色 30%，调整不影响弹窗、侧栏、顶栏或右侧预览，字段使用 32% 局部填充；提高可编辑文字、占位提示、标题与可用强调操作的对比度，禁用状态保留弱化，浅色版维持轻透程度。底部安全留白使用面板外间距，避免暗面延伸到空白区域。该规则覆盖旧的模块 90% 阅读底色；侧栏恢复独立玻璃，`chain-editor-workspace` 及左右栏底板透明，不在整页或侧栏与工作区的共同外层铺暗面。空预览开放显示柔化背景及简短提示；作品预览不铺中性衬底，透明底作品直接透出背景，不再绘制棋盘格；作品像素、编辑画布和点击大图保持原义。占位提示与次要文字使用清楚的明暗色阶，生成模式选中项及生成主按钮使用强调色填充和对应前景色；独立进度控件仍保留阅读底色。电脑／手机生成操作区不铺整行底板、不加额外内边距；可读性由主按钮填充和进度按钮自身的阅读底色承担，不额外叠加模糊滤镜，手机预览缩略图仍按图片处理。整行开关底板通过 `appearance-group` 参与材质，轨道和滑块保留原状态色，不能因 `role="switch"` 将整个控件排除出覆盖检查。

玻璃／磨砂主题共用同一套材质，不按预设名称分支。全局背景贯穿页面，页面根底板和 `appearance-content` 透明，实验室仅在上节规定的左侧实际编辑范围承托；导航、内容与背景保留各自边界。独立 `appearance-group`／`appearance-surface` 分组承载内容材质，`appearance-panel` 承担浮层材质，内层分组与普通控件仅作薄填充，侧栏底部额度／安全模式／设置胶囊也遵守同一规则，避免双层玻璃叠成黑条；嵌套窗口不重复模糊。实色主题沿用原有底色。普通中性按钮、分段选中项也透底，强调、保存、危险、禁用及开关状态保留可辨识含义。

所有主题的卡片不画常态或悬停装饰边／阴影，也不在图片和信息区之间保留分隔线；选中与键盘焦点外圈保留。玻璃／磨砂图片卡片自身透明且不做背景滤镜，材质放在非叠图的信息区；启用磨砂标题时沿用既有叠图渐变，历史手机日期栏单独承载底色，避免整卡底色在图片圆角边缘露出亮边。

图片／画布衬底用 `appearance-media` 标明；高对比提示及反色操作用 `appearance-contrast` 标明。这两类不进入通用透光覆盖；作品预览不铺衬底，透明底作品直接透出背景，也不绘制棋盘格，蒙版、画布坐标、加载轨道、作品像素和状态遮罩沿用原有规则。空结果区单独使用薄透底色。图库标题仍服从既有磨砂卡片开关。

覆盖范围包括实验室四模式及提示词／角色／参数／预览、风格串、画师／角色库、收藏库、提示词库、Roll、历史、创作足迹、外部来源页、助手、六类设置，以及共用选择器、资料管理和导入／确认弹层。`tests/integration/AppearanceCoverage.test.tsx` 扫描全部组件 JSX 的中性底色，缺少材质语义或明确用途的新增容器会回归失败；表单与 house 控件由共用规则接管。
