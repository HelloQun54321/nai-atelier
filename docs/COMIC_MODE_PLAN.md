# 漫画创作模式施工文档

> 本文件为 NAI Atelier「漫画创作模式」独立施工蓝图。四期全部开发并验收完成后，再将稳定约定精炼汇总至 `docs/PRODUCT_DECISIONS.md`；在此之前不修改总产品决策文档。

---

## 一、定位与核心边界

- **模型范围**：仅支持 **NovelAI V5 系列模型**（`V5 Full` 的 `High / Medium` 档位与 `V5 Curated` 可切换），默认使用 `V5 Full (High)`；完全独立于生图实验室草稿，绝不暗改实验室的当前模型、参数或提示词。
- **工坊能力复用**：直接复用现有风格串库、角色库（自定义 + Danbooru 词库）、提示词库（含 `@名称` 联想检索）、统一后端单并发队列（`generationJob` / `generationSeries`）、多 Key 池自动轮询与 Opus 免费额度守卫（常规免费出图，需消耗 Anlas 时必须显式确认，绝不静默扣费）。
- **双模式并存与职责边界**：
  1. **手动分镜逐格精控**：画布矢量分镜框提供像素级精确裁切（自由拉框、两点一刀切分、斜角调整、叠框、旋转、吸附）；选中单格独立设词与选配锚点，按单格长宽比自动匹配 Opus 免费分辨率逐格生图并裁切填入，支持画内拖拽缩放构图。
  2. **AI 整页锚点一图成型**：对接「创作助手」当前已配置的大模型进行分镜剧本编排，花额度前提供可视化预览画布；参考分镜框以「半透明构图与锚点引导区」呈现，不承诺像素级贴合任意大斜角异形框；支持整页成图后的**单格局部重绘**（重绘内同样支持锚点定位）。
- **历史与保护**：
  - 逐格单格生图与整页生图均走统一生成链路并落入「生成历史」；
  - 点击「导出整页 PNG」时，既下载到本地（遵循工坊默认导出与分享设置），也同步归档一份整页合成成品至生成历史（来源标记为 `comic`），便于收藏、回看与回收站引用保护。

## 二、界面布局与导航入口（已确认）

1. **桌面端入口**：左侧导航栏「工作区」分组新增「漫画」（与风格串、实验室、Roll 串并列）。
2. **手机端入口（`<768px`）**：遵循「手机底栏固定 5 格不加位」原则，参照风格串→Roll 串、历史→创作足迹的成对做法，在**实验室顶栏**新增「漫画」直达图标（进入漫画后顶栏提供返回/切回实验室入口）。
3. **桌面工作台排布（PS 4 列专业骨架：全局导航 | 满高竖工具栏 | 点阵绘图桌画布 | 右侧平铺三标签工作台）**：
   - **顶部主栏与动态工具属性栏**：左侧放页面标题、「手动逐格 / AI 整页」模式切换与规格/模板入口（`V5 档位 · 色彩 · 画幅 ▾`，点开修改模型、黑白/彩漫、对白策略、自定义宽高与套用分镜模板）；中间为仿 PS 动态工具属性栏，随左侧工具切换实时展示画笔粗细/透明度/颜色、气泡框形/横竖排、贴纸样式、一刀切缝留白或格内构图缩放；右侧放撤销/重做、导出 PNG 主按钮与右侧栏收起开关。
   - **满高停靠式竖工具栏**：贴靠在全局导航右侧，上下贯通停靠（含单键快捷键）：导航选择组（选择 `V` / 抓手平移 `H` / 缩放镜 `Z`）、分镜排版组（自由拉框 `R` / 一刀切分 `C` / 格内移图 `M`）、嵌字装饰组（气泡 `B` / 自由文字 `T` / 贴纸 `S`）、手绘修饰组（画笔 `P` / 橡皮 `E`）及底部前景色块；窄屏/手机自动折为顶部单行滚动条。
   - **中央点阵绘图桌漫画区**：微弱点阵底纹承托画纸，默认饱满自适应缩放，空白画格带左上角 `01 / 02` 分镜角标；采用防顶部/左侧截断的居中滚动容器，支持 `Ctrl+滚轮` 缩放、抓手/空格/中键平移，右下角保留迷你「吸附 + 缩放 + 适应屏幕」悬浮胶囊。
   - **右侧宽敞三标签工作台**（`416px～440px` 宽屏舒展排版，可收起，兼容同时停靠创作助手；平铺式无套娃边框与克制微色点控件）：
     - **`分镜生图`（默认首页）**：顶部常驻横向格号切换条（`[1 ✓] [2] [3] [4] [+]`），直接编辑当前格画面描述、`@` 提示词库与角色库引用、四类空间锚点与折叠式样式/构图微调，底部固定「生成当前格」按钮及自动免费分辨率/费用状态。
     - **`画风设定`**：可搜索风格串载入、全页公共画风正负面词，以及紧凑版 V5 模型、色彩模式与对白策略配置。
     - **`嵌字·图层`**：集中管理当前选中的气泡/文字/贴纸排版属性与页面嵌字清单，以及 4 大图层的显隐、锁定与上下排序。
4. **手机端轻量化适配**：保留页面查看、选格改词、一键生图、切换模板、基础气泡改字与导出 PNG；复杂的自由斜角顶点微调、两点斜切与精细图层笔刷收简或引导桌面精修。

## 三、核心创作机制（基于 V5 49 张实测锁定）

### 1. 四类全能空间锚点与红绿灯护栏
- **四类可拖拽圆点**：
  1. 🔵 **角色锚点**：人物站位、动作、表情、景别与该格环境光影；同一人物跨多格出场必须拆为多个独立锚点槽（禁止单槽塞多坐标）。
  2. 🟢 **空镜 / 道具锚点**：无人空镜格的场景主锚点，或有人格内指定角落物件的落点。
  3. 🟡 **气泡锚点**：定位气泡在画面中的坐标、框形（椭圆 / 锯齿吼叫 / 云朵思考）与尾巴指向。
  4. 🟣 **特写叠框锚点**：在大主格角落叠加画中画小特写（眼眸 / 手部 / 关键物件）。
- **槽位上限与分镜密度护栏**（针对单次发送给 V5 的每张生图请求）：
  - **手动逐格模式**：每一格独立生图，整页总格数不设 AI 画质硬上限（画布防卡顿软上限 24 格）；单格独享「推荐 ≤12 槽、硬红线 ≤24 槽」（单格也可 0 锚点自动构图，日常 1～5 个点最顺手）。
  - **AI 整页模式**：同一生成区内的所有格子共享一次生图的面积与槽位名额——竖版单区推荐 **1～4 格（最多 5 格）**，横版跨页单区可至 **6 格**；槽位总数 **4～12 槽**为全精正剧画质甜点区，超限（格数过多或槽位 >12）时给出温和提示并支持一键自动拆分为「上下 / 左右双区」分别免费出图再拼页；单次请求硬件发送硬拦截 **≤24 槽**（超过网关将 `422` 拒收）。
- **后台自动防踩坑规则**：
  - **防幽灵克隆铁律**：若某格内已存在角色锚点，后台编排严禁在该格另建独立 `no humans` 纯背景槽，自动将背景/环境描述并入该格角色锚点。
  - **黑白网点漫自动净色**：选择「黑白网点漫」时，仅对发送给 V5 的临时副本自动剥离角色词中的纯色相词（红/蓝/绿/紫/金等），并在角色负面与全局负面同步压制色彩、清理官方预设中压制 `screentone / halftone / multiple views` 的冲突词，**绝不改动用户角色库或风格串原资料**。

### 2. 三选一对白文字策略（砍掉外部导入漫画去字与重型 OCR 包）
生图前由用户自由切换：
1. **AI 直出带字**：通过独立气泡锚点将 2～6 字短台词或漫画拟声词（`Text:`）直接融入画风绘出（独立槽定位可避免跨格串台）。
2. **空白气泡 + 后期嵌字（AI 整页推荐默认）**：指令 V5 直出带指向尾巴、自动避让人物脸部的纯白无字对话框，出图后纯本地毫秒级识别纯白气泡区域，按锚点坐标自动落入可自由改字、换字体、调横竖排的可编辑文字层。
3. **无气泡纯画面 + 画布矢量气泡**：指令 V5 输出零气泡纯净画面，全部气泡与文字由画布矢量工具自由添加排版（同时省出气泡锚点名额）。

## 四、四期落地计划

### 第一期（已完成）：分镜画布工作台 + 手动逐格 V5 生图
打通完整画布底盘，立刻可以画漫画、改词逐格生图并导出 PNG：
1. **导航与视图骨架**：桌面侧栏「工作区 → 漫画」、手机实验室顶栏「漫画」入口、`App.tsx` 保活视图接入与五语基础文案。
2. **数据模型与跨重启自动留稿**：
   - 定义漫画页面数据结构（画幅尺寸、纸张底色、分镜框多边形/旋转/层级/裁剪与图片平移缩放、单格提示词与 V5 参数覆盖、单格空间锚点、手绘涂鸦层、矢量气泡/文字/贴纸层、图层可见性与锁定）；
   - 独立本地持久化自动留稿（不影响实验室草稿，支持跨刷新/重启恢复当前工作页）。
3. **交互式分镜画布引擎**：
   - 纸张比例预设（日漫竖页 `832×1216` / 横版跨页 `1216×832` / 竖条漫 `832×2048` / 自定义）与常用分镜模板一键初始化（单格、四格、经典 3/4/5 格、L 型、画中画叠框）；
   - 自由拉框新增分镜格、两点一刀切分现有分镜格（支持水平/垂直/任意斜切并自动保留留白间距）、拖拽四角顶点调斜角、整框移动/旋转/缩放/层级置顶叠框、网格与边缘吸附；
   - 完整撤销 / 重做历史栈、画布缩放/平移/一键适配视口。
4. **单格 V5 生图与工坊深度打通**：
   - 全页画风配置直接引用现有风格串、切换 V5 模型（`V5 Full High / Medium`、`V5 Curated`）与全彩漫 / 黑白网点漫模式（含发送副本自动净色与去冲突词）；
   - 选中单格可编辑正向/负面词（复用 `TagAutocompleteTextarea` 支持 `@` 提示词库与 Tag 补全）、从角色库直接添加角色锚点、在单格预览区拖拽定位四类锚点（受 ≤24 硬上限护栏保护）；
   - 根据选中分镜格实际外接比例自动匹配最贴近的 Opus 免费分辨率（64 像素对齐，≤1,048,576 像素），通过工坊统一后端单并发队列与 Key 池发车（含费用变更守卫、实时阶段状态、取消/暂停与自动落入生成历史）；
   - 生图完成后自动裁切填入对应分镜框（支持鼠标拖拽与滚轮微调图内构图偏移与缩放，也可从生成历史直接选已有图片填入任意格）。
5. **基础后期图层与导出**：
   - 图层面板（分镜框层 / 手绘层 / 气泡与文字层 / 贴纸层，支持显隐、锁定与顺序切换）；
   - 画笔 / 橡皮（调粗细、颜色、不透明度）直接在手绘层作画；
   - 矢量气泡（椭圆 / 吼叫 / 思考 / 旁白方框，可调尾巴指向、边框粗细与底色）、可编辑横竖排文字、内置漫画常用贴纸/效果贴图（集中线、汗滴、怒筋、星芒、惊叹号等）；
   - 导出整页高清 PNG：使用离屏画布将所有可见图层（含精准多边形裁切、手绘笔迹、矢量气泡文字与贴纸）按原画幅合成导出下载，并同步归档一份整页成品到「生成历史」（`source: 'comic'`）。

### 第二期（已完成）：AI 整页锚点编排与一图成型
- **AI 分镜编排接入创作助手大模型**：后端新增 `POST /api/prompt-agent/comic-storyboard`（未重启旧后端时前端自动回退既有重写通道），复用用户已配置的创作助手服务商、代理与角色库外观，输入剧情、目标格数（3/4/5/6/8 格）与出场角色即可一键输出半透明构图引导区、四类空间锚点（角色 / 空镜道具 / 气泡点 / 特写叠框）与备用台词（0 生图额度，不污染助手对话记录）。
- **花额度前可视化预演与整页直拖微调**：中央画布实时展示半透明虚线构图引导区、带标签/台词预览的可拖拽四类锚点，以及双区拆分时的红色虚线拼接缝与每区免费分辨率标牌；支持角色库补点、`Delete` 删点、撤销重做、显隐引导层与「气泡点一键转矢量嵌字」。
- **12/24 槽护栏、自动双区免费出图与无缝拼合**：按横竖画幅与槽位密度自动决策单区直出或拆为「上下双区 / 左右双区」分别走 Opus 免费分辨率出图（每区严格执行总词不剧透、有人格防幽灵克隆合并背景、黑白网点发送副本净色与三选一对白编译），双区出图完成后在本地无缝拼合为完整原画幅整页成品并自动归档至「生成历史」，成图后可直接叠加手绘、矢量气泡文字与贴纸并导出 PNG。

### 第三期（已完成）：三选一对白闭环 + 单格局部重绘
- **纯前端纯白气泡连通域自动识别（`comicBubbleDetector.ts`）**：离线像素连通域分析自动剔除页面外缘白边与细长格缝，精准定位内部纯白气泡并就近匹配剧本气泡锚点台词，生成透明无框高清可编辑文字层贴入原生气泡（支持双击改字、横竖排与透明气泡导出）。
- **整页直出成图单格局部重绘（`comicInpaintEngine.ts`）**：支持一键对齐引导格或在画布自由拖拉/缩放红框重绘区，配置重绘强度、聚焦放大（Focused）及重绘区内独立角色/物件锚点，走统一 `operation: 'inpaint'` 队列与像素级回贴链路（含 Opus 守卫、付费确认与 `Ctrl+Z` 撤销）。

### 第四期：两级漫画书架、整话阅读与回收站保护闭环
- 后端 D1 持久化「漫画作品 / 话 → 页序列表」两级书架（默认自带「速写单页集」），支持拖拽排页、复制页、整话连续阅读与批量打包导出；
- 接入历史回收站引用保护，防止已被漫画页引用的单格原图或整页成品被误清。
