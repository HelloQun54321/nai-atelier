## 1. 共用界面、窗口与全站基建

### 1.1 顶栏与导航
- **「以搜索框为界，左看右管」全站同构**（Pixiv 保留原双层导航特例）：左侧聚合浏览与筛选（文件夹／来源／范围切换／筛选／跳页），搜索框尾部内嵌结果计数徽标（桌面单行显示 `已加载 / 总数` 或单值，千位 `k`／百万 `M`，手机隐藏；回收站、Pixiv 等无搜索框页保留独立竖排徽标），右侧聚合管理与执行（多选／新建／抽卡／主操作／更多操作）。
- **禁止动态顶动布局与空洞长横条**：选中卡片时顶栏保持静止，不得动态插入按钮挤动搜索框，也不在顶栏下方叠加全宽横条（设置分组并入底部 `TagSelectionBar` 或常驻禁用钮；画师库模型切换与随机「返回完整目录」收进筛选面板／结果底部；实验室补充样张提示用底部紧凑短胶囊）。筛选按钮激活数量使用定宽右上角标。
- **更多操作与多选顶栏**：全站「更多操作」统一用纯图标竖三点（`MoreVertical`，桌面锚定浮层、手机底部面板，接入 `data-appearance="control"`）。多选模式原位替换顶栏，固定顺序为「已选计数 → 全选／反选／清空 → 业务批量动作 → 右对齐危险操作 + 退出多选」。
- **搜索框内筛选胶囊**：已选条件在搜索图标后单行排列，关键词输入紧随其后；宽度不足收折为 `+N`（点击打开原筛选面板），不换行、不横滑。玻璃材质下底色由搜索容器承载、输入框保持透明。
- **可收起顶栏把手**：所有主页面顶栏共用收起把手（桌面居中于顶栏上缘，手机 `<768px` 移至顶栏最左同行等高），状态跨页面保存在本端浏览器。手机顶栏禁止横向滑动与换行叠压，长文案只进 `aria-label`／`title`。
- **桌面侧栏与手机底栏**：桌面侧栏将 AITag、法典、Danbooru、Pixiv 归入默认折叠的「素材浏览」组（记住展开偏好，收成图标栏时点按弹紧凑菜单）。手机底栏固定五个入口，不为单页加位：Roll 串并入风格串页（顶栏骰子进入，`<768px` 显示），创作足迹并入历史页（顶栏脚印进入，`<768px` 显示），外部图源收进资源库面板第二层。

### 1.2 列表加载、瀑布流与共用目录树
- **连续加载与读取三态**：可浏览列表接近滚动末尾（瀑布流按任一短列末尾）时自动分批追加直至真实末尾，不设 200／800 固定上限；能真跳页的列表（历史、AITag、法典）将跳页放顶栏。严格区分加载中、失败重试与真实空结果（未知数量显示 `—`，不当作零或空）；整页首读用居中 `PageSpinner`（文案统一「加载中…」），局部用 `InlineSpinner`，禁止裸文字或骨架屏。带侧栏页面的空态按正文可用宽水平居中。保活页面保留草稿、筛选与滚动位置。
- **共用瀑布流与列数偏好**：首帧绘制前同步测宽分列；图片真实尺寸返回后**仅重平衡视口下方尚未浏览的纯尾部**，已浏览卡片不搬列；少量删卡保留其余卡片所属列并回填视口上方滚动位移；主动改搜索／筛选／排序才回顶重分列。提供全局默认及 10 个图库页面的独立布局（瀑布流／竖向／方形）与列数设置（桌面 1～7 列、普通最小卡宽约 180～200px，Roll 自动布局约 220px 且最多 4 列；手机 1～3 列）。
- **共用筛选浮层规范**：全站浏览页与弹窗的「筛选」浮层统一复用 `ToolbarPopover` 共用原语（`TOOLBAR_LABEL_CLASS` 12px 灰字标题、`TOOLBAR_FIELD_CLASS` 统一字段框、`FilterToggleButton` 统一圆角切换芯片、`FilterPanelFooter` 左重置＋右辅助／应用底栏）；宽度按复杂度分三档（标准 `320px`、含时间／标签／多下拉的复杂面板 `360px`、AITag 宽面板 `480px`），不再各页手写复选框、大蓝条或散落重置按钮。
- **共用目录树与正交「只看收藏」筛选**：风格串、画师／角色分组、提示词片段与收藏夹统一复用目录树组件：标题栏固定新建／编辑／删除，仅下方树列表单层滚动；桌面按需展开左侧栏（支持拖拽子树移动），手机点文件夹图标直接打开完整路径底部面板（不再经中间路径条或原生 `<select>`）。父目录汇总后代并按对象去重，删除目录仅解除本节点关系并提升直接子目录，不删作品。**「收藏」归属筛选维度而非文件夹**：风格串、画师库（含 Roll 画师弹窗）、角色库与提示词库（片段／组合／片段管理）均移除左侧目录树内的虚拟「收藏」节点，统一在顶栏「筛选」浮层首位提供「只看收藏」开关（按现存对象去重，换封面仍保留收藏状态），支持任意文件夹／分组与「只看收藏」正交叠加；旧本端持久化的 `#favorites` 选中状态自动回退「全部」。

### 1.3 卡片展示、弹窗层级与界面文案
- **卡片视觉与聚焦**：默认开启「全图磨砂卡片」与「卡片悬停浮动」（移除易导致误触的「卡片指针倾斜」）；资源图库默认开启「选中作品聚焦模式」（选中或看详情时其余卡片压暗至 70% 并平滑垂直居中，生成历史多选不套用）。所有主题的浏览卡片不画常态／悬停装饰边框或图文分隔线。
- **悬浮按钮显露与性能红线**：图库卡片悬浮圆钮（千级节点）**禁用 `backdrop-filter`**，统一用 45% 黑底＋白边＋白图标，语义色仅在悬停／聚焦／按下时显现（`IMAGE_CARD_ACTION_TONE`）。**图上常驻状态色仅限三处**：已收藏的玫红实心爱心（右上首位）、已屏蔽画师的红色实底按钮（左上）、已保存／已收录的翠绿对勾。其余辅助操作在桌面靠鼠标悬停／键盘聚焦原位显露（右上竖排「收藏 → 下载 → 复制 → 附加动作」，左上管理／删除）；手机与触控笔（`<768px`，桌面窄窗右键等效）长按约 450ms 弹出底部同款操作面板（详情与大图在手机上改用底栏常驻操作）。
- **窗口尺码与层级分档**：管理、选图、反推、导入與设置使用居中固定外框小窗，内部滚动；原生 `<select>` 展开项强制使用当前主题实色面板与正文色，防玻璃透明底导致浅底白字。层级严格分档：内容窗口 `1200～2000`，嵌套目录编辑／锚定浮层／手机底部面板 `2100`，全局提示 `2300`，确认框 `2400` 最高。桌面停靠助手为非模态，Esc 优先让位其他可见窗口；手机覆盖层逐层返回。
- **当日免确认记忆**：所有确认弹窗（删除、费用、迁移、恢复）提供默认不勾选的「今日内不再显示」，按本端本地自然日与具体操作／Key／风险范围隔离记住；离开编辑器提供「放弃并离开（红底）／继续编辑／保存并离开（绿底）」，记住保存后仍每次执行真实保存。内置助手不得代用户勾选当日授权。
- **界面文案克制（禁止堆叠说明文字）**：优先靠清晰的按钮名、标签名和控件显隐状态表达含义，**禁止在按钮、开关、输入框旁堆叠多行说明**。明确拒绝四类冗余文案：① 解释显而易见交互或常识的废话（如「改错了就撤销」「勾选后下面收起」「修改只影响下次生成」「点眼睛查看明文」）；② 防御性免责复读（如反复声明「原图与历史保留」「不修改原资料」「不消耗生图额度」「扣费前照常确认」）；③ 相邻位置或不同入口重复提醒同一件事；④ 面向用户的常规面板暴露本地目录路径、开源协议编号、算法细节或运维排错步骤。仅在真正涉及扣费、第三方外发隐私风险（如中转发送 Key／提示词）、数据丢失或硬上限时保留一行简短提示；少数非显而易见的低频规则收进 `InfoPopover` 或悬停 `title`，不常驻占位。
- **全站图标语义规范（一义一图、一图一义）**：相同动作跨作用域统一图标，不同语义严禁撞图；结构／模式主控件带文字，卡片与输入框辅助工具条整排统一纯图标加 `title`（不在纯图标尾部单独给「复制」挂文字）。固定映射如下：
  - 保存完整资产（风格串／角色）用 `Save`，摘录单栏提示词片段进词库用 `BookmarkPlus`；
  - 从提示词库取用统一 `Library`（与侧栏同源），从角色库取用用 `UserRoundSearch`（避免同屏与词库撞图）；
  - 清空内容（保留槽位／清词／清蒙版）用 `Eraser`，删除实体或进入删除模式用 `Trash2`（常态中性，悬停／激活标红），关闭浮层或解绑单张封面／附件用 `X`；
  - 撤销／重做统一 `Undo2`／`Redo2`，`RotateCcw` 专职重置当前模式／恢复默认；
  - 从图片反推 Tag 统一 `ScanSearch`，`ImagePlus` 专职上传底图／添加封面；
  - AI 提示词整理与生成搭配统一 `WandSparkles`（淘汰 `Wand2`），`Sparkles` 专职创作助手入口；Tag 校对 `SpellCheck`，AI 翻译 `Languages`，复制 `Copy`（纯图标，正负与角色栏一致），导入 `Download`／选文件 `FolderOpen`／剪贴板 `ClipboardPaste`，随机搭配 `Dice5`，屏蔽 Tag `EyeOff`，更多操作全站统一 `MoreVertical`，排序 `ArrowUp`／`ArrowDown`，折叠 `ChevronUp`／`ChevronDown`。

### 1.4 语言、外观、隐私分享与本地维护
- **五语界面**：内置简中（默认）、繁中、英、日、韩字典，即时切换界面与 Windows 托盘／安装器文案，助手下一轮跟随；绝不自动翻译改写 Prompt、Tag 或私人资料原文。README 提供五语入口。
- **外观与主题共享**：内置 `NAI Atelier 默认`（出厂默认：白天浅色、晴空蓝 `#0d8bf2`、透光材质、标准密度／圆角／字号、完整动效，默认开启图库聚焦、全图磨砂卡片与卡片悬停浮动）与 `Cupertino Liquid Glass`（液态玻璃）；主题预设只切换配色、表面材质与高级材质细节，**强调色（所有主题明暗统一遵循用户选择，出厂默认第一个晴空蓝 `#0d8bf2`，不再允许主题按明暗单独覆盖）**、明暗模式、界面密度、圆角语言、字号、动效与图库三开关均作为通用显示偏好在切换预设时保持不变（仅「恢复出厂默认外观」一并重置）。主题库在同工坊后端共享，当前选用主题与「预设 ID × 明暗」工作区壁纸覆盖按本端独立保存；Windows 收集小窗采用单 WPF 窗口内存合成壁纸与玻璃折射，不做桌面取样。参数细节见 [THEMES.md](./THEMES.md)。
- **图片分享与元数据清洗**：图片下载按钮支持在「隐私与分享」切换导出 PNG 原图或 `.json` 生成信息（优先从 PNG 内嵌普通／stealth 元数据提取）。元数据清洗默认关闭，独立于安全模式；开启后可选「全部生成信息」或「仅提示词（保留真实参数）」，支持写入自定义文本，仅作用于分享副本，失败绝不静默回退原图。「启动时自动开启安全模式」默认关闭，按显式开关执行。
- **多端数据主权、迁移与更新**：电脑 `local-data` 与独立 Android（见 [ANDROID_STANDALONE.md](./ANDROID_STANDALONE.md)）分别持有事实源，不隐式合并；局域网手机共享电脑工坊。「存储与备份」管理工坊数据、默认导出目录（系统默认／自定义文件夹／每次询问）、数据备份及手机端缩略图缓存（电脑端隐藏）；「本地资源与模型」管理词库就地下载／本地 `tag.sqlite` 导入、反推模型与画师图包；「同步与网络访问」管理酒馆同步、局域网密码与反推 HTTPS 入口。Windows 迁移先冻结写入并停服，逐文件核验后切换且保留旧目录；数据路径失效时明确停止，绝不自动新建空库。源码启动前核对目录与监听 PID 单实例占位，不按 `node` 进程名盲杀。安装版更新固定取自官方 GitHub Release（见 [WINDOWS_DESKTOP.md](./WINDOWS_DESKTOP.md)），源码版更新脚本默认从官方仓库 `main` 分支 fast-forward 拉取最新源码并重新构建（拦截跨 major、存储定位变更及受保护数据目录）。软件更新、桌面启动器与声明集中于「关于与系统」（完全开源免费，防倒卖提示），无启动弹窗。

## 2. 风格串、收集、提示词库与 Roll 串

### 2.1 风格串、分享包、查重与剪贴板收集
- **风格串列表与卡片**：支持层级多文件夹归属与独立多标签筛选（筛选面板旁提供全库「管理标签」支持重命名、合并去重与移除）；「待实测」标记在标题栏，实际生图成功后自动摘除。卡片左上红钮删除（仅删配置，核对引用保留仍在被历史／收藏使用的原图），右上依次为「收藏 → 下载 → 复制 → 发送到实验室 → 编辑信息」。
- **已明确废弃**：取消风格串「统一角色」模式及其全部运行链路；取消独立的「复制风格串」按钮与组合复制弹窗（统一通过复制图片携带元数据或用 `.naia` 分享包交换）。
- **`.naia` 风格串分享包与 `.zip` 画风包导入**：支持整库、完整筛选结果或已选项导出 `.naia`（单包上限 10,000 条／2 GiB），封面可选不带、压缩（默认）或原图，随包携带必要 Vibe 编码与精准参考（导入重关联，不自动付费重编码），自动核对快照写入不可手动篡改的「整库打包／部分打包」标记，保留去重后的作者与来源声明。导入采用只读本地预览（支持 `.naia` 及含 NovelAI 元数据的本地 `.zip` 图片包，按偏移流式读取 WebP EXIF／PNG 文本块并兼容 `manifest.json` 来源链接，超过 200 条的大 ZIP 默认不勾选防误导；支持按模型筛选、搜名称与提示词、放大看图、新建或选目标文件夹、逐项重试归类），当前阶段不做同名覆盖或自动查重跳过，也不内置第三方下载链接。
- **本地「查找相似」**：纯本地词库与 `::` 权重路径解析（不调 AI、不生图）：正向画师集合 ≥75% 召回且画师与画风词加权相似度均 ≥75%（无画师时须 ≥2 个具体画风词且重合度 ≥90%）才归组；组内任意两串均须达标（完全子图），按组内最低两两得分降序排列，支持多列并排对照高亮共同词与单条确认删除，不提供批量删除或自动合并。
- **Windows 置顶收集小窗**：仅开放本机控制（局域网手机不远程开关剪贴板监听），重启后默认关闭。提供等宽「风格串／收藏库／提示词库」三模式且独立计数：前两者接收复制的图片本体（支持读取伴随的剪贴板 `HTML Format` 唯一 `<img src>` 原链优先抓原图，拉取受限再平滑回退位图）、资源管理器多选图片文件（原文件优先，≤12 MB）或直链——**法典（`quicktagcloud.com`）预览图直链及分享链接自动按规则升级为对应封面原图（兼容 `.png` 与含 Alpha 隐写的 `.webp` 原图并原样保留封面）**；风格串模式要求含 NAI 元数据（无原图时明确跳过），收藏库模式无元数据也收；提示词库模式原样收录复制文本（自动取首行作名称，同次去重，不弹确认框）。

### 2.2 提示词库、取用与实验室分栏
- **主浏览即管理面**：入口统一称「提示词库」，顶栏仅留「片段／组合」两档（移除全部／原文独立分区，旧偏好回落片段；「收录提示词」与「粘贴收录」默认保存为「片段」，历史已存的「原文」条目也在「片段 → 全部／未归类」中直接展示并可点开编辑或送到实验室，不再套一层「管理提示词」弹窗）。「粘贴收录」中「保存并继续」清空正文、名称与用途 Tag，保留目录分类与自由标签。
- **可编辑目录与 16 类固定用途解耦**：片段使用用户可自由增删改与无限细分的目录树（初始预设 5 根 12 二级目录，画风配方为整段正负一体叶子，人与人互动归动作夹、载具归物品夹），目录仅管收纳与限定候选范围。系统语义固定为 **16 个用途 ID**（存于 `params._promptLibraryPurposes`，用户可改条目用途但不可自定义类型）；纯用途随机抽取只接受非空、正向且仅含单一匹配用途的纯片段，混合与未标注片段保留完整原文供手动或助手语义取用。
- **组合与角色库自定义角色互通**：组合目录只保留固定根「角色」，夹内双向投影角色库的自定义角色（同 ID、同封面，编辑写回同一实体，或另存为独立组合；挂「角色」标签新建即落成 `type: 'character'`）。组合快照完整保存全局与角色的各用途栏及「补充」栏（`extra`／`prompt`）、分类负面与四态约束，不包含独立画师串与生图参数。
- **卡片、就地封面生成与关联回查**：片段点卡片直接在右侧栏（窄屏覆盖层）就地编辑；组合与原文点卡看详情并可「送到实验室」（选定目标与追加／替换／仅填空白后直入文生图，不二次弹窗）。卡片左上放删除与清除封面，右侧放收藏与就地封面生成（筛选菜单内配独立「封面生成设置」以 `{content}` 拼入正文，成图直接写回 `previewImage`）。未指定封面时默认取最早关联的本地历史原图引用；历史保存时通过 `prompt_library_links` 对 ≥8 字符的库条目做规范化文本包含匹配（含角色分栏，分批回填），**仅允许关联空来源或 `playground` 记录，绝不覆盖已有具体来源 ID**。
- **补全、AI 提取分类与 AI 生成搭配**：输入框支持 `@名称` 检索个人提示词库（与 Tag 补全上下分组）。「AI 提取分类」（切分原词交当前助手模型判类或看图推断，剥离负面与参数）与「AI 生成搭配」（按选定固定用途单次调用助手模型生成候选）均须用户主动点击，界面明确提示可能产生模型服务费用，不消耗 NovelAI 额度。
- **实验室分栏编辑与内容 Roll**：实验室默认整段编辑；可选打开分类编辑（分页固定为「全局／角色／场景／参考／参数」，全局画风始终整段不拆；互动挂角色页顶部共用栏并在启用角色 ≥2 且抽到互动时稳定分配 `source#`／`target#` 或 `mutual#`；角色槽默认人物设定／外貌／服饰／动作／表情，生物／物品／载具按需添加）。内容 Roll 支持主体 8 类与画面 7 类单列勾选、锁定与单栏重抽，7 类画风用途不参与随机。

### 2.3 Roll 串画风探索
- **单一随机流程**：直接复用完整画师词库（无图画师也可参与），每串人数默认 `4～4`、权重默认 `0.7～1.4`（步进 0.1，每条配方独立重掷权重，固定画师也不锁死权重）。抽取先扣除已固定偏好，无重复补足「收藏保底」，其余位置按「收藏倍率」与来源频次随机补位；开启「只抽取收藏画师」时仅从有效收藏池补位，池不足以满足上限时直接停止报错，绝不偷偷缩减人数或混入普通画师。
- **画师来源集合与共用预设**：默认全画师库，也可在顶栏／设置从本地风格串多选（含「随机选 3 条」或「使用全部风格串」）建立当前记录的候选来源快照（跨串重复出现提高相对抽取权重，同串重复不叠加；「使用画师库」一键恢复全库）。Roll 与画师库共用完整生成配置与命名预设（公共正负词＋独立 `characterPrompt` 合入全局正向，种子跟随全局「强制置空」开关，生成间隔与随机浮动按 Key 共用）。
- **界面、单一配置入口、纯净卡片与记录生命周期**：左侧提供可收起 Roll 列表导航（顶栏使用侧栏开关图标 `PanelLeft` + 当前条目标题区分于右侧生图按钮；头部精简为总数、批量清理按钮与 `+ 新建`，点击新建直接以不撞号自增 `Roll N` 命名并切换；固定画师新建以首位画师主名命名如 `dino`／`dino 等 5 位`；记录 ≥2 条时可点批量清理进入原地多选（自带「空记录」「7 天前」「留最近 10 条」快捷勾选，自动跳过正在生成的记录，一次二次确认批量删除，历史原图与已存串保留）；搜索与「最近／创建」排序紧凑同行，悬停重命名／删除）。顶栏移除冗余的「筛选」浮层（画风记录已承担分卷隔离，搜索框与「多选」内已收藏／未收藏快捷项覆盖日常查找与批量挑图）；「设置」浮层作为全页唯一的抽取规则入口（高频直调张数、人数与权重，低频「偏好与画师范围」「生成间隔」「旧轮清理」默认折叠并展示实时摘要，底部紧凑排列三大配置入口；「旧轮清理」提供本端持久化的 4 档自动清理 `关闭／清上一轮／留最近 2 轮／留最近 3 轮` 及手动一键「立即清理未保留项」——仅在手动点「再 Roll 一轮」且历史与收藏就绪时触发，永久保护已收藏 ❤️ 与已存为风格串 ✓ 的候选，助手连续 Roll 强制跳过，原图与已存串保留）；「提示词与生成设置」大弹窗仅编辑模板与参数（不再重复提供「抽取设置」标签页或通栏改名框）；「管理画师与偏好」弹窗专注画师固定／偏好／屏蔽（内嵌可展开的「手动添加固定 Tag」，不再重复套「抽取设置」浮层）。候选卡片画面保持纯净：**所有卡片（含未出图占位卡与已出图卡片）左上角不再常驻 `#编号 / R轮次` 标**（悬停直接显示删除按钮，编号与轮次统一在右侧详情查看；未出图卡片中央已展示排队顺位与进度），**底部不画彩色权重占比条与画师随机色点**，底栏展示按权重优先排序的前 2 位主画师标签与 `+N`，出图完成后在画师标签正下方居左永久保留历史持久化的真实生成耗时（如 `4.8s`／`1m 32.4s`）。默认本轮张数不再写死 6 张，而是自适应 Roll 图库当前展示列数（一次满一行，手动在「设置 → 本轮张数」修改后优先遵循手动值）。Roll 页顶栏固定保持「多选／再 Roll 一轮／设置」，中断后不在顶栏临时插入「补齐剩余」按钮——卡片内合并「暂停／取消」为单颗居中圆形 Icon 按钮：生成中仅当前作品卡带绕边旋转强调色光环、中央圆形 `⏹` 停止按钮（悬停变红，点即结束本批并释放队列）以及紧贴按钮下方的实验室同源状态文案与 `0.1s` 实时秒表；中断待继续时仅队头卡正中以实心强调色圆形 `▶` 按钮一键唤醒整批剩余队列（下方配 `继续剩余 N 张` 与轻量 `仅生此张`），其余未出图空卡为浅灰圆形 `▶`（仅生此张）。Roll 页隐藏全局右下角公共队列浮条，状态语义通过 `services/generationStatus.ts` 与实验室生成按钮完全同源（中转代理按正常「生成中…」展示，仅真实公共队列等待才报「云端排队」）。已抽出的候选配方与轮次快照不可改写，但公共模板可继续改、候选与整条记录可二次确认彻底删除（原图与已存串保留）。保存时自动归一化 `sourceChainSets` 防本地 D1 约 2.1 MB 上限（详见 [STYLE_ROLL.md](./STYLE_ROLL.md)）。
- **连续 Roll 例外与明确废弃项**：仅在用户明确要求时由助手调用 `run_roll_series` 在页面后台逐轮循环，按指定 Opus 百分比、点数或轮数停止，任何失败、取消、容量将满或关页即停。**已明确废弃且禁止恢复**：画风对比、投票／Elo 排名、进化评选、自动权重测试、换 Seed 验证、手动逐项调权界面，以及从已有风格串套用公共配置入口。

## 3. 画师库与角色库

- **个人层级分组与来源目录**：画师（按精确原始 Tag）与角色（区分 `catalog:Tag` 与 `custom:chainId`）均支持个人多分组树及桌面卡片拖拽追加归属。角色库固定提供「danbooru／自定义」两个只读来源目录，词库角色信息栏仅显示一次「Danbooru」。
- **角色同族变体折叠与就地覆写**：词库中同基础名＋同作品限定的服装变体默认折叠为代表卡（原位展开子卡；加入自定义分组时自动带入全族；「同角色变体联动收藏」默认开启，点亮／取消整族代表图）。词库角色点铅笔可在原身份上保存个人补充提示词／封面覆写（不复制到自定义）；自定义角色卡片仅保留左上删除与右上「收藏 → 下载 → 复制 → 铅笔编辑」（移除底部重复编辑与进实验室工作台入口）。
- **画师完整并集、多词搜索与参与统计**：完整目录取 Tag 词库与已接入 V4.5／V5 图包的并集（支持中英文逗号分隔的多词子串模糊搜索）；默认筛选有样张画师（无图包且无自建样张时自动展示全目录）。增量维护每位画师在现存风格串中的「收录串数」与非导入历史的「生成图片数」，支持排序与交集筛选。随机抽卡采用无放回抽样并避让近期五批，画师库可独立勾选排除已偏好／已屏蔽画师。
- **画师卡片操作、单向屏蔽互斥与就地流式补图**：点按画师卡片为选中画师（不弹大图）。左上放置**已屏蔽时常驻红色实底**的全局屏蔽钮（屏蔽成功自动解除 Roll 锁定并**单向取消该画师偏好收藏**，取消屏蔽不恢复收藏）与单页样张移除钮；右侧依次为常驻偏好爱心（与收藏库 `sourceType=artist` 同步）、就地补图生成图标（按当前卡版本直接流式生成单张并幂等归档为自建样张，状态由右下旋转小圈反馈）、单卡 `V4.5 / V5F` 版本切换按钮（全局 V4.5／V5 Full 切换移入筛选面板顶部）。
- **样张图包管理**：V4.5 单包与 V5 七分片（6 个 `NAID5F-*` 加补齐缺口的 `NAID5-STYLISH-8000`，核查依据见 [ARTIST_SAMPLES_V5_FULL.md](./ARTIST_SAMPLES_V5_FULL.md)）按无新增字节判定超时、支持断点续传、SHA-256 校验与只读流式偏移索引；图包缩略图保守裁除已核实规格的两侧纯黑边，原图字节不变。**明确否定**：外链下载方案、Danbooru 自动补图、全词库自动批量补图及旧浏览器本地收藏名册。

## 4. 外部图库、收藏库与本地反推

- **Pixiv 与 Danbooru**：Pixiv 登录走系统默认浏览器＋回调自动捕获／手动粘贴双兜底，复用工坊代理；顶栏紧凑双行，榜单按上游游标无限续读，右下角带 `P` 心形区分 Pixiv 账号收藏与右上工坊本地爱心。Danbooru 严格区分站点验证、403、429 与临时网络故障，离开页面立即取消排队重试。两站详情均直达单页／当前图「图片反推」。
- **AITag 与法典**：
  - AITag 搜索条件胶囊内嵌搜索框；列表由前后端共用 `aitagMetadataCore` 下发轻量结论，在线检索与本地已加载元数据筛选（模型、画师串、排除氛围／精准参考等）联动，整页待补齐时暂缓连拉；卡片左上常驻圆形「风格串收录状态」，标题前用绿点（整组已缓）／蓝点（首图已缓）表达本地缓存，保存风格串优先复用浏览器已缓原图字节。
  - 法典接入在线书目与共创广场（只读校验清单与 SHA-256），支持跨书目检索与层级目录；打开详情自动读当前原图配置，不把 SD／ComfyUI 参数映射为 NAI。
  - **详情统一三主操作**：AITag 与法典详情固定排列「保存到风格串（绿） → 导入实验室（主题色，完整恢复正负词／角色／模型／Seed／参数进文生图） → 用作底图（紫，仅投递图片进选定编辑模式，保留当前提示词）」；AITag 标题栏另带纯图标「批量保存整组」与「保存后跳转」开关。
- **全局收藏库**：汇总全站右上常驻爱心（AITag／Pixiv／法典按作品组折叠并标命中页数，任一页收藏组卡即亮；旧历史／风格串／角色收藏标记只读兼容汇总）。来源与自定义收藏夹分列于左侧文件夹导航（自定义夹支持手柄拖拽排序，来源与夹名不自动变成普通 Tag）；筛选面板内提供独立全库「管理标签」。「加入收藏库」弹窗仅接收本地 ≤12 MB 图片（画廊页面不接外部文件拖入，页面拖拽仅用于归类已有卡片）。详情按「标签 → 正向 → 角色 → 负面 → 参考 → 参数」固定排列且默认折叠长文本；**明确移除备注、评分、图钉、相似推荐与资产提取工具**。
- **本地图片反推（WD Tagger）**：模型在「本地资源与模型」卡片化管理（下载／暂停／切换／删除，识别中保护文件）；共用「识别图片 Tag」面板（右上浮层也可管模型）支持粘贴图片，结果明确区分「复制 Tag」「加进全局正面提示词」「加进角色提示词」（优先空角色槽，绝不清空已有角色词）。原站标签与反推结果分区展示，并与原图自带 Prompt 明确区分。

## 5. 生成历史与历史回收站

- **历史浏览**：顶栏左侧收敛为单一「筛选」入口（首位提供 `❤️ 只看收藏` 切换，其余依次为时间、模型、方式、来源、排序与随机浏览）及页码跳转，中间搜索框内嵌总数计数，右侧为直达「多选」、「回收站」及纯图标更多清理菜单；随机浏览洗牌在同次翻图与返回间保持稳定。手机历史列表只留图片，不在卡片下叠时间行。大图详情先排操作再排提示词与参数，「导入到实验室」默认进文生图，也可切编辑模式并按需复用历史蒙版。
- **历史回收站强制缓冲**：单张删除、多选删除、清空及按时间／数量清理（含创作助手操作）**一律只移入回收站**，严禁从活动历史直接永久删除。被有效收藏、用作封面／配方引用或仍在使用的 Roll 候选首次原图引用的记录阻止移入（批量自动跳过，用作封面时明确列出引用条目名称；纯提示词库文本关联不阻止移入，恢复时保留关联、永久删除时清理；按最新 N 张清理时受保护旧图额外保留，不挤占 N 张名额）。移入与恢复在统计上保持中性；仅在回收站内经独立二次确认（不提供当日免确认）执行「永久删除」时，才清理记录、扣减画师／关联计数并释放无其他引用的物理原图。

## 6. 统一创作工作台（生图实验室）

- **双层导航与自适应分栏**：风格串／自定义角色编辑与自由实验室共用工作台。上排为四模式切换（手机缩为左对齐当前模式标题＋底面板切换），下排为居中紧凑分区条：文生图固定「全局／角色／参考／参数」，图片编辑固定「底图／提示／参考／参数」（当前模型与操作不支持任一参考如 V5 局部重绘时自动隐藏参考分区）。中间可用宽 `≥560px` 时保持编辑与预览左右并列（兼容同时停靠创作助手），低于 `560px` 才纵排并将公共工具收进右上更多菜单。
- **草稿隔离与跨重启记忆**：四模式各自独立持有提示词、参数、底图与蒙版。「记住上次生图设置」仅作用于自由实验室（可分项勾选参数、全局正负、角色正负；复开时结果预览与编辑底图／蒙版留空），预设工作台只保留当次会话草稿、绝不读写跨重启记忆。

## 7. 创作参数、密钥池与官方计费

- **密钥保管箱三渠道**：每条密钥绑定「NovelAI 官方／生图网关／按次渠道」之一（默认脱敏显示 `pst-…XXXX`，改值须删后重建）。成员网关支持流式接口（兼容 SSE 中间帧与二进制 MsgPack 帧并完整透传 Vibe 编码数据），2× 独立放大对成员网关发送 `nai-diffusion-5-curated`；查询订阅时并行探测同源 `/api/me/quota`：命中 `fairQuota.v5Capacity` 时按个人上限绘制额度圆环满圈与 20% 预警，命中独立成员钱包时直接使用网关点数余额（不再套用默认 `1666` 本地预算）。按次渠道仅发生成请求，隐藏点数／额度区并显示「按渠道计费」。
- **「Opus 额度」与预计回满时间**：官方与成员网关统一称「Opus 额度」（成员百分比保留一位小数）；未满额时侧栏第二行紧凑追加预计回满时间（如 `≈320 张 · 1天4小时后满` 或 `恢复受限`：拼车直读精确回满秒数，官方按 `timeUntilNextPercent` 线性估算，普通第三方网关不盲猜）。
- **Key 池自动轮询**：2 把及以上非按次密钥可开启总开关并勾选入池（存于 `nai_key_pool`，按密钥保管箱上下顺序稳定编号 `#1`/`#2`…，手动切池外 Key 自动关池）。采用**单并发顺序出图＋满圈率优先**（`remaining / capacity` 降序 → 绝对剩余降序 → 平局轮换避开刚用过的 Key，跳过过期／非 Opus／冷却／耗尽项）。实行**发车前零阻塞、出图后后台异步刷新**：缓存余额 `>1%` 直接秒发车（批内刚用过的 Key 仍在后台刷新时直接切另一把干净 Key 并行推进），仅在无缓存、缓存耗尽或最高余额 `≤1%` 警戒区时才在发车前同步核实；**全池耗尽或参数需消耗 Anlas 时立即停下提示，绝不静默跨 Key 扣费**。侧栏与资源详情角标实时显示当前轮换到的序号（`池 #1`、`池 #2`…），并在保管箱、悬停提示与展开成员列表同步标注对应序号。
- **出口生图用时**：桌面网关仅统计「向上游出口发起生图请求 → 收齐最终图片响应」耗时，持久化于 `params._local_generation_duration_ms`，在实验室预览底栏／大图、历史大图标题栏与 Roll 详情／大图中常驻展示。
- **模型档位与移除低消耗模式**：V5 Full 同行提供 `High / Medium` 档位选择（Medium 灰显固定步数／采样器／负面预设并禁用负面词与 CFG Rescale，切回恢复 High 草稿）；噪声调度默认 `karras`；默认画幅贴近免费像素（`832×1216`／`1216×832`／`1024×1024`）。**已彻底移除「低消耗模式」**，不偷偷压步数、缩尺寸或停参考。
- **官方常量自动同步与幂等记账**：模型清单、免费门槛、倍率与 Vibe／参考计价系数随官方 Web 应用后台自动同步（侧栏琥珀点区分「网络下载失败」与「官方改版结构变化」两类告警）。每张成图与每次新 Vibe 编码凭唯一凭据在单 D1 事务内原子写入本地预算扣减、累计与 `local_usage_events`（网络闪断最多补投递 3 次结算，记账失败保留产物并提示，绝不重发生图）。Vibe 编码按「图片＋模型＋完整提取参数」复用，兼容 `.naiv4vibe`／`.naiv4vibeBundle`／PNG 内嵌编码，新编码须确认费用。

- **前缀缓存、80% 自动摘要与 `@角色` 引用**：已发送的工作区快照固定在原位、变化追加末尾以复用模型前缀缓存；整体上下文达 80%（或手动输入 `/compact`）时调用当前模型生成语义摘要续聊，原会话完整消息与工具回执保留不删。输入框支持 `@` 联想引用角色库中的自定义与词库角色（数量上限跟随当前生图模型角色槽，引用标签随消息保存，不自动改写实验室草稿）。
- **破限模式、联网搜索与防空转**：内置默认开启、可在设置直接编辑正文并一键恢复默认的单一「破限模式」开关；联网搜索默认走免费源（DuckDuckGo／Bing RSS），可选配独立搜索 API；连续三轮工具全败或相同参数连续报错时自动停机防空转，可继续的中断提供手动「继续处理」按钮。
- **已明确废弃**：取消多套提示词注入预设管理与酒馆预设适配；取消助手 LLM 价格配置与金额记录（仅展示 Token、上下文圆环与耗时）；不提供运行中转向或排队追加消息控件。

## 11. 漫画创作模式

- **入口与三栏轻量化工作台**：桌面端位于侧栏「工作区 → 漫画」，手机端位于实验室顶栏直达按钮（保持手机底栏固定 5 格不变）；接入工坊液态玻璃（`.appearance-panel`）与壁纸透视，并完整接入全局防窥安全模式（遮挡画布 SVG 图像与书架/阅读器成图，点击临时揭示、`Esc` 重遮挡）。手机端画布默认满屏显示，属性面板以底部抽屉展开。桌面端坚持清爽三栏结构：「左侧可收起作品页列表条 | 宽敞居中绘图桌画布（仅手动逐格模式在画格上浮现快捷选图胶囊，底部悬浮 5 工具胶囊，其余低频工具与独立图层浮层收入「···」菜单） | 右侧固定三步工作流（`1 画风设定 → 2 分镜生图 → 3 气泡嵌字`）」；顶栏「画幅与模板」只专注画幅、格缝滑块与 **45 款去重精装分镜预设**（支持大图浏览与对开页 `整页 / 左半页 / 右半页` 分区套用），不重复堆叠模型与色彩开关。
