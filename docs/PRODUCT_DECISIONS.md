## 1. 共用界面、窗口与分享

- 带文件夹侧栏页面的空库、无匹配等状态按整个页面正文水平居中，侧栏收展及窗口变化自动重算；窄正文须保证状态和操作不被侧栏或滚动边界裁掉。正常图片列表继续使用自己的滚动区域，不为居中改动顶栏、把手、目录位置或首屏避让。

- 搜索框内的已选条件共用同一套胶囊：搜索图标之后从左到右排列，关键词输入接在后面，单行且优先保留输入空间；宽度不足收成「+N」，打开当前页面原有筛选面板查看和取消条件，不另起一行或要求横向拖动寻找。增删条件保留输入节点、草稿和焦点，隐藏胶囊不参与键盘聚焦；极窄手机收起框内装饰性搜索图标以保留操作空间。已有来源切换、排序与分类导航按各自用途保留，不为统一展示而额外增加胶囊或改变筛选语义。

- 已有内容分类侧栏采用现有顶栏的文件夹图标控制，默认收起，分别记住本端展开偏好；图标的提示与高亮表达当前分类，收起不重置分类、搜索、筛选或正在编辑的内容。主页面的电脑分类侧栏展开时避让真实顶栏，玻璃主题底边与主侧栏共用留白，收起释放宽度；手机按当前入口的可用空间展示，不新增常驻底栏或恢复已取消的侧栏。文件夹面板以风格串为交互基准：标题旁用共用加号新建，选中具体目录时默认在其下建立子目录，选「全部／未归类」等全局项时默认根层；提示词片段与组合的主浏览及管理窗口同样遵守，进入新建时聚焦名称，上级仍可手动更换，不沿用上次新增的旧上级或目标覆盖。目录行使用文件夹图标、统一的浅强调选中态、侧栏材质与桌面宽度；已有收藏夹颜色和排序、固定用途图标及移动端导航按对象语义保留。是否新增分类能力按对象的真实整理需求单独判断，不能因统一按钮而增加新的文件夹数据结构。

- 原生下拉选择器的展开选项与分组统一使用当前主题的实色面板及配套正文色，不能继承玻璃控件的透明底而出现浅底白字；明暗模式直接控制选择器的系统配色，禁用项保持可辨认的次要文字，系统强制颜色优先。覆盖全部页面、工具栏与助手入口，保留原生键盘和手机选择语义，不为可读性改造每个下拉框。

- 悬浮操作按所在任务补齐，不要求所有场景拥有同一组按钮。实验室结果预览保留左右管理／分享、中间翻图和底部工具的分工，操作按实际尺寸向内换列并彼此避让；编辑模式的小预览沿用页面通知。通用大图在原图最终失败后提供手动重试，换图不沿用旧错误；Pixiv 多页大图保留滑动，并提供页码、前后按钮和方向键，单张不显示分页。电脑自定义角色大图复用缩放和平移，手机保持角色详情入口，不同时挂载两个活动查看层。批量导入与清理候选的键盘勾选只改变选择，输入框和删除锁定状态保留原有语义。

- 封面右上操作按实际空间先从上往下、再向左相邻列从顶部继续；收藏保持首位，图片取用与编辑、发送实验室、保存或生成样张等附加按钮共用同一排布。以名称、状态及模型所在的实际信息区为下边界，留出间距，并避让左侧删除／版本控件与底部翻图；不缩小触控按钮。极扁或极窄封面在换列仍不足时补足必要显示高度，封面宽度始终由所属卡片列确定，不因补高与图片比例反向改变。悬停、键盘聚焦与触屏长按只切换显隐，不改变操作顺序或展开时的卡片布局。排布跟随实际尺寸与参与控件变化；选中、保存状态和图标更新不重建尺寸观察器，相同布局不重复写入，保留作品居中滚动。风格串、自定义角色、提示词库、Roll 结果、历史及各图库图片卡片共用此规则；画师目录的 Tag 级屏蔽／偏好与样张浏览、生成按目录专节处理。

- 所有确认类型提供默认不勾选的「今日内不再显示」，包括删除、费用、存储迁移与恢复；按本端本地自然日及稳定操作类型分别记住，不按翻译标题分类。只有勾选后明确确认才保存，取消、Esc、遮罩或手机返回不授予授权；跨日恢复提示。费用按 Key／接入、金额／张数及预算风险状态区分，迁移／恢复按实际目标区分，普通余额递减和删除另一张同类作品不应制造新类型。偏好只保存作用范围摘要，不能持久保存 Key 或请求体；存储不可用时仍可完成本次确认，后续继续询问。离开编辑器区分「放弃／保存」，记住保存后仍每次执行真正保存，成功才离开；失败保留草稿。参数、文件选择和恢复口令表单仍由用户填写，当日授权只省对应最终确认；内置 Agent 不能代用户勾选扩展当日授权。

- 所有主页面顶栏与状态行共用可收起把手：电脑展开时把手保持顶栏上边中央原样；仅手机断点将把手移到顶栏左侧独立位置，位于同一行且完全在顶栏内，不新增工具行、不覆盖其他控件并保留原触控区。描边胶囊内为向上小三角，悬停／键盘聚焦时显示「收起」并填充主题色；点击后整条顶栏与状态行隐藏，页面顶边保留可展开把手，变为向下小三角并提示「展开」。不移动顶栏位置，也不为把手预留额外高度。收起状态按本端浏览器保存并跨页面共享，顶栏高度变量同步归零，滚动内容顶到页面边缘；设置等模态窗口内的页内导航不跟随，不另做每个页面一套开关。

- **共用目录树：** 风格串、画师／角色分组、提示词片段与组合、收藏夹及其 Roll／分享包／取用入口统一复用目录树导航、上级选择、多归属复选及单目录编辑窗口，业务适配层只处理各自内容、存储与可靠操作。嵌入树只负责内容布局，不带独立面板材质、边框、圆角、定位或滚动层，外部侧栏／窗口只承托一次；普通新建与编辑共用名称、上级及一次保存，业务特有字段按需扩展，不把整树管理或批次再保存作为日常必经步骤。层级不设固定上限，分支可收展，所有层级可新增、改名、删除或调整上级；电脑按需展开侧栏，手机用完整路径选择，不改原顶栏把手。电脑拖动目录名至目标目录可移入整棵子树，拖动中导航顶部提供临时根层目标，拒绝自身、后代、无变化或其它业务／实例的目录拖入；保留上级选择供手机与键盘操作，目录拖动、作品追加归属与收藏夹同级排序各守原有含义，失败回读或保留草稿后可重试。父节点浏览包含后代，祖先计数按对象身份去重，归属复选只增减直接触及关系；删除仅解除本目录关系，直接子目录提升上级，作品及其它归属保留。各业务独立存储；Roll 选画师与画师库仍共用同一画师分组资料，浏览位置与收展独立。旧平面目录只读视为根层，已有配方、Tag、图片及归属不迁移；目录结构只在用户主动编辑后保存，现有节点总数保护不等同固定深度限制。

- 资源数量只在原顶栏下沿增加居中小字，明确总量、筛选结果或已加载范围；不借此调整把手的位置与形状、顶栏高度、控件排列和图片滚动层叠，不额外新增状态栏。

- 桌面侧栏将 AITag、法典、Danbooru、Pixiv 按原顺序归入「素材浏览」，工作区、画师库、角色库、收藏库与历史仍直接可达。展开侧栏时该组原位折叠，默认收起，按本端浏览器记住手动展开状态；切页或整体折叠不覆盖该偏好。当前来源子项高亮，收起分组时父项仍标明当前来源；「素材浏览」入口使用叠放图片图标；整体收成图标栏时点击在右侧打开按四项内容收紧的来源菜单，减少面板宽度、行高与留白，触屏仍保留可靠点击高度。选择后收起，沿用共用浮层的视口避让、背景拦截、Esc／点外关闭及焦点归还。手机保留原有底部导航与资源库面板，各来源页面及浏览状态继续独立，不增加自定义导航配置。

- 资源图片卡片默认让图片铺满卡片，名称和辅助信息叠在底部渐变磨砂区，上缘渐隐、正文清晰，保留原图比例与必要卡片间距；纯文本条目继续使用文字卡片。覆盖风格串、画师、角色、法典、外部图库、浏览足迹与收藏，页数和封面翻页不遮挡文字或图片操作。叠图底栏的透明底与亮色文字优先于主题的普通白底、文字色阶映射，图标保留收藏／警告等语义色；图上按钮、定位点与导入提示保留必要的对比承托，不归入普通中性分组的透明化。鼠标悬停以轻抬、微放大表达浮动，卡片不额外绘制装饰阴影。外观提供「全图磨砂卡片」「卡片悬停浮动」两个默认开启的独立开关，随本端偏好及外观预设保存；关闭磨砂恢复图下信息栏，关闭浮动保持静止，触屏及减少／关闭动画时不浮动。此为卡片展示细节，沿用产品宪法中作品优先、静止克制的原则。

- 界面提供简体中文、繁體中文、English、日本語与 한국어，默认简中；选择按当前工坊浏览器保存并即时更新控件、日期和数字格式，切换不重挂载编辑器或清空草稿。内置助手下一次请求跟随所选语言，历史对话、Prompt、Tag、作品原名、用户标签与资料原文保持不变。语言字典内置，不依赖运行时在线翻译。Windows 启动提示与托盘同步保存语言，安装器提供同样五种语言。
- README 入口提供对应五种语言的使用说明，菜单名对照界面译文，安装／更新命令、路径、费用与数据边界保持一致；专项技术文档与变更日志继续以简中维护，不能将界面语言支持表述为 Tag 词库或私人资料自动翻译。

- 用户已恢复独立 Android APK，首次范围为完整工坊：四模式、图库、Agent、按需下载的本地反推。共用 React 手机界面与业务规则，手机独立持久保存资料、原图和凭据；词库、模型按需下载，不把开发者缓存装进 APK。已有局域网入口继续可用，电脑数据及存储定位规则保持原有边界。实现、验证与交付状态见[独立 Android 说明](./ANDROID_STANDALONE.md)。
- 独立 Android 与电脑分别保存事实源，不隐式迁移或同步；原件按内容去重，缩略图保留明确缓存上限，词库与模型可再下载。手机卸载会清除私有资料，完整备份必须包含凭据与会话并由密码加密，恢复先验证再确认替换；手机导出取得系统真实写入收据。Android Agent 使用项目工具访问资料，磁盘工具只访问应用内创作目录，不能把电脑绝对路径或桌面常驻监听当成手机能力。
- 项目版本只跟随电脑端迭代，Android 单独修复不推进显示版本；APK 使用独立递增构建号与原签名覆盖安装，调回显示版本也不要求卸载。手机图片继续长按显露原位操作，不增加常驻更多按钮；原生图片菜单与嵌套卡片长按不得抢夺工坊操作，输入文字仍保留系统选择／复制。大图按原图比例适应真实可用区域，打开与加载完成时不出现宽度跳变，窗口或详情区域变化后继续适配；统一双指缩放、触点双击放大／复原、单指平移；双指抬起一指后继续平移，缩放时不翻图、不触发长按，适应窗口时横滑翻图。外部详情点按进入大图，返回收起当前层并保留原详情位置。

- 同类按钮保持紧凑、一致的高度、基线和间距；保存用绿色，一般主操作用主题色，危险操作用红色，未保存修改确认框的「放弃并离开」使用红底白字；完成／禁用回归中性灰。语义底色与前景成对保证阅读，较亮的状态环／图标颜色不直接用作小字前景；辅助文字及浅色弹窗正文保留透光后的对比余量。抽卡是浏览动作，初次、再次与执行中均使用中性样式。两套预设的明暗检查范围见[界面检查记录](./THEME_VISUAL_AUDIT.md)。
- AITag、Pixiv、Danbooru、法典、收藏库、画师库与角色库统一选择聚焦：有选中项时，已选卡片保持原亮度与明确边框／勾选，其余卡片沿用 AITag 的 70% 亮度；关闭详情或清空多选后恢复。覆盖图库浏览足迹、目录抽卡与各网格布局；该模式默认开启，可在设置中统一开关；关闭只取消其他卡片变暗与自动居中，不影响选择和详情，生成历史的批量选择不属于此模式。
- 手机作品详情是当前页面的覆盖层，返回只收起当前层并继续原作品位置；多层窗口逐层返回，后台保留的页面不响应前台返回。滚动由现有列表缓存／作品锚点恢复，浏览器历史不再重复恢复旧值。
- 保活页面保留草稿、筛选和滚动位置，实验室输入与普通通知只更新相关内容；真实资料、外观、语言与激活状态仍及时传入，页面事件使用最新业务状态，不以冻结隐藏页面或卸载重建换取速度。连续加载仅在实际列表进度或加载状态变化时开启下一轮，无关图标与文字更新不释放请求锁。

## 2. 风格串、收集与筛选

- 风格串可按层级文件夹整理，同一串可归入多个文件夹，用户标签仍可多选，二者独立；父文件夹包含子文件夹的串，同串直接归属父子目录时父级只计一次，并与现有搜索、模型、收藏和标签等筛选叠加。文件夹区域默认收起，从现有顶栏图标展开，电脑收起后释放侧栏宽度，手机收起后不保留文件夹面板；展开偏好和当前目录按本端保存，收起不清除筛选，入口继续标明当前目录状态。目录和归属由当前工坊持久保存，不搬动图片、不改配方和生成参数；单条与批量都通过多选后工具栏的「设置文件夹」勾选归属，卡片封面悬浮层不提供该入口，部分选中只改主动触及项；拖到具体目录追加归属，全部／未整理只作浏览。删除目录仅解除该目录关系，保留其他归属，无任何归属才回未整理；子目录提升到上一级，同名加编号。旧单归属读取时兼容，不主动改写旧资料。新建串的成功归类及时同步保活列表，弹窗沿用页面活动状态、焦点和手机逐层返回规则；独立 Android 使用真实写入行数判断并发冲突。完整工坊备份保留目录，`.naia` 分享包仅交换配方及必要素材，不携带文件夹树或归属。

- 用户已明确取消风格串「统一角色」模式，删除其入口、界面、角色替换／副本运行链路及旧独立对比接口，不保留兼容空壳或待启用功能；不得按此前方案自行恢复。

- 顶栏按「搜索、筛选 ｜ 智慧姬同步 ｜ 多选、查找相似 ｜ 收集模式、分享包、批量导入、新建风格串」分组。收集是高频功能，保留直接入口；智慧姬同步仅在设置开启后显示。不额外常驻通用图片反推或手动刷新。

- 从库页或自由搭配点击「使用」，先在当前页选择目标、方式并预览，确认成功后进入实验室文生图，不二次弹取用面板；复用实验室真实草稿和撤销，执行任务时拒绝外部写入。编辑已存组合与使用分开，「复制组合数据」明确是结构化数据复制，不混同普通提示词文本。

- 库条目的封面在用户没有指定时自动取「最早关联到的本地生成原图」（保存原件资产引用，不依赖历史行、不再复制资产；手动换过的封面一律不覆盖）。删除历史仍保留封面原件，最后一个资产引用释放后才清理。库条目里「从历史选图」换封面时，选图面板只列这条目关联的生成图，后续匹配同一提示词的图会自动出现。
- 图与库条目的关联同样是**文本匹配推断**，不冒充「这张图由该条目生成」的精确记录：保存历史时把正文与六类库条目 `base_prompt` 做规范化（大小写、空白）包含匹配，正文取整段 Prompt、结构化基础／主体词，以及每个角色的正文与分栏（带角色的图里人物／服饰／姿势／表情只存在角色分栏，只看整段 Prompt 会漏掉它们）；不足 8 字符的条目不参与，命中多条时长条目优先；一条图可同时属于多条条目。关联只覆盖**空来源**与 `playground`：只要这一行已经记了具体来源 id（风格串、角色、库条目、Roll、画师样张、外部导入），一律保留原归属——即使来源类型为空也不改写，否则从某条串或某个样张来的图会被改成库条目，那条串的历史就查不到自己的图了。
- 关联数据独立成表 `prompt_library_links`（`history_id`、`chain_id`、`kind`、`chain_name`、`matched_length`、`created_at`），历史行的 `params._promptLibrary.sources` 记录全部命中，主来源仍落在既有 `source_chain_id／source_chain_name／source_chain_type` 上，历史页「来源」筛选不需要改动就能按条目筛图；不新增列、不改存储键、不改既有行的语义。
- 首次使用按请求分批回填（每批上限 200 行，进度写入 `settings`），避免大库一次扫描阻塞请求；`rebuild` 接口显式重置进度。新增条目或修改正文后，普通读取继续分批补算该条目，详情优先处理当前条目，不重建其他条目已解除的关联；完成后移除该条目的补算标记，不改旧图参数与主来源。删除历史、删除条目、解绑来源同步清理关联；条目改名或改正文时重算该条目的既有关联并摘掉不再命中的主来源，单纯改名不重扫全库。
- 「AI 生成搭配」由用户主动触发、单次文本补全、使用当前助手模型，同样不消耗 NovelAI 生图额度，界面说明模型服务可能收费；输出规范、附加指令、详细补全与「保持留空」沿用六类库的既有设置，越界词过滤按库分别执行，缺库如实提示、不补空条目。
- AI 生成搭配沿用当前助手单次文本调用和六类生成规范，候选可编辑并按选择保存片段，也可保存为组合；失败候选保留，保存不重复调用模型。写入风格串复用共用映射，角色内容写用户选择的角色或新建角色，场景、镜头写全局，保留其他角色与参数。
- 搭配写入风格串时选择目标角色；全局未分栏正文仍保留在补充，按栏替换同步处理分类负面，只有明确选择合并才进入补充。保留画师、风格负面、生图参数与坐标，写完清掉目标串旧编辑草稿，避免反向覆盖。

### Roll 串画风探索

- 独立「Roll 串」位于电脑工作区、手机资源菜单，流程为「一键抽取并出图 → 保存喜欢的结果 → 再 Roll 一轮」。直接使用现有画师库的完整 Tag 词库，不要求手填、预先收藏、旧画师表导入或另建画师池；缺图 Tag 也可参与。普通新建记录使用推荐公共正负词与默认参数，不隐式继承当前记录；推荐公共栏放质量、细节增强、皮肤材质、景深、光照、年份、背景与画师位置，独立角色栏只保留人物和姿态描述。角色栏独立保存、生成时按模板位置合入全局正向，不改为模型结构化角色通道；重分栏保留全部原词，只作用于新建或主动套用推荐。已有记录与自定义预设原样读取和保存，打开旧默认记录也不自动升级、拆分或重分栏。创作者可手动编辑公共配置并按记录保存。Roll 与画师库共用完整生成配置编辑器和同一套命名预设，包含公共正负词、独立角色提示词与全部 NAI 参数；推荐预设只读，双方均可手动自定义、另存、互选、更新与删除。当前 Roll 记录与画师库各版本模板分别保存快照，不因共用预设后来修改而被改写。预设不包含抽取人数、画师、权重或候选。主动套用只复制到当前草稿，保存 Roll 配置后才生效；保存、更新、删除预设不回写已存记录或作品，也不生图。有候选时仍冻结记录配置，但当前配置可另存为新预设；不会自动设定自定义预设，也不提供导入／导出。已取消从已有风格串套用公共设置的入口，不再恢复。Roll 随机补位默认使用完整画师库，也可由用户选多条本地风格串组成当前记录的画师来源集合；这是可替换的候选来源条件，不是自动偏好或独立模式。来源串可多选且不受每串人数范围限制；固定 Tag 保留并仍计入每串人数，随机只从所选集合补位；同一画师出现在不同已选串时按出现串数增加相对抽取机会，同串内重复书写不叠加，并与偏好倍率共同生效。每串人数、提示词权重、屏蔽／排除、样张过滤和偏好保底仍沿用原规则；来源不足时提示，不回落到未选画师。手动选择替换来源须确认，取消不改变当前条件；保存来源 ID 和实际出现计数快照供重开编辑，源串后续修改不静默改变旧条件；使用「使用画师库」可清除来源恢复完整目录默认。有候选后该记录配置冻结，既有候选不重写；变更配置需新建记录。样张归画师库管理。首次无需先建画风记录；每串人数范围、本轮张数和最低／最高权重由用户在「本轮设置」直接调整；人数与权重各占独立一行，完整配置同步使用同一组控件。人数上下限相同即固定人数。默认权重 0.7～1.4，沿用 0.1～3.0、一位小数的规则，上下限相同可固定权重；开始新一轮或保存配置后随记录保存，切换／重新进入记录恢复。新条件只作用于后续抽取，固定只保留 Tag，所有画师权重每条配方重新随机；每轮固定有限配方，一次发起、逐张出图与保存，沿用既有 Key、整轮费用授权、后台互斥、暂停和历史；失败／取消不自动付费续跑。当前候选继续 Roll 时固定其画师 Tag，并明确沿用该记录的公共配置与 Seed。
- 每轮按当前总人数、固定 Tag、画师来源集合与权重范围重新抽取，不参考已保存组合，也不由候选推断来源、代数或偏好；保存配方只是留存结果，不作为下一轮的偏好信号，也不自动调用评图模型或推断画质。
- Roll 只有一个随机流程，不恢复全随机／固定画师／固定权重三个模式或随机组队抽卡流程。每串人数范围包含固定项，默认 4～4 位；在可满足锁定和偏好保底的范围内逐串随机人数，再补齐剩余画师。全部 Tag 的提示词权重独立随机，固定 Tag 不固定权重。固定项不能超过人数上限，候选池不足以满足上限时明确报错，不偷偷缩小范围。样张过滤只限制随机补位，显式固定的无样张 Tag 仍保留；历史覆盖项不能绕过过滤。
- 锁定、屏蔽和偏好集中在带样张的「Roll 画师」弹窗，两个设置入口复用同一弹窗。弹窗以图片为主，搜索、分类筛选与排序紧凑排在顶部；浏览排序与使用筛选共用画师库规则，包括热度、名称、收录串数与生成图片数升降序，以及已收录／未收录、已生成／未生成交集筛选；首次沿用画师库排序偏好、之后独立记住本页选择，切换后回到列表顶部，不影响锁定、偏好或抽取概率。倍率／保底与样张过滤收进按钮旁的小弹出卡片，手机同样按视口收窄；不向页面插入设置行或常驻侧栏，打开时不挤动图片；去掉教程段落和重复统计。图片与名称复用画师库的样张封面及信息栏，跟随同一套画师库图片布局、列数和全局磨砂信息栏偏好；瀑布流按实际预览比例排布，不用固定图片框制造留白，方形／竖图设置继续生效；完成操作放顶栏，不常驻底部操作条占用看图空间。选择勾选与边框表达锁定，图片和名字都能切换锁定。桌面宽图、手机双列，间距保持适量。卡片复用图库的悬浮、图片缩放与触屏识别，服从全局动效／减少动效偏好。点击封面切换固定 Tag；无样张保留空封面，由用户勾选只抽有样张的画师。封面共用画师库的样张组件：左上屏蔽、下方删除当前页，右侧依次为偏好爱心、生成、单卡版本；爱心常驻，生成、版本、单页删除与多图翻页按悬停、键盘聚焦或触屏长按显露。生成模板、版本隔离、费用确认、后台保存与单页删除保护复用同一逻辑，不另存 Roll 样张或追加分享入口；Roll 打开时沿用画师库当前默认版本，之后每张卡独立切换，仅更新该卡样张，保留搜索、筛选、排序、滚动、锁定与偏好，目标版本缺图保留空封面，不借用另一版或重读整个列表；屏蔽成功解除该 Tag 的锁定，卡片留在列表、可直接取消屏蔽。全局屏蔽沿用用户 settings、跨记录生效；旧记录排除项可在同一界面解除。手动粘贴固定 Tag 收纳在弹窗内；来源选择入口位于 Roll 顶部工具栏、靠近本轮设置，并在新建／编辑记录设置中与画师管理并列；入口图标右侧保留名称，下一行显示当前来源状态（已选串数与画师数，或「画师库」）。来源选择器沿用风格串大图偏好，并提供模型、收藏、待实测、标签 AND、搜索、创建／更新时间排序、重置及只看实际识别出画师 Tag 等条件；筛选组合生效且保留已选来源。详细来源概率、快照及替换边界见本节首条规则。随机选取默认数量为 3，从当前完整筛选结果中无放回选择有可用画师的不同来源串，替换选择草稿、置顶供手动调整并保留用户取消的画师；数量非法或可用来源不足时仅提示、不改选择。最终仍需用户确认应用，且不会自动发起 Roll。另有「使用全部风格串」快捷操作，读取本次窗口已加载的全部个人串，忽略搜索、筛选、分页和手动取消状态；按跨串出现次数聚合可用画师后直接替换来源并关闭，不需逐串选择或二次确认。无可用画师时提示且不改旧来源，仍过滤全局屏蔽；不自动 Roll，之后资料变化需再次执行才更新快照。来源切换、手选确认与关闭集中在顶部，来源窗不留底栏，为大图卡片保留完整高度。已选画师 Tag 清单从顶部按需打开锚定小浮层，保留勾选、出现次数和屏蔽状态，不插入列表行或挤动图片。
- 偏好由收藏库未归档的画师来源条目决定，画师库、Roll 和收藏库共享状态；无样张可收藏 Tag，以空封面呈现，不制造假图。取消偏好只归档该画师的收藏引用，不删除原图。抽中倍率默认 1（均匀抽取），使用滑条与数字框联动设置：常用范围 1～100 倍、步进 0.1，数字输入及旧记录的大倍率保留并扩展滑条上限，拖动降低时不收缩范围。调整倍率或保底不触发完整画师目录的筛选排序，两个入口的排除名单仅随真实覆盖项变化更新。保底默认 0（关闭），两者由用户独立设置并随记录／轮次条件保存；倍率是相对普通画师的抽中权重，与提示词权重分开。先扣除已锁定偏好，再从可用偏好中无重复补足保底，其余位置按倍率抽取；屏蔽、排除与样张过滤后不足保底，或锁定与保底合计超过上限，整轮停止并提示，不能用普通画师补齐。偏好名单跟随当前收藏，历史实际候选不改写。
- 每轮保存抽取条件快照（人数范围、权重范围、固定 Tag、偏好倍率／保底、样张过滤），供筛选面板回看并「沿用这轮条件」；新轮次不写模式，旧快照不改写。记录管理只显示轮次数、已出图与已存风格串数，不引入评分或排名。旧三模式记录继续读取，固定模式与单项锁定仅作为固定 Tag，旧人数范围继续保留，旧固定组超过上限时补足人数，既有候选、图片、轮次和原存储键保持不变，不执行数据库迁移或批量改写私人资料。
- Roll 页沿用风格串／历史／画师库的工具栏、图片显示偏好、卡片辅助操作和原位多选，不作为独立工具另铺一套界面；顶栏提供记录切换与管理、搜索、筛选、多选、Roll 主操作及风格串画师来源选择入口，不重复显示轮次与数量摘要，也不另设清除筛选胶囊。记录名在顶栏直接可见；Roll 主操作固定在横向滚动区外，窄屏始终可达，旁边用「张数 · 人数 · 预计费用」摘要表达本轮代价，完整数量／权重／样张过滤按「仅本轮」与「记录默认」分组收进下拉。自动列数最多四列、按实际可用宽度保留约 220px 预览，明确列数尊重本页设置或继承的全局偏好；手机沿用图片布局及详情覆盖层。候选卡片显示编号、所属轮次和画师权重；卡片辅助操作按悬停、键盘聚焦、长按显露，爱心常驻；详情直接保存完整风格串或送实验室，未选中不占空侧栏。未出图的候选不允许保存为风格串；生成中的候选在封面标出状态。
- 候选卡片底部的画师占比色带只承担「比例分布」一件事：等色相间隔、等明度的低饱和 12 色，段与段直接相接，只垫一层暗槽压暗插画、避免亮色画面把色带冲掉；按权重降序铺开，而颜色锚定画师在原串里的位置，所以排序后仍与详情面板的头像方块、权重条按颜色一一对应。超过 12 位画师时只画权重最高的 12 位，其余合并为一段中性灰，不循环复用颜色。已明确否定单色相深浅、纯灰阶、高饱和 6 色轮转，以及段间切 1px 缝隙：色带压在插画上，单色相会失焦，灰阶更像未加载的进度条，颜色若与画师身份无关就只剩噪声；4px 高度里切缝会变成梳齿状断口，还会挤占固定像素、让段宽偏离真实占比。
- 搜索按画师 Tag、中文名或编号，筛选含全部、已出图但未保存、已保存、待生成、已收藏、未收藏、回收站及轮次。收藏状态与卡片爱心共用收藏库判定、即时跟随，只针对已出图的未丢弃候选，未出图配方不算未收藏图片；多选在全选／反选之外提供「选择已收藏图片」「选择未收藏图片」，范围是当前筛选结果并替换已有选择；多选时卡片爱心让位给勾选框，已收藏图片在勾选框旁显示只读实心爱心标记。全部如实显示未生成配方，数量指当前展示范围。详情上一张／下一张遵循当前筛选、轮次与排序，首尾禁用对应方向；保存、收藏或取消收藏使候选离开「已出图但未保存」「已收藏」「未收藏」结果时，依次选下一项、前一项，若结果为空则收起详情；这三类筛选在历史（收藏筛选另含收藏库）就绪前显示读取状态，不误报零匹配；收藏读取失败保持未知数量、禁用依赖收藏的快捷多选并提供就地重试，助手 favorite 返回 null，成功后才恢复真实判定。中断后的补齐只针对当前未关闭出图批次中未生成且未丢弃的原配方，其他轮次缺图可多选后明确生成。上游错误网页在共用链路转为简短说明，保留真实 HTTP 状态与业务错误码；生成失败不以刷新记录冒充重试，提示可关闭，通过「补齐剩余」主动续做，已有图片保留。单项／批量丢弃只写可恢复状态，不删除原图或已存风格串；回收站中的已归档候选可由用户确认后永久清理，原图与已保存风格串仍保留。记录支持重命名、新建和可恢复收起。每条记录最多 240 个候选，界面显示剩余容量并在将满时提示新建记录；批量保存逐项继续并反馈已保存数量、失败候选编号与原因，重试只处理失败与未处理项，成功项不重复创建；保存关联遇到并发版本变化时先回读最新记录，无法确认时暂停后续项目并保留未处理项。
- 用户已明确取消 Roll 串的画风对比、投票／Elo 排名、进化评选、自动权重测试、换 Seed 验证和手动逐项调权界面，不得以可选工具或盲选等形式自行恢复，不提供排名、评分、两两比较或自动进化。

- 画师库与 Roll 双向可达：画师库多选后可直接「在 Roll 中固定」并新建画风记录；Roll 候选详情显示画师样张缩略图，可带画师名跳到画师库搜索。两个入口复用既有固定画师与样张数据；只有用户明确设置的偏好倍率或保底影响抽取，不产生评价任务。

## 3. 画师／角色目录

- 画师与角色提供个人多分组，顶栏文件夹图标按需展开，默认收起，分别记住本端浏览分组与收展偏好；桌面展开紧凑侧栏，手机展开下拉导航，保留大图空间。全部、未分组及自定义组显示完整有效目录的成员数，不受搜索、当前样张版本或分页限制；每个精确身份在同组只计一次，多归属在各组分别计数，已不在目录的旧身份不计。目录／分组读取中或失败显示未知，不冒充零；角色完整轻量名单只在展开导航或查看分组时按需读取并复用，不为计数加载原图。侧栏标题行的加号直接新建，选中自定义组后同排铅笔改名、垃圾桶确认删除，沿用风格串文件夹的按钮、行图标和选中样式，不将新增入口藏在管理窗口；按现有多选批量增加／移除分组；电脑支持把角色、画师及 Roll 画师卡片直接拖到自定义组追加归属，拖动已选卡片携带全部既有选择，未选卡片只处理自身，不改变选择或抽取条件。原有其他组保留，已在目标组不重复保存，全部／未分组不作为拖放清空归属的入口；外部文件和取消拖动不写入，失败保留条目与选择供重拖。手机与键盘继续使用设置分组。部分归属显示部分选中，未触及组保持每条原归属，失败保留草稿。删除分组仅移除归属，不删条目或图片。画师使用精确原始 Tag 身份，V4.5／V5 共用，归一化相似的独立名字不合并；角色按 catalog:Tag 与 custom:chainId 区分，同名不串组。分组按类型与用户保存在已有 settings，新增可选 parentId 承载层级，旧缺失字段按根层只读兼容；共用目录树组件，父组包含后代且去重，删父仅提升直接子组并保留成员。原子版本保护并发，无新 schema 或旧资料迁移，完整备份自然保留。
- 分组与搜索、收藏／偏好、样张、角色范围及使用统计取交集，对完整可用目录先筛选再分页，不把尚未加载的组员当作不存在；画师库在原文件夹导航内统一选择「全部画师／偏好画师／已屏蔽」，替代筛选中的重复收藏开关；状态与全部／未分组／自定义分组、搜索、样张及参与统计取交集。手机仍在原按需展开导航内选择，不增加顶栏或常驻栏；收起保留当前范围，文件夹按钮提示生效状态。分组计数继续表示完整有效目录归属数，页面计数表示当前交集结果；名单读取中或失败明确反馈并可重试，不冒充零匹配。爱心和全局屏蔽按共享现状即时更新，不补造已离开真实目录的历史 Tag，也不引入 Roll 当前记录的锁定／排除状态。主动切状态退出旧抽取并回到首批顶部，成功抽取按原规则清除浏览状态；状态浏览与抽取排除选项、归类及真实偏好互不改写。普通全部浏览仍走原分页。角色复用完整轻量检索记录及同一中英文、多字段匹配和相关度排序。库页随机浏览保持本次集合及原概率模式，只在当前分组可用池内选取，切组退出旧批次，收展保留查询与选择；组内角色混抽在一类不足时可由另一类补足，不回全库，只抽自定义不依赖 Tag 目录就绪。Roll 管理画师弹窗复用同一画师分组元数据，但浏览分组与展开偏好独立；分组筛选及归类不改变固定／偏好／屏蔽、Roll 来源、概率、提示词或生成参数，不自动生成。

## 4. 外部图库、收藏与图片反推

- AITag 搜索／月榜的 404 只有在携带完整分页字段、零总数、空 items 且无错误标记时才视为在线无结果；与官网语义一致，不触发离线缓存提示。详情／配置的 404、访问限制、服务错误与损坏响应保持失败语义，不用空列表掩盖。

- AITag 作品卡片左上角不再显示 NAI 字样，常驻圆形风格串收录状态，与右上收藏浮层共用尺寸及承托；未收录用叠层风格串加右下叉，已收录用绿色叠层图标加右下勾，保留多语言悬停名称和辅助阅读。状态与「风格串已保存」筛选同源，作品组有任一页已保存即为已收录，不冒充整组已全部保存；风格串来源关系变化即时刷新，不新增持久字段或独立保存开关。

- AITag 浏览结果按数值作品编号去重，同页或跨页重复只就地补充资料，迟到摘要不得抹掉已有首图元数据、本地图片或完成状态；收藏取消仍按最新明确结果生效。同一查询与筛选下，资料晚到而新命中的作品接在已显示结果之后，不插到正在浏览的作品前方；主动改变条件或跳页才按新结果重新分列。模型识别及条件判定按真实资料复用，相关资料或条件改变即失效，不缓存未知结果为永久结论。首图远程转本地时复用已显示节点至新地址加载成功，失败仍沿用候选、重试及原页出口；缩略图取整的微小比例差不反复改写布局，明显比例变化仍修正。

## 5. 历史浏览

- 顶栏按「时间、只看收藏、更多筛选 ｜ 排序、随机浏览」排列；模型、生成方式、来源与可选关键词收在更多筛选，不常驻通用搜索框。始终单行，不平均拉宽填满；剩余空间不足时将时间收回筛选并压缩图标。

- 后台新图不打断旧图浏览，取消收藏／删除当前图后继续邻图；返回恢复列表位置和卡片。列表按真实比例完整呈现，大图、下载与编辑使用原图。

## 6. 统一创作工作台与编辑模式

- 生成过程预览使用后台任务的实时推送，四模式、电脑、局域网手机与独立 Android 共用；普通与流式请求共用 Vibe／精准参考解析、模型与模式校验和计费输入，官方直连或支持流式响应的兼容中转可带参考预览，复用已有编码不额外编码，成员网关继续普通生成；优先最新进度与最终图，积压时允许跳过已被新图替代的过程帧，不再逐帧等待绘制；状态、历史和告警仍完整交付，不能跨保存或终态串图。本轮总步数随任务保留，重新进入工作台不取新草稿或空组件计数。过程预览开关只控制上游过程图，关闭时仍优先实时观察任务，断线才退回查询。后台任务的 ZIP 成图与原生流式成图共用提前交付：完整成图校验后立即开始保存，与记账、公共队列收尾并行，最终图保持可见并明确显示「正在保存…」；保存与必要收尾都落定后才发布完成计数、交接执行位和终态，保存失败也先收齐收尾回执，不再生图。公开 ZIP 接口保持原有字节和记账头部语义。编辑历史的估算费用沿用本轮结算快照；统计、关联与封面维护可并行或批量处理，但不能丢到无人等待的后台任务。后台只保留最新帧用于重连，旧帧不写入私人存储；隐藏页不回放过程，回前台补查真实进度与结果。观察断线只重连或查询同一任务，不重提交生图、不取消后台执行与保存；新一张的过程预览优先于上一张历史，保存失败仍保留未保存产物。

- 连续请求间隔收进现有生成箭头菜单，与张数设置对齐，四模式、桌面／手机共用。默认显示 2.0 秒，可直接输入 0.0～3600.0 秒，也可用加减按钮每次调整 0.1 秒；按钮以整数十分之一秒归整，编辑后点按只保存最终步进值，保存期间禁用。输入、按 Key 保存及实际等待均保留一位小数，旧整数设置继续有效；0 只关闭额外缓冲，不解除单并发、暂停、失败停止或费用确认。按 Key 复用既有队列偏好持久化，独立于公共队列开关。第一张立即开始，后续从上一张历史保存完成计时；新任务、插队与旧任务恢复不重置同 Key 时钟，暂停经过的时间也计入。调整立即影响后续请求，设置和迟到回执不能串 Key。后端在普通／流式与无租约请求准入再次核对，所有页面、连接同一工坊的手机与 Agent 遵守同一间隔；独立后端仍各自协调。限流、未知结果不自动重试，2 秒为项目选定缓冲，官方未公布保证安全的间隔。
- 电脑与手机实验室共用任务分区：文生图按「全局／角色／参考／参数」，图片编辑按「底图（画板／画布）／提示／参考／参数」显示当前分区。「角色」只放角色提示词；Vibe 与精准参考（Precise Reference）集中在「参考」，保留两个模块及各自控件，不增加子分区。精准参考的「角色／画风／角色与画风」是参考类型，不能把整个功能称为角色参考。参考分区随当前模型与编辑模式的实际能力显示，均不支持时隐藏（当前 V5 系列如此）；若正在参考页则回到文生图的全局或图片编辑的底图分区，不清除已有配置，也不自动编码。第二层按实际分区数量等宽排列，紧贴主模式顶栏下沿、按首尾模式按钮的实际边界收紧居中，保留中央连续底板、整体轮廓与顶栏材质，不增加工具行。编辑方式切换和全局随机搭配移入右上公共工具区：单个无文字按钮以文本行／树状列表图标分别表达当前整段／分类状态，分类启用时使用选中态，悬停与可访问名称说明当前状态和切换动作；随机搭配使用骰子图标，撤销仍紧邻。全屏电脑工具行使用纯图标；窄屏或桌面窄栏进入右上「更多操作」后，两项均沿用其他菜单动作的图标加文字、各占一行样式，不单独保留图标小排，也不挤占模式导航；现有撤销填入在菜单里同样使用文字行。随机搭配只在分类编辑显示，包括各角色的就地入口，整段不显示；切换只改变编辑偏好，不改已有创作内容。随机对话本身保持稳定挂载，宽窄布局变化只移动触发按钮，不关闭对话或丢失临时编辑。选中项保留薄内边距，填充与文字颜色和顶栏一致，以较低高度和次级字重区分层级。按实际按钮边界适配窗口和助手宽度；预览保留右侧。手机保留完整宽度和至少 44px 触控高度。分区切换保留字段与画布挂载、折叠状态及各自滚动位置，支持键盘切换；模块按所属分区的固定顺序展示，不再提供自定义排序；四模式各自保留默认展开偏好与手动展开／收起，默认全部展开（含 Vibe 与精准参考），设置里的四个实验室页面分组默认展开；电脑及手机均可在「实验室模块默认展开」调整，单模式及全部恢复默认只影响展开偏好。旧排序不再读取或写回，已有默认展开设置继续沿用。连续玻璃编辑面只承托当前分区的实际内容，原有独立不透明度保持。
- 风格串／自定义角色与自由实验室共用工作台、模式导航、公共工具与参数／预览；新打开预设从文生图开始，后续按条目恢复会话模式，独立于自由实验室。四模式各自保存 Prompt、负面、模型与编辑参数，隐藏不清底图／蒙版。作品预览不铺衬底，透明底作品直接透出背景，不绘制棋盘格。
- 随机种子标题右侧使用「强制置空 ON/OFF」小开关，四模式、风格串／自定义角色工作台及桌面／手机共用既有全局生图偏好并持久保存。ON 时输入框留空且禁用，生成使用随机种子；OFF 时恢复当前草稿原种子并允许编辑，原值未设置时显示随机。切换只改变偏好，不清除或改写预设、历史与各模式草稿里的原种子。
- 四模式及桌面／手机的生成入口统一「生成」与费用提示，未就绪直接显示底图读取、画布加载、缺选区／蒙版或待应用扩展的实际原因；普通单张沿用已有提交检查与费用快照，不等待订阅／官方规则联网同步；后端任务准入共用。桌面编辑与手机共用排队、取消及生成步数反馈，区分准备、加入、等待与即将生成；公共队列阶段、前方任务数、总数及当前使用者随后台任务查询／实时回执传回；生成主按钮右侧使用人物图标小按钮显示「前方任务数／队列总数」，仅当前 Key 勾选多人拼车公共队列且有本次状态时出现。点击后在桌面锚定菜单／手机底部面板查看阶段、人数、使用者、步数与取消，不再常驻整行提示；关闭公共排队立即收起，切换 Key 同步更新并拒绝旧设置的迟到回执。它独立于本机有限队伍的张数进度，不因关闭连续生成而隐藏。零与未知保持区别，中转不虚构人数；取消期间显示「取消中…」，任务结束立即恢复下一次操作，旧任务／旧 Key 的迟到状态不覆盖当前任务。
- 各创作入口与内置 Agent 共用按 Key 的后端单并发与暂停状态；有限任务由运行设备后台托管，单张准备、请求、回贴与历史保存共用执行位。切页或进入后台不释放任务，不依赖浏览器心跳；普通新请求在同 Key 忙碌或暂停时被拒绝，只有主动入队可以等待。队尾等待前序任务完成；排到下一位以当前图片落库为交接边界，插入任务执行完再继续原任务余量，多次插队最新优先、嵌套插队保留余量。准备阶段暂停可直接继续，只有真实请求／保存期间显示「暂停中…」，不能因额度检查卡死恢复入口。暂停收回并保存当前图片后保留任务，主动继续才恢复；追加或费用补充授权不覆盖用户暂停。跨客户端取消给出明确 cancelled 终态，不冒充租约过期；取消在途任务先保存已提交产物。普通／流式、直接请求与 Worker 入口共用准入，公共队列清理完成前仍独占。独立 Android 工坊复用同一状态机；任务全程前台服务与 CPU 保活涵盖等待、间隔、图像处理和保存，按 Key 指纹与 token 独立计数，结束即释放，不跨独立工坊协调。
- 开启连续生成与排队时，四模式、桌面与手机的生成栏以主按钮为中心：左侧小按钮使用图片图标，显示同 Key 队伍的 `a/b` 与暂停／继续图标，`a` 只计成功保存的图片，`b` 为本轮已完成及剩余全部任务；追加／插队增加总数、取消剩余任务减少总数，完成后保留结果至下一轮。主按钮显示「生成／加入队列」、当前新批次的张数及预计总资源消耗，箭头在同一按钮内，桌面主按钮独立对准预览区中心，图片进度与公共排队小按钮分居左右并留相同间距；主动作、张数与费用相邻；主按钮恢复 1.50.1 的图片图标与留白，桌面以 320px 宽、至少 44px 高为基准，两种模式和费用显隐共用尺寸，空间不足时收缩并给两侧小按钮留位，手机有公共排队按钮时允许主按钮收窄、内容换行，保留至少 44px 高的紧凑胶囊入口。真实准备、生成、保存及已保存后的短间隔显示原有流动渐变和光点，暂停／排队等待／费用待确认停止；暂停中仍在收图或保存时先保留特效。动画依据后台任务状态及当前 Key 的公共队列状态，不以未完成张数冒充执行；生成期间主按钮仍可加入队列，箭头仍可插队，不套用等待光标或禁用行为，减少／关闭动效沿用外观偏好。只有前台真实准备／生成或仍有未完成任务时主动作才变为「加入队列」，空队伍暂停、已完成进度和普通不可提交状态不构成入队依据。张数默认 1，以紧凑加减和直接输入调节；加入队列、排到下一位、等待列表与逐项取消收进箭头菜单，空闲／忙碌时均保留两种排队选择，复用桌面向上居中于主按钮的工具菜单和手机底部面板，菜单操作居中排布，队尾／下一位分别使用列表末尾／开头图标，不再独立摆放张数、队列按钮或剩余张数。画布未就绪不能提交；排队等待不锁定下一份文字草稿。
- 「连续生成与排队」位于「生图偏好与实验室」，默认开启，沿用本端生图偏好保存，旧设置缺字段时保持开启，不随 Key 或外观预设切换。关闭后四模式及所有工作台的新手动请求、费用展示均按单张，隐藏张数／间隔／追加／插队、队列 `a/b` 计数与无用空闲进度及箭头，普通单张从空闲到生成完成保留主按钮及已勾选公共排队的状态入口，不展示没有后续任务可暂停的暂停按钮，也不重新显示 `0/1`；主生成按钮保持常规最小宽高，不随菜单或费用文字隐藏而缩小，手机通用触控样式不能覆盖该尺寸。本端 Agent 的多张或排队请求明确拒绝，不静默降为单张，确认或准备期间关闭也不得投递未提交的多张任务。已提交任务继续，只有旧队列仍有后续图片或等待项时才保留暂停管理，旧暂停状态的继续与等待项取消仍可达，结束后收回管理入口；不自动清暂停，不影响公共队列／中转或其他设备的偏好。重新开启从 1 张开始，按 Key 保存的间隔保留。
- 已确认任务一次性提交固定提示词、参数、底图、蒙版、历史来源与费用授权；后端在进程内临时持有执行所需配置／凭据，不新增持久任务表、不迁移私人数据，每 Key 最多 50 个等待项。前端只读观察真实进度和保存回执，临时断网或页面冻结不结束归属，回前台立即补查；投递回执丢失用同 token 核实，重复投递幂等，不新建任务重发生图。随机种子每张重新抽取，固定种子照用；编辑每张使用同一原底图／蒙版，聚焦回贴保留选区外像素与整图坐标，结果不自动接回底图。保持每次 n_samples=1，历史保存成功才增加进度，再提交下一张；普通单张复用已有费用快照，不加联网门禁。连续与排队执行前核实共享额度，普通界面与标准权限 Agent 在费用上涨时进入待确认状态，确认剩余消耗后继续，后台不能替用户批准；完全访问的 Agent 任务沿用已授予的生图费用权限，直接继续，仍遵守暂停与失败停止；除成员网关明确缺少额度接口的受控降级外，额度无法核实、换 Key、生成或保存失败停止，不自动重试或补张。回贴或保存失败保留未保存产物供下载：回贴失败保留上游原图，回贴成功而保存失败保留最终图片，部分成功时已保存项仍进入历史、当前未保存产物保持优先展示与失败标记；预览在历史保存成功后释放，未变化图片不随每次状态查询重复传输，旧客户端仍可读取完整快照。记账与公共清理异常独立提示。关闭／刷新发起页发取消以停止后续，不自动恢复；运行设备退出、系统强杀或断电不承诺在途结果。明确取消 Agent 同时取消其后续及等待任务；request_generation.count 默认 1，只接受指定张数，全部结果含请求数、实际保存数和历史 ID，部分成功不能报整轮成功。
- 「记住上次生图设置」位于「生图偏好与实验室」，默认开启，按本端保存，不随 Key 或外观预设切换。同一板块的记忆内容分为参数设置、全局正向、全局负面、角色正向与角色负面提示词，默认全部勾选；主开关关闭收起细项且保留选择。参数包含模型、生成／编辑设置、模式与角色非文字配置；全局正向包含既有 base／subject 和风格模块启用，沿用工作台合并全局框，不猜词串语义或添加隐藏主体选项。跨重启只写入及恢复所选部分，已有全量记忆也按当前范围过滤；未选部分在自由实验室使用空值／默认值，在预设工作台使用该预设原配置，角色按稳定 ID 配对，只选角色词时仍保留必要槽位，未选的角色词不能从参数副本绕回。四模式与不同风格串／自定义角色各自独立；关闭主开关不读取或更新跨重启记忆，同次使用的完整会话草稿继续保留，改范围不清当前输入或取消任务，重新开启后按范围记住当前草稿。关闭不删除旧记忆，「放弃未保存修改」同时清除该条目的会话与持久副本，恢复的预设草稿仍标为未保存、不自动写回原件。持久副本不带底图、蒙版、结果或已应用的图片几何，应用更新临时草稿遵循同一范围。
- 自由实验室刷新或同次使用中重新打开时保留文字、参数及模式，跨重启恢复遵循记忆偏好；四模式的结果预览先留空，编辑模式的底图、蒙版、选区、扩图范围与旧来源关联一起清空；历史不自动选中或充当占位。同次打开内切模式保留各自底图和新结果，编辑生成／翻图／重置不覆盖文生图预览；「文生图最新」仍由用户主动取用。风格串／自定义角色工作台同次会话保持既有历史与编辑资产恢复，历史原图不受影响。
- 预设顶栏的身份／模式区只保留返回与模式导航；名称在卡片展示，信息编辑在卡片铅笔入口，手机长按卡片后可点，仅更新名称、描述、标签。工作台使用最新信息并保留草稿；已保存预设的保存菜单区分「保存修改／另存为新串」，自由实验室顶栏直接保存为风格串；实验室与已保存串工作台均可从角色卡动作区将单个角色命名后保存到角色库，有当前生成图时用作封面。
- 风格串／自定义角色有未保存修改时，离开确认提供「放弃并离开／继续编辑／保存并离开」；桌面将放弃放左侧，继续编辑与保存放右侧，窄屏依次纵排保存、放弃、继续编辑。保存为绿色主按钮，放弃为浅红次按钮，默认聚焦继续编辑；保存复用原有完整保存流程，成功后才到原目标页，失败留在编辑器并保留草稿。Esc、遮罩与手机返回按继续编辑处理，保存中禁止重复提交或关闭；不能完整入库的编辑模式沿用继续／放弃两种选择，不扩展入库能力。

- Tag 权重类型使用带明确选中态的「括号／数值」二选一，默认括号，选中已有同类权重时显示对应类型；切换类型不改原文，添加／转换由「添加权重」执行。中间统一显示倍率，括号类型只读、数值类型可编辑；按 [NovelAI 官方规则](https://docs.novelai.net/en/image/strengthening-weakening/) 将每层花括号换算为 ×1.05、方括号换算为 ÷1.05，多选按倍率比较，等价写法显示同一个数，不同倍率显示「不同权重」。显示最多六位小数但不据此比较或自动改写，未实际编辑的数值框失焦／回车不修改原文，明确转换使用完整换算值；数值包装保留最多十二位小数以消除浮点尾差，不再截为两位。已有权重加减按各组原值独立走一步，普通词按所选类型起步，不合并或统一倍率。括号加减每次调整一层，两个方向均经过无权重：`{{tag}} → {tag} → tag → [tag] → [[tag]]`；多词组连续经过无权重时临时保留组范围与整组选中，继续加减仍包裹整段，多个组各自独立并保留内部子组。无权重原文不写入隐藏标记或数值包装；取消该组选择、直接编辑、外部换内容、撤销／重做、删除模式或显式重新包装后清除临时分组，不作为持久数据。数值保持 ±0.1，Shift 为 ±0.01，实际编辑数值后回车／失焦应用。添加数值权重仍将多选词合并成组，添加括号仍按词分别包裹，移除权重、删除模式与撤销入口保持原位。
- 实验室、预设工作台等共用 Tag 输入框中，词库标记为画师或角色的匹配词在右下显示圆形资料按钮；普通 Tag 不显示。点击打开资料弹窗，显示名称、中文名、有效作品数及图片，复用画师样张／Danbooru 封面与已有图片悬浮操作、偏好、屏蔽、收藏、样张维护和费用确认流程，不自动生图。权重组中每个匹配词均可独立打开资料；分类依赖词库 category 标记，不依赖中文翻译是否存在。

- 参数来源与步数收费边界均可点按查看；参数详情的完整值与翻译失败原因使用共用说明浮层。说明操作不改变参数或取消已选 Tag，不发起模型翻译。

## 7. 创作参数与官方费用依据

- 成员网关接入绑定在保管箱 Key 条目，不设全局网关开关；成员 Key 必须显式绑定 HTTP(S) 地址，生成、订阅／成员余额和 Vibe 编码使用同一目标，桌面、局域网与独立 Android 同步。旧官方条目缺少地址时沿用官方与既有公共队列设置；成员接入优先于该 Key 的旧队列地址，设置中不展示第二个路由入口。Medium 使用实际模型 ID 与有效参数，不改写为其他档位、不维护第三方模型白名单。成员生成直接请求普通 ZIP，无实时预览、不尝试流式再补发；未配置或损坏接入拒绝，不回退官方，不跟随重定向。余额／额度明确标注成员来源，费用与张数仍是官方规则估算，不能承诺网关实际扣费或耗尽后的付费路径。本次复用既有 settings 条目，未引入资料迁移。第三方网关常只接受官方网页端的缓存字段，精准参考对网关统一改写为附原图数据的 `director_reference_images_cached`；只有网关额度接口明确返回 404／405／501 时，后台连续生成清除旧订阅快照并按无免费权益保守估价；费用超出原有授权时仍等待确认，其他错误与官方接口异常仍停止。桌面、局域网和独立 Android 使用相同规则，缺少订阅时成功张数照常记录，费用与 Opus 保持未知，不伪造结算。
- 成员网关的额度百分比在侧栏、设置、手机底栏／详情、提示与旧值说明中统一四舍五入显示两位小数，整数补零；原始额度、圆环进度、低额度判断、张数估算与费用计算保留完整精度，官方直连的显示规则沿用原样。
- 保管箱条目默认只显示脱敏 `pst-…XXXX`；「显示」为单条临时回显、不写入任何存储，关闭设置、切换或删除该 Key 即复位；「复制」经剪贴板取回完整 Key。Key 本体不提供界面编辑，改值须删除后重新添加。新增条目保存后立即成为当前使用项，预算、额度与排队随之切换，不额外确认。明文不回显到助手页面快照。
- V5 Full 的 High／Medium 作为同一模型的生成档位显式选择，默认沿用 High；四模式共用档位与限制；支持档位的型号将模型和 High／Medium 下拉排在同一行，档位按内容留宽，不支持档位的型号仍使用全宽模型下拉、不预留空位。Medium 的固定步数、采样器和负面预设显示实际值并灰白禁用，不支持的全局／角色负面词及 CFG Rescale 同样禁用；CFG、尺寸、种子及正向词保持可用。固定设置跟随官方运行时，旧缓存按已确认限制回退。切换只改模型档位，保留 High 的参数和负面词草稿，切回即可恢复；费用、真实请求与结果历史使用当前档位的有效值，不能把保留的草稿当作实际生效参数。官方所述默认消耗降低比例不作为固定费用折扣。
- 公共队列设置按 Key 保存，兼容 st-chatu 协调协议与通用 NovelAI 生图中转。填写完整 /ai/generate-image 或 /ai/generate-image-stream 地址交给该服务生图；其他地址作为 st-chatu 队列基础地址，不靠域名猜测。公共任务索引由 Key 指纹与 taskId 共同组成，同 Key 在途重复 ID 明确拒绝，不覆盖 controller；只清理过期终态，不因 TTL 丢弃活动记录。成图先交付，不等待 complete／leave 往返；内部独占保留到公共清理结束，清理失败由任务终态单独提示，不重发生图。中转会接收当前 Key、提示词及参考内容，界面明确提示；个性语仅对 st-chatu 生效，中转不虚构人数。「停止等待」只中断连接，服务端是否取消由中转决定；失败不自动重发或回退官方，官方费用估算不冒充第三方结算。
- 已移除低消耗模式及其设置接口、参数收敛与前后端拦截。四模式、普通／聚焦重绘及模型支持的参考能力直接可用，历史／灵感导入遵循用户选定模式，不因旧开关改道；旧设置原样保留且不读取，不迁移或清理私人数据。
- 生图偏好的免费步数锁仍是独立偏好；局部重绘保持新草稿默认聚焦，可随时手动切换，已有草稿保留明确选择。实际生成遵循用户明确选择的参数与图生图输出尺寸，不额外压低步数、缩小尺寸或暂停参考。
- Vibe 以官方网页协议为准：图片、模型与完整提取参数决定可复用编码，各模型独立匹配，未知提取参数保留未知；PNG 编码只使用图片自身可识别的模型，不继承当前草稿模型。不同完整参数的编码独立保存，兼容扩展表与统一只读视图保留旧表、旧行及编码文件；不能用重建旧表或修改模型／提取量占位来绕过旧唯一约束。手动新编码确认费用；切模型、导入或缺失恢复只复用已有编码，不自动付费补齐。兼容官方 `.naiv4vibe`、`.naiv4vibeBundle` 与 PNG 内嵌编码，导出使用官方文本哈希和类型；旧图片及编码保留，旧记录按已知模型键读取，不猜测改写。资料可重命名、归档、恢复，组合支持最多 16 项、重复参考、排序、追加／替换导入与独立保存／导出；强度保留有限负值与超过 1 的输入，多参考按绝对值总和归一化，附加费随官方运行时显示。保存回执核对素材、模型、提取量及编码哈希后才清除付费恢复记录，异常只补保存；在途编码仅在同 Key、同接入地址及同参数下合并。
- Vibe 详情导出整份资料的全部编码，不依赖选中变体，组合另行导出；保存完成与浏览器开始下载分别反馈，取消安静处理。永久删除只在归档详情开放，沿用统一危险确认及每日授权；资料或单份编码被风格串、历史、收藏、组合、持久设置、助手可恢复草稿或本端实验室草稿引用时拒绝，不自动解绑。后端保护已持久引用及在途生成／编码，删除核查至完成期间与其他资料写入互斥；未知或损坏引用无法核实时保留资料。跨设备、其他标签页尚未共享的临时草稿无法穷举，确认中说明此边界，不另建跨端租约或自动清理机制。
- 常规参数保持免费边界内的探索偏好，未明确要求付费高步数时不擅自放宽。尺寸默认优先贴近官方免费面积的 64 倍数，兼顾竖／横／方构图；现有竖横预设为 832×1216／1216×832，方图为 1024×1024，官方边界变化时一起审计。Scale 提示简写为「宽 × 高 · 免费像素范围内／超出免费像素范围」，去掉「当前输出」及像素总数算式，仅表达像素边界；提示紧挨标题右侧，倍率输入靠右，三者始终同排。空间不足时只在提示内部折行，不按宽度断点将整个提示移到标题下方，也不于滑块下方另设状态栏与分隔线。
- 文生图、图生图、普通／聚焦重绘及扩图共用官方计费依据：按实际请求尺寸、步数、活跃订阅、模型受限状态与参考配置判断免费资格；图生图使用缩放提交副本后的尺寸，聚焦使用裁剪后请求尺寸，扩图使用最终请求画布。
- 生成入口费用提示同源：零 Anlas 且模型不消耗 Opus 时显示「免费」，受限模型显示「消耗 Opus 额度」，付费估算明确 Anlas 单位；模型受限清单继续随官方运行时更新。订阅未知时显示费用确认中／未知且不阻止操作；已有快照后台刷新时继续显示该快照的估算。
- 免费资格、免费张数、模型倍率、最低费用、编码／参考附加费及公式系数由官方运行时同步，前端提示、确认、助手与网关估算同源；不能在局部控件写死价格。模型专属的步数项系数在首次向上取整前生效，不能混为整张费用折扣；模型能力按返回对象归组，变体继承基础模型的额度与能力，不能串入其他 switch 的标签。官方数值变化自动生效，结构未识别或字段损坏时保留最近完整规则并示警；旧快照缺少计费字段或沿用错误参考判定时须重新同步。验证按 `AGENTS.md` 执行，联网自检同时执行官方实际费用调用与基础计价函数；官方共用判定函数在费用、重试等不同调用处的输入不可混同。
- 实验室保持打开时继续订阅运行时更新。Key 激活与启动不等待官方常量同步。手动／Agent、四模式、ZIP／SSE 复用已有订阅快照并后台刷新，不额外联网校验，不附加费用上限拦截或同步异常确认；新 Vibe 编码保留原费用确认，不追加网关二次拦截。成功后只按该请求的生成前快照记账，订阅尚未取得时不猜测本地扣费；ZIP、SSE 与付费编码的记账异常均保留成功产物并单独提示，不能触发自动付费重试。完整最终图之后的上游断流仍执行本地结算，已收到记账回执之后的收尾断流不推翻回执；流正常结束也不能代替记账确认，成图已收齐但缺少有效记账回执时保留图片并提示状态未确认，不因此重发生图或重复结算；本地结算以每张成功产物／每次新编码的唯一凭据，将预算扣减、个人 Anlas／Opus 累计和用量事件写入同一 D1 事务，失败整体回滚；回执丢失后重复投递同一凭据只结算一次，内容冲突明确拒绝。只对本次凭据的本地断线／502／503／504 做至多三次投递，不重发生图或编码，不持久化待补账任务、不自动回填旧账；网关提示与日志只记录结算阶段／状态，不泄露 Key 或数据库错误原文。
- 启动没有近期完整规则快照时立即后台同步，不附加固定等待；健康快照先复用，把带宽留给页面。等待同步时共享驱动短间隔读取本地网关状态，完成后恢复分钟轮询，隐藏时暂停；不借此加密账号额度查询或重复抓取官方 bundle。未知／失败状态按真实健康记录展示，不能为缩短转绿时间撤销告警。
- 额度查询与官方规则同步分别反馈：已知额度显示真实百分比和额度颜色，规则同步异常使用独立琥珀点并提示估算可能过期，不把它画成 Key／额度失效；额度查询失败保留红叉及上次快照说明。侧栏折叠／展开、设置与手机资源详情共用该语义。
- 本地连接避免空闲回收与复用撞车：网关读取／写入 Worker 及保存历史使用新连接；Wrangler 的 ProxyWorker 经 Miniflare `outboundService` 交由 Node 禁用复用转发，旧 Miniflare 的 Node 回环服务取消 5 秒空闲回收。源码、快速开发和安装版启动入口共用项目内预加载，不修改依赖文件、数据库存储键或 D1／R2 绑定。Node fetch 自动解压回包后必须移除旧 Content-Encoding／Content-Length，不能让 Miniflare 再压缩并使原生 HTTP 调用方误读；升级 Wrangler 时验证两版运行结构、连接边界和压缩响应，验收包含实际 Pages 启动兼容日期及原生 HTTP JSON 读取，不以浏览器／fetch 自动解码通过代替。跨层回归只替换远端付费边界，使用隔离 D1/R2 检查实际历史上传、编辑回贴／蒙版、Roll 元数据、样张归档与 Vibe 编码读回；这些验证留在测试中，不加入日常启动／点击／生成前置流程。
- 本地预算和个人 Anlas 统计使用估算口径，历史参数不展示为官方实付价格。免费编辑不误扣 Anlas，只有受限模型的成功免费档请求计入 Opus；修正规则不自动回填、返还或改写旧预算与历史。
- 订阅 `active: false` 不据此判 Key 失效；非活跃 Opus 不沿用残留 usage 免费资格，可确认使用保留 Paid Anlas，由官方验证。官方余额不覆盖手动本地预算。

## 8. 创作助手界面与业务形态

运行行为、交流语言与生图 Prompt 策略直接维护在 [PROJECT_AGENT.md](../PROJECT_AGENT.md)；页面／文件工程契约见 [能力覆盖](./AGENT_WORKSPACE_CAPABILITIES.md)，这里仅保留产品形态与交互决定。

- 内置助手的用户界面名称为「创作助手／創作助手／Creative Assistant／創作アシスタント／창작 도우미」，设置、入口、来源标注及辅助提示统一称呼；相关模型、权限、会话等简称「助手」。内部 Agent 标识、接口、存储键与规则文件名沿用现有工程命名，已有用户资料和会话标题保留原文，不因改名迁移。
- 每次工坊页面／应用启动后首次打开助手默认新建对话，不恢复上次启动选中的会话；旧对话保留在列表供主动选择，不停止其已有任务。同一次页面运行内收起重开、切换编辑器入口及组件重挂载继续本次选中会话，并发初始化只创建一次；首次创建失败显示错误并允许重试，不静默退回旧对话。
- 生成队列、Roll、画师样张、提示词库、收藏夹、图片反推与本机资产都有专用助手工具；状态型能力通过页面已登记命令复用同一队列、费用确认与结果核验，不新增第二套后台任务状态。只读档可查询状态，写操作仍受权限与确认边界。
- 完全访问包含用户要求的四模式生图及其费用授权，无需再次口头询问或弹窗批准；预算不足、明确指定多张／排队及任务费用上涨同样沿用授权。标准权限保留逐轮确认，只读不能生成；Vibe 编码、删除和清空继续确认。权限由后端配置读取，不由模型工具参数授予；后台任务只捕获本轮授权，不扩展张数、不解除暂停、不自动付费重试。
- 读取当前页面及前景范围，聊天简短显示读取到的页面，用量直接可见；后台标题跟随只识别当前前景，装饰追光不触发页面读取，发送任务与实际操作仍读取完整最新状态并核验快照。不常驻旧草稿横幅与撤销按钮。权限在输入区，过程展开在聊天菜单，API 下方集中生图协作偏好。
- 聊天正文不按长度、逗号或 Tag 外观猜测提示词；分析、标题与列表保留普通 Markdown。明确标记 `prompt` 的围栏显示可复制的「提示词」框，带程序语言的围栏显示代码；无语言及 `text`／`plaintext` 围栏显示「文本」，旧对话保留原文与复制，不推测或改写历史内容。助手输出格式约定维护在 `PROJECT_AGENT.md`。
- 已发送的工作区快照保留在会话原位置，状态变化在末尾追加，以支持模型服务复用相同请求前缀；每次模型调用前仍读取最新页面，只排除采集时间造成的重复快照，不减少工具与资料查询能力。内部快照不作为用户消息展示、计数、编辑或重试，旧会话无需迁移，长历史按完整用户轮次裁剪；缓存命中以模型服务实际回执为准。
- 上下文圆环保留鼠标悬停与键盘聚焦读取，点按可固定／收起，点击外部、失焦或 Esc 关闭；手指离开不触发鼠标式收起，触屏扩大命中区域，数值与未知状态沿用原语义。
- 思考强度滑块的圆钮使用对应明暗主题的不透明底色，透光面板不能让填充轨道透过圆钮；最高可用档保留紫色与粒子效果，标题、触发器和无障碍文本均显示真实强度，不能将不同模型的最高档统一改名为 Ultra。点击、拖动与键盘调节共用释放吸附规则；保存时保持滑条可操作与焦点，只允许一个设置请求在途，后续快速调节保留最后档位，旧响应不能回拉当前预览。较慢保存才显示加载图标，保存期间暂缓发送，失败恢复最后成功档位并显示原因。
- 保持固定业务系统提示词、实时项目状态与原始对话调用工具；内置「破限模式」固定规则，默认开启且可关闭，注入创作向交付契约（直接给出可用成果，不以前置审查、说教或替代方案回避请求，覆盖创作、文学润色与敏感题材场景）；规则正文可在设置页直接编辑并原子保存到当前工坊，下一次助手任务生效，可一键恢复内置默认，不扩展为多套预设管理或酒馆 Agent 预设适配。开关由后端配置原子保存，进行中任务保持启动时规则，关闭即移除附加段，不改历史、草稿、工具或权限。桌面、局域网手机与独立 Android 共用语义，旧注入字段继续不生效，不清理私人文件。规则预览展示本项目实际附加段；本契约只作用于模型输出内容，工具权限、费用确认与网络层审核过滤仍由服务本身决定。
- 联网搜索默认使用免费源（DuckDuckGo HTML，失败回退 Bing RSS），不引入 Key 与费用；设置页提供「使用搜索 API」独立配置服务地址与 Key，留空时自动使用同地址的已配置连接（含自定义连接）。开启后优先调用兼容 DeepSeek Search/Fetch 协议的服务，按成功请求计费、失败或无结果时回退免费源，搜索词会发送给搜索服务。开关与地址由后端配置原子保存、下一次助手任务生效；没有可用 Key 时即使开启也只走免费源，不报错、不阻塞创作。
- 助手「连接 API」参考 DSH 自身的信息架构：默认「第三方模型提供商」从内置预设选择，填入 Key 后自动获取模型并选用首个；「自定义模型 API」保留地址、协议、模型目录与能力配置。预设仅作为填写辅助，仍按自定义连接保存；保存后自动设为默认，可在列表中编辑调整。
- 助手跟随实验室的整段／分类编辑：分类编辑时读取真实提示词目录，按 `directory:<目录ID>` 读写动态栏位，兼容已有固定分类键；画师串使用 `basePrompt`，全局主体与角色正文按页面顺序同各自分栏合并，角色正文作为补充内容保留。文生图中对不上现有分类的旧原文留在补充栏，图片编辑中则保留在画师串，不猜测归类；整段编辑不提供分类写入，明确拒绝而不改写到别处。修改已有角色按 ID 合并，只传要修改的字段，未提及的分栏、负面、坐标与来源保持原样。
- 任务循环优先完成而不是半路失败：超出模型预算时只在模型请求视图中折叠较早的大型只读工具结果，再裁剪旧轮次；原会话保留完整工具回执与顺序，需要详情时可按 ID 重读。输出上限随思考强度和模型能力调整；最终回复被截断时保留已完成草稿与工具结果并如实说明。单次模型请求采用无输出空闲时限及总时限；仅对尚无输出与 Token 用量的瞬时服务错误有限退避重试，取消、超时、鉴权／额度错误及已有输出不重试，也不重放已执行工具或真实生图。
- 循环防空转由程序判断：相同参数的成功读取允许再次查询；相同调用连续失败后才拦截并说明原因，成功写入会清除对应失败记录；连续三轮工具调用全部失败时停止。只读且不经页面连接的查询可同批并行，写操作、页面与工作区工具保持顺序执行。页面一次未响应后暂停逐轮读取快照，标签页恢复通信或间隔一段时间后再读。
- 不提供任务转向、后续追加或排队控件；执行时可保留下一条输入，结束／停止后由用户发送。可继续的限额、截断、超时与服务中断提示提供「继续处理」，须由用户主动点击；系统以当前草稿接续同一目标，不能自动续跑。用户主动停止、鉴权或额度失败不提供该入口。展开思考／工具过程跟随最新输出，主动上翻暂停跟随，返回末尾或重新展开后恢复。

- 连接器融入酒馆主题，紧凑且默认折叠；收起真正减少占用、仍可辨认状态，后台变化不擅自展开或打扰创作。

## 10. 创作足迹与使用记录

- 「创作足迹」是独立页面，桌面位于侧栏「记录」组，手机从历史页工具栏的足迹按钮进入；历史页在手机底部导航中保持高亮。页面不替代历史：足迹负责聚合与回看，历史负责逐张作品与完整参数。
- 覆盖本地可统计的全域资产：生成历史、风格串／角色、常用标签、Vibe 资产与编码、Roll 实验／候选／保存、收藏来源与收藏夹、创作助手会话与消息、当前本地预算与本机累计用量；画师、标签与角色从首次全量回填及后续增量维护的精简参与快照派生，时间范围覆盖全部现存历史，不再截断 4000 张；切换周期不重复解析原 Prompt。画师样张补全等辅助生成不计入作品、活跃、趋势、风格串与画师统计。
- 轻量 `local_usage_events` 账本记录生成失败、取消与受阻，以及后端成功生成／新 Vibe 编码的 Key 用量；只存时间、Key 指纹、真实模型、成功张数、估算 Anlas、Opus 张数与计费是否已知，不存密钥原文、Prompt、聊天或图片。成功用量在公共网关记录一次，覆盖桌面、局域网与独立 Android、四模式、Agent、Roll 和辅助样张；不依赖前台观察或历史图片留存，取消前已成功的图片仍计数，失败请求和已有编码复用不重复计数。旧版本缺少的模型／周期明细不猜测回填。
- 时间导航简化为周／月／年，默认打开当前年；三者都用下拉选择具体周期：周选具体周，月选年月，年选具体年份或「全部年份」，均不提供未来周期；所选周期联动作品/资产/事件统计。收藏概览汇总全部收藏，不随周期变化。热力图在周／月显示活动格，年显示年度热力图；全部年份时热力图显示最近一年。风格串按 `source_chain_id` 聚合，排除自由实验室（`playground`）、Roll 来源与导入文件名；已删除的串保留真实来源名。
- 概览、热力图日期、风格串、画师、角色、模型、标签与创作模式都可点回筛选后的历史；历史页接收足迹带入的一次性查询，不覆盖用户之后的手动筛选。排行是个人使用频率，不做评分、公开排行或社交对比。
- 热力图下方、风格串与画师排行上方以通栏「Key 使用量」替代原成本区的用量展示；桌面逐 Key 对齐别名、已记录图片、V4.5、V5、Anlas 估算与 Opus 张数，点击该行原位展开真实模型及新记录的生图／编码费用。手机及侧栏挤压后的窄空间改为纵向条目与两列消耗，展开明细同样按可用宽度重排；主列表只展示保管箱现有 Key 及正在使用的 Key，无法匹配的旧指纹默认折叠到「未关联的历史用量」，不能当作新增的可用 Key，也不删除或擅自合并旧记录。只标记当前使用项，不在统计页切换生图 Key。
- Key 用量随已有周／月／年及具体周期联动；时间选项兼顾用量记录的起始日期，没有历史作品时在 Key 区保留具体周期选择，不因删图而无法查询旧用量。「全部年份」的 Anlas／Opus 优先展示原有累计（含旧版及其中已计入的新消费），不与新账本二次相加；其他周期仅用有日期的新明细，旧累计仍在详情保留。图片总数与模型分布明确为已记录部分，旧版缺失明细显示「—」，不能以零冒充，也不能用 Opus 张数冒充 V5 全部生成数。其余创作资产仍属整个工坊，预算与官方余额沿用原入口。
- 进入足迹与刷新时先读取轻量 Key 用量，再发起历史聚合和资产查询，避免争用本地后端而延迟用量展示；切换周期同样先读对应周期用量，不重复加载与周期无关的资产。历史参数按组合一次聚合模型、尺寸、步数、模式及参考使用量，画师／角色派生只读取所需字段；Roll、Vibe 和分组共用只读资产摘要，不向页面下载完整配方、候选 Tag 或编码元数据。资产摘要保留日期以便本端切换周期，分组读取失败显示未知，已知空分组显示零；摘要、助手会话与收藏各自就绪后展示，不等待最慢分组。用量读取失败仍继续加载其他统计，离开页面取消摘要读取且不追加尚未发起的查询；每次进入与主动刷新读取最新本地数据，不以过期缓存冒充新结果。
- Opus 用量表达为计入免费额度的成功生成张数，不能拿共享余额前后差当作本工坊消耗；Anlas 沿用本地估算，不冒充官方或成员网关实付。缺计费快照仍记录成功张数，点数和额度显示未知／已知部分；用量写入异常保留成功产物并单独提示，不重发生图。原失败／取消／受阻在底部「生成结果」保留全工坊、所选周期口径；外部图库浏览与助手 Token 目前只从收藏来源和会话元数据派生，不记录每次浏览或聊天内容。
- 提供 CSV 导出，只包含聚合名称、数量和时间，Key 行附所选周期及费用／额度口径；已有累计单列并标记「累计（含旧版）」，没有新版明细时不导出伪零张数，不导出指纹、密钥、Prompt、聊天或原图；统计不自动生成、不自动消耗、不自动重排收藏。
