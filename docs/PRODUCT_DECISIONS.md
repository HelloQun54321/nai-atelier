# 产品决策记录

本文按模块保留影响后续维护的已确认约定与明确拒绝的方案，2026-10-04 从原产品宪法整理。修改相关模块前阅读对应节；长期原则见 [VIBER_INTENT.md](../VIBER_INTENT.md)，维护规则见 [AGENTS.md](../AGENTS.md)。用户新决定直接修订对应条目，历史过程查 CHANGELOG 与 Git，不在这里累计每次修改。

## 1. 共用界面、窗口与分享

- 所有确认类型提供默认不勾选的「今日内不再显示」，包括删除、费用、存储迁移与恢复；按本端本地自然日及稳定操作类型分别记住，不按翻译标题分类。只有勾选后明确确认才保存，取消、Esc、遮罩或手机返回不授予授权；跨日恢复提示。费用按 Key／接入、金额／张数及预算风险状态区分，迁移／恢复按实际目标区分，普通余额递减和删除另一张同类作品不应制造新类型。偏好只保存作用范围摘要，不能持久保存 Key 或请求体；存储不可用时仍可完成本次确认，后续继续询问。离开编辑器区分「放弃／保存」，记住保存后仍每次执行真正保存，成功才离开；失败保留草稿。参数、文件选择和恢复口令表单仍由用户填写，当日授权只省对应最终确认；内置 Agent 不能代用户勾选扩展当日授权。

- 桌面侧栏将 AITag、法典、Danbooru、Pixiv 按原顺序归入「素材浏览」，工作区、画师库、角色库、收藏库与历史仍直接可达。展开侧栏时该组原位折叠，默认收起，按本端浏览器记住手动展开状态；切页或整体折叠不覆盖该偏好。当前来源子项高亮，收起分组时父项仍标明当前来源；「素材浏览」入口使用叠放图片图标；整体收成图标栏时点击在右侧打开按四项内容收紧的来源菜单，减少面板宽度、行高与留白，触屏仍保留可靠点击高度。选择后收起，沿用共用浮层的视口避让、背景拦截、Esc／点外关闭及焦点归还。手机保留原有底部导航与资源库面板，各来源页面及浏览状态继续独立，不增加自定义导航配置。

- 资源图片卡片默认让图片铺满卡片，名称和辅助信息叠在底部渐变磨砂区，上缘渐隐、正文清晰，保留原图比例与必要卡片间距；纯文本条目继续使用文字卡片。覆盖风格串、画师、角色、法典、外部图库、浏览足迹与收藏，页数和封面翻页不遮挡文字或图片操作。鼠标悬停以轻抬、微放大和阴影表达浮动。外观提供「全图磨砂卡片」「卡片悬停浮动」两个默认开启的独立开关，随本端偏好及外观预设保存；关闭磨砂恢复图下信息栏，关闭浮动保持静止，触屏及减少／关闭动画时不浮动。此为卡片展示细节，沿用产品宪法中作品优先、静止克制的原则。

- 界面提供简体中文、繁體中文、English、日本語与 한국어，默认简中；选择按当前工坊浏览器保存并即时更新控件、日期和数字格式，切换不重挂载编辑器或清空草稿。内置助手下一次请求跟随所选语言，历史对话、Prompt、Tag、作品原名、用户标签与资料原文保持不变。语言字典内置，不依赖运行时在线翻译。Windows 启动提示与托盘同步保存语言，安装器提供同样五种语言。
- README 入口提供对应五种语言的使用说明，菜单名对照界面译文，安装／更新命令、路径、费用与数据边界保持一致；专项技术文档与变更日志继续以简中维护，不能将界面语言支持表述为 Tag 词库或私人资料自动翻译。

- 用户已恢复独立 Android APK，首次范围为完整工坊：四模式、图库、Agent、按需下载的本地反推。共用 React 手机界面与业务规则，手机独立持久保存资料、原图和凭据；词库、模型按需下载，不把开发者缓存装进 APK。已有局域网入口继续可用，电脑数据及存储定位规则保持原有边界。实现、验证与交付状态见[独立 Android 说明](./ANDROID_STANDALONE.md)。
- 独立 Android 与电脑分别保存事实源，不隐式迁移或同步；原件按内容去重，缩略图保留明确缓存上限，词库与模型可再下载。手机卸载会清除私有资料，完整备份必须包含凭据与会话并由密码加密，恢复先验证再确认替换；手机导出取得系统真实写入收据。Android Agent 使用项目工具访问资料，磁盘工具只访问应用内创作目录，不能把电脑绝对路径或桌面常驻监听当成手机能力。
- 项目版本只跟随电脑端迭代，Android 单独修复不推进显示版本；APK 使用独立递增构建号与原签名覆盖安装，调回显示版本也不要求卸载。手机图片继续长按显露原位操作，不增加常驻更多按钮；原生图片菜单与嵌套卡片长按不得抢夺工坊操作，输入文字仍保留系统选择／复制。大图按原图比例适应真实可用区域，打开与加载完成时不出现宽度跳变，窗口或详情区域变化后继续适配；统一双指缩放、触点双击放大／复原、单指平移；双指抬起一指后继续平移，缩放时不翻图、不触发长按，适应窗口时横滑翻图。外部详情点按进入大图，返回收起当前层并保留原详情位置。

- 同类按钮保持紧凑、一致的高度、基线和间距；保存用绿色，一般主操作用主题色，危险操作用红色，未保存修改确认框的「放弃并离开」使用红底白字；完成／禁用回归中性灰。抽卡是浏览动作，初次、再次与执行中均使用中性样式。
- AITag、Pixiv、Danbooru、法典、收藏库、画师库与角色库统一选择聚焦：有选中项时，已选卡片保持原亮度与明确边框／勾选，其余卡片沿用 AITag 的 70% 亮度；关闭详情或清空多选后恢复。覆盖图库浏览足迹、目录抽卡与各网格布局；该模式默认开启，可在设置中统一开关；关闭只取消其他卡片变暗与自动居中，不影响选择和详情，生成历史的批量选择不属于此模式。
- 手机作品详情是当前页面的覆盖层，返回只收起当前层并继续原作品位置；多层窗口逐层返回，后台保留的页面不响应前台返回。滚动由现有列表缓存／作品锚点恢复，浏览器历史不再重复恢复旧值。
- 共用瀑布流在列数不变、列表原序列未变或纯尾部追加时保留已显示卡片所属列，Agent／详情侧栏挤压、图片尺寸返回及页面隐藏造成的零宽度不重挂载旧卡片；筛选删项、插入、替换、排序或列数变化时按新集合重新分列；纯尾部追加以已有列实测高度为起点、计入间距后选择当前最短列，实测不可用时沿用估高，不让迟到尺寸的估算误差持续累积。风格串封面尚未载入时用有效的现有生成尺寸预留，真实图片比例优先，无封面仍保留原占位。风格串、画师、角色和收藏库主动改变搜索、筛选、来源或排序时清除旧滚动缓存与旧定位、从顶部显示新结果，条件变化即使结果仍是旧前缀也重新分列；普通数据刷新、尺寸更新、保活与详情返回保留位置。已有连续加载入口按最后一组任一列的实际末尾接近可视区域时追加，不等待最长列见底；普通网格保留列表底部哨兵，沿用原加载锁、失败重试与数量上限，不为手动加载页面添加自动行为。瀑布流优先使用图片真实宽高比，比例未知时先完整显示，加载后同步修正卡片高度；竖向／方形布局保留既有裁切比例。图片列表统一服从有效的布局及手机／桌面列数偏好，不再为画师／角色库固定六列；设置以范围选择器共用一组控件，提供全局默认与风格串、画师库、角色库、生成历史、收藏库、法典、AITag、Pixiv、Danbooru、Roll串的页面设置。各页面默认跟随全局，关闭跟随后独立保存整组偏好，恢复跟随则即时使用当前全局值；页面内抽卡、收藏筛选及浏览足迹沿用所属页面，不另拆设置。电脑明确列数支持1～7列，手机仍为1～3列；全局与页面独立设置、普通网格与瀑布流统一有效。明确列数优先，自适应按列表实际宽度决定，约180px为普通卡片最小宽度，竖向／方形同步；Roll自动布局保留约220px及最多四列。偏好按本端浏览器保存，旧全局值继续有效，与外观主题预设独立。自适应缩略图只在需要更高像素档位时更新，缩窄保留原档，固定档位与直接图片不监听宽度。Agent 展开时工作区一次让位，动效留给面板自身，避免整页卡片逐帧重排。
- 卡片与图片预览的悬浮辅助操作在触屏静止态按需隐藏，包含编辑、复制／下载、删除、设封面、上传、翻图、灵感选择与板管理；图片爱心收藏常驻且位于右上操作列最上方，不常驻「更多」入口。长按约 450ms 按电脑端相同位置与顺序原位显露，松手后保留，消耗本次释放点击；点外部、另一个对象或滚动时收起。超过 10px 位移、系统接管手势或离开取消等待，输入／选择器与已显露操作不启动长按。鼠标悬停、键盘可见焦点与 Agent 语义悬停仍可显露，混合设备按实际指针区分，触摸产生的粘滞 hover／普通焦点不能显露。主要生成、返回、保存与异常恢复入口保持直接可达；重要说明与被截断的完整值继续点按查看。
- 外观偏好覆盖按钮、输入、选择器、弹层、详情、启动门禁、错误态与滚动；主题、主色、圆角、密度、字号、材质和动画一致生效。来源／分类、用户自选色、作品像素、画布坐标与触控底线保留含义。
- 资料管理、预设选择、反推、导入与设置使用居中、共用固定外框的小窗口，随视口收缩、内容内部滚动，详情不改变窗口大小；短表单／确认框紧凑，大图与大画板保留完整查看语义。资料默认值须明确保存，与本次参数分开标注；本次参考选择与参数即时生效，简短提示归到完成按钮，不另占说明行，关闭／完成按钮不标为「应用」。
- 筛选弹层默认与触发按钮居中对齐，边缘可避让；模态打开时工作区与侧栏统一遮罩、虚化并停止背景操作。全屏返回按钮与危险操作拉开距离，左右翻图对称、按共用显露规则可达，不被侧栏遮挡。
- 简短操作菜单与只读说明使用共用锚定浮层，点外部、关闭按钮或 Esc 收起；透明命中层拦截背景误触，内容受视口约束并内部滚动，保留主题、安全模式、焦点与文本选区，不撑高原卡片。菜单卸载并归还焦点后再打开详情、编辑或确认窗口。
- 图片管理操作在左上；卡片、详情、小图与全屏的图片取用统一在右上竖排「下载 → 复制」，沿用历史页圆形图标及共用显露规则，提示和无障碍名称明确「下载图片／复制图片」。创作预览的管理、分享、封面、上传与返回统一圆形、边框和材质，保留移除的红色底、设封面的主题色底及清空／上传的中性深色底，不以统一外形抹平语义色；管理名称区分「移除当前图片／清空当前历史组」，均保留历史原图。设封面位于右上同组下方，上传在右下；小图与全屏保留同组管理能力，全屏左上用稍大的返回箭头并与管理操作拉开距离。触控设备保留 44px 命中区域，处理中使用旋转图标并保持按钮尺寸。安全模式不遮品牌，大图查看明确豁免。
- 列表缩略图由共用组件按可见范围加载，激活后直接开始取图；布局变化不隐藏同地址的已加载图片，失败重试重新启动加载。手机同地址的旧请求清理不能取消新请求；需要代理的远程图在原图回退时仍走代理。
- 图片清洗由全局可选开关决定，默认关闭；在「隐私与分享」页使用独立的「图片元数据清洗」板块，与安全模式板块并列，两者设置互不影响。「清洗内容」默认「全部生成信息」，沿用完整清洗；「仅提示词」移除整图及角色正负词和隐藏副本，保留图片中实际记录且可识别的生成参数，缺失值不补成默认值。不能把合并后的提示词猜分为风格与主体，或仅删画师标签冒充风格保护。自定义文本支持文字与 emoji，留空按所选内容清洗，填写后再将内容写入分享 PNG 的 `Description` 和 `Comment.prompt`，使用 UTF-8 文本块；仅提示词模式继续保留真实参数，不带回原词或补造模型、签名等来源信息。模式与文本按当前浏览器保存，关闭清洗时保留偏好但不应用。分享处只提供「复制／下载」，不新增「分享版／原图」旁路。开启后创建独立副本，失败不能静默输出原图；原始资产与完整信息保留。
- 默认记住最后使用的 Key，尊重记住偏好；预算与官方余额可紧凑展示，但展开／收起均可辨认来源与完整数值，保留未知、旧值和失败说明。排队人数为 0 也显示，未知不冒充 0；生成完成反馈不延迟下一次操作。
- 设置按功能归组：安全模式与名称隐藏、启动开启偏好归入「隐私与分享」；局域网访问归入「数据与维护」，手机访问地址由当前网卡及实际监听端口生成，可复制，不能写死 IP。简单勾选、相关输入与必要提示按可用空间同行，窄屏自然换行。
- Tag 词库更新直接使用「数据与维护」中的设置行：标题与来源／更新按钮同组，下方就地显示细进度条、状态、数量与生成时间，窄屏自然换行；不再为下载更新打开独立页面或弹窗。电脑下载复用工坊已有出站代理，失效的 jsDelivr 默认备用源移除；明确配置的备用地址继续支持，失败分别保留各线路原因，更新失败保留现有词库。
- 桌面侧栏保留预算／余额与 Opus；手机实验室四模式在底边中央将 `Anlas 本地预算/官方余额` 与 `Opus额度 百分比` 作为一组紧凑小字显示，两项只留小间距，不分别贴左右角，不使用独立卡片、圆环、钻石或收起说明，用小上箭头、点划线与按压反馈表达可展开。图片查看与生成继续并排独立操作；底部资源面板与设置「NovelAI 与 Anlas」共用完整资源视图，点数按本地预算／官方余额、Opus 按剩余额度／估算张数排成两列，明细和异常归到对应分组，刷新图标明确可操作。资源面板限制阅读宽度，订阅与同步时间的值紧邻标签、不拉向右边缘，相同数值与时间只显示一次；未知用占位、异常用颜色与符号，详细原因放入展开面板。图库／历史等浏览页不增加全站常驻资源条；各入口复用同 Key 的订阅驱动，点按余额刷新按钮或 Opus 行同步刷新。
- 首次使用明确并列 EXE 安装与源码本地部署，任选一种；普通 Windows 使用者优先获得安装包入口，部署工具与命令行步骤只归源码版，两种方式共用应用内词库下载与创作流程。Windows 提供可分发的 x64 安装版，面向 Windows 10／11，安装向导允许选择程序目录，有桌面／开始菜单入口及系统卸载登记，内置窗口、Node 和完整本地后台；使用者不需要 Node、npm、Git 或开发构建。安装版程序与数据分离，默认工作区位于 `%LOCALAPPDATA%\NAI Atelier\workspace`，不自动接管源码数据，卸载保留个人数据；重复打开回到原窗口，关闭窗口收进托盘，退出工坊才停止后台。源码部署仍在安装依赖后创建指向根目录 BAT 的快捷方式，启动／重启成功时检查修复，不生成桌面脚本副本；历史模板清理只限源码部署，自定义文件保留。构建、验证与分发边界见 [Windows 安装版](./WINDOWS_DESKTOP.md)。
- macOS 版与 Windows 安装版共用桌面壳、内置 Node 与本地后台，按构建机原生架构打包（Apple Silicon 为主），所有原生依赖不经 Rosetta。不做 Apple 签名与公证（ad-hoc），首次打开由使用者放行，因此不提供应用内自动安装，更新走下载页覆盖。遵循 macOS 习惯：原生红绿灯标题栏、标准菜单与 ⌘ 快捷键、关窗留在程序坞继续服务、⌘Q 才停止后台；不使用托盘。Windows 专属能力在 macOS 用系统原生方式实现（`scutil` 代理、系统选择面板、JXA 剪贴板监听、应用包 `pixiv://` 协议），只属于 Windows 的桌面快捷方式在 macOS 安装版不显示。细节见 [macOS 版](./MACOS_DESKTOP.md)。

## 2. 风格串、收集与筛选

- 用户已明确取消风格串「统一角色」模式，删除其入口、界面、角色替换／副本运行链路及旧独立对比接口，不保留兼容空壳或待启用功能；不得按此前方案自行恢复。

- 顶栏按「搜索、筛选 ｜ 智慧姬同步 ｜ 收集模式、批量导入、新建风格串」分组。收集是高频功能，保留直接入口；智慧姬同步仅在设置开启后显示。不额外常驻通用图片反推或手动刷新。
- 收集开关按 Windows 本机监听能力开放，窄窗口收起文字但保留可点击图标；局域网手机不远程启停电脑剪贴板监听，不因响应式补齐而扩展为手机收集功能。
- 模型、排序、收藏、待实测与用户标签集中在统一筛选面板。标签只用于用户自己的分类，不自动附加 NAI／AITag 类型、来源或照搬外部标签；多标签要求同时包含，编辑后选项即时更新，随资料扩展支持滚动／搜索。
- 「管理标签」紧邻筛选面板的「自定义标签」选择区，按当前资料类型的完整条目统计分类和使用条数，不受搜索、模型、收藏或待实测筛选缩小；支持搜索、确认重命名、目标已存在时合并去重、确认移除，只改各条资料的标签，保留其他分类、内部状态、提示词、生成参数和图片。沿用既有逐条保存与回读，不建立独立链标签目录或资料迁移；新分类仍从卡片信息编辑添加。成功同步已选标签筛选，部分失败回读真实结果并保留输入，回读失败先手动重新加载再继续；关闭窗口后保留原搜索与筛选，手机筛选返回完成后才打开管理，避免返回误关新窗口。共用自定义角色链与风格串分别统计，词库角色 Tag 和收藏标签目录保持各自含义。
- 风格串通过顶栏「多选」直接进入批量选择，窄屏保留图标与明确的「批量选择风格串」名称，不套单项管理菜单；所有模型均可选择，独立于智慧姬同步。批量操作原位替换固定顶栏，提供已选数量、全选／反选当前筛选结果、清空选择、删除与退出；窄屏在同一行横向滚动，不额外插入工具栏。图片与名称均可选择，左上圆形勾选，隐藏单条删除、编辑、爱心和分享；零选择仍保留多选模式，筛选变化剔除隐藏选择，类型切换退出。删除一次确认实际数量，确认及执行期间锁定选择和退出，逐项显示进度、完成后统一回读真实结果，只保留仍存在的失败项；回读失败明确要求核对，不能把旧快照或丢失回执当成成功。仅删除风格串配置，不删除已有历史或收藏记录；单条删除、更换封面及共用图片清理先提交条目变更，再核对其他风格串、收藏、历史与画师资料的引用，仍被使用的图片保留，不迁移资料或新增资产表。
- 风格串卡片的图片取用与编辑在封面右上竖排「收藏 → 下载图片 → 复制图片 → 编辑信息」，铅笔与图片按钮共用透明圆形样式；删除在左上使用与历史页一致的红色圆形按钮，确认后才删除，不恢复白色按钮组。收藏改为共用图片爱心，常驻且汇入全局收藏库，「待实测」标记位于封面左下。用户通过复制图片携带其中的创作信息，不需要独立复制风格串，取消对应按钮及组合复制弹窗，不另加替代入口；图片取用沿用现有原图与分享清洗规则。无封面仍保留编辑和删除，访客只提供图片取用，同步视图隐藏单图操作；除爱心外，桌面悬停／键盘聚焦、触屏长按统一显露，不缩小触控命中。批量导入候选移除也由长按显露，仅移出本次列表并释放预览，不删除原文件。
- 「待实测」属于风格串，实际生成成功后摘除；收集中／已暂停属于监听器，来源、时间、内部目录标记各自表达，不能混成资产分类。
- 置顶收集窗可拖动、折叠、显示进度，跟随主题和动画，后台更新不抢焦点；折叠仍可辨认状态。已有控制窗时，不在开关旁重复放状态菜单。
- 收集失败给出简短具体原因，网络中断不一概归因于代理；失败或未入队链接之后重新复制可再次接收，处理中与已完成链接仍去重。完整可见的详情不重复弹提示，截断长文本与折叠失败标记可查看全文；不自动重发，不增加已拒绝的手动重试或为少量重复建立重复率面板。服务重启后收集保持关闭，不自动恢复剪贴板监听。
- 智慧姬展开操作栏的具体重排仍搁置，不能把未定案示意图当成全产品布局模板。

### Roll 串画风探索

- 独立「Roll 串」位于电脑工作区、手机资源菜单，流程为「一键抽取并出图 → 保存喜欢的结果 → 再 Roll 一轮」。直接从现有画师库的完整 Tag 词库抽取，不要求手填、预先收藏、旧画师表导入或另建画师池；样张归画师库管理，缺图 Tag 也可参与。首次无需先建实验；每串画师数、本轮张数和最低／最高权重由用户在「本轮设置」直接调整，完整配置的抽取设置同步使用同一范围。默认权重 0.7～1.4，沿用 0.1～3.0、一位小数的规则，上下限相同可固定权重；开始新一轮或保存配置后随记录保存，切换／重新进入记录恢复。新范围只作用于后续抽取，锁定画师保留指定权重，既有候选不重写；锁定／排除与完整参数留在完整配置中。每轮固定有限配方，一次发起、逐张出图与保存，沿用既有 Key、整轮费用授权、后台互斥、暂停和历史；失败／取消不自动付费续跑。
- 每轮都从画师库纯随机抽取，不参考已保存组合、不记录候选来源或代数；保存配方只是留存结果，不作为下一轮的偏好信号，也不自动调用评图模型或推断画质。
- Roll 页沿用风格串／历史／画师库的工具栏、图片显示偏好、卡片辅助操作和原位多选，不作为独立工具另铺一套界面；顶栏只保留记录切换与管理、搜索、筛选、多选和 Roll 主操作，不重复显示轮次与数量摘要，也不另设清除筛选胶囊。人数／张数、权重范围及完整参数入口收进 Roll 按钮旁下拉。自动列数最多四列、按实际可用宽度保留约 220px 预览，明确列数尊重本页设置或继承的全局偏好；手机沿用图片布局及详情覆盖层。候选卡片显示编号和画师权重；卡片辅助操作按悬停、键盘聚焦、长按显露，爱心常驻；详情直接保存完整风格串或送实验室，未选中不占空侧栏。
- 搜索按画师 Tag 或编号，筛选含全部、已保存、待生成、回收站及轮次。全部如实显示未生成配方，数量指当前展示范围。中断后的补齐只针对当前未关闭出图批次中未生成且未丢弃的原配方，其他轮次缺图可多选后明确生成。上游错误网页在共用链路转为简短说明，保留真实 HTTP 状态与业务错误码；生成失败不以刷新记录冒充重试，提示可关闭，通过「补齐剩余」主动续做，已有图片保留。单项／批量丢弃只写可恢复状态，不删除原图或已存风格串；记录支持重命名、新建和可恢复收起。批量保存逐项关联、失败保留未完成选择，重试复用已保存链与封面。
- 用户已明确取消 Roll 串全部对比与调权功能：移除画风对比、投票／Elo 排名、进化评选、自动权重测试、换 Seed 验证和手动调权新变体，不得以可选工具或盲选等形式自行恢复。普通 Roll 只出图供直接挑选保存，不安排评价任务。
- 记录保存公共正负词、结构化角色、完整参数与固定 Seed；有候选后公共配置冻结，变更公共条件新建记录。候选只保存画师 Tag、权重、时间与保存关联，不保存来源、方法或代数。用户已明确清空旧 Roll 记录并取消对旧对比资料的兼容：投票、冠军、验证副本、进化／权重测试轮次、候选独立 Seed 与早期候选字段的兼容处理均不保留；本地记录与其生成图片已清空，不提供恢复入口。清空只涉及 Roll 专用记录与来源图片，不删除其他历史原图或已另存风格串，不新增清库或迁移机制。
- 结果可存为现有风格串或送往实验室，生成图片共用收藏与图片分享；保存封面独立持久化，原有历史不改写。实验沿用私人 settings，无数据库迁移；保存版本冲突明确重新加载，不静默覆盖。实现分析、参考来源和维护入口见 [Roll 串说明](./STYLE_ROLL.md)。

## 3. 画师／角色目录

## 5. 历史浏览

- 顶栏按「时间、只看收藏、更多筛选 ｜ 排序、随机浏览」排列；模型、生成方式、来源与可选关键词收在更多筛选，不常驻通用搜索框。始终单行，不平均拉宽填满；剩余空间不足时将时间收回筛选并压缩图标。
- 随机与重新洗牌共用位置，新图提醒不增加一行，多选操作替换固定顶栏。生成时间、收藏时间与随机发现分别表达；随机覆盖当前筛选全部结果，同次洗牌跨页、翻图及返回保持稳定。
- 后台新图不打断旧图浏览，取消收藏／删除当前图后继续邻图；返回恢复列表位置和卡片。列表按真实比例完整呈现，大图、下载与编辑使用原图。
- 历史卡片长按统一显露原位操作，不再进入多选；批量选择从「管理 → 批量选择图片」进入，多选期间单图辅助操作隐藏。
- 大图参数可收起，缩放拖动与滑动翻图避免误触；输入、前景窗口与确认不被快捷键抢占。历史图片爱心直接汇入全局收藏库，不再提供第二套加入收藏表单。
- 大图详情先显示操作，再显示提示词与参数；翻图回到详情顶部。「导入到实验室」统一提示词恢复与底图编辑入口，默认明确进入文生图，可选择图生图／局部重绘／扩图。有匹配操作的历史蒙版时可主动选择复用，默认清空旧蒙版；收藏使用图片右上共用常驻爱心，不再填写标题或选择目的地才能收藏。

## 6. 统一创作工作台与编辑模式

- 生成过程预览使用后台任务的实时推送，四模式、电脑、局域网手机与独立 Android 共用；每个收到的预览按顺序提交并留出前台绘制机会，相同图片仍更新步数，本轮总步数随任务保留，重新进入工作台不取新草稿或空组件计数。后台只保留最新帧用于重连，旧帧不写入私人存储；隐藏页不回放过程，回前台补查真实进度与结果。观察断线只重连或查询同一任务，不重提交生图、不取消后台执行与保存；新一张的过程预览优先于上一张历史，保存失败仍保留未保存产物。

- 连续请求间隔收进现有生成箭头菜单，与张数设置对齐，四模式、桌面／手机共用。默认显示 2.0 秒，可直接输入 0.0～3600.0 秒，也可用加减按钮每次调整 0.1 秒；按钮以整数十分之一秒归整，编辑后点按只保存最终步进值，保存期间禁用。输入、按 Key 保存及实际等待均保留一位小数，旧整数设置继续有效；0 只关闭额外缓冲，不解除单并发、暂停、失败停止或费用确认。按 Key 复用既有队列偏好持久化，独立于公共队列开关。第一张立即开始，后续从上一张历史保存完成计时；新任务、插队与旧任务恢复不重置同 Key 时钟，暂停经过的时间也计入。调整立即影响后续请求，设置和迟到回执不能串 Key。后端在普通／流式与无租约请求准入再次核对，所有页面、连接同一工坊的手机与 Agent 遵守同一间隔；独立后端仍各自协调。限流、未知结果不自动重试，2 秒为项目选定缓冲，官方未公布保证安全的间隔。
- 风格串／自定义角色与自由实验室共用工作台、模式导航、公共工具与参数／预览；新打开预设从文生图开始，后续按条目恢复会话模式，独立于自由实验室。四模式各自保存 Prompt、负面、模型与编辑参数，隐藏不清底图／蒙版。
- 随机种子标题右侧使用「强制置空 ON/OFF」小开关，四模式、风格串／自定义角色工作台及桌面／手机共用既有全局生图偏好并持久保存。ON 时输入框留空且禁用，生成使用随机种子；OFF 时恢复当前草稿原种子并允许编辑，原值未设置时显示随机。切换只改变偏好，不清除或改写预设、历史与各模式草稿里的原种子。

- Tag 辅助、反推及图片元数据导入作用于当前模式；安全模式、手机、主题、Key、费用与异常恢复覆盖全部模式和入口。
- 四模式与预设工作台的全局／角色正负提示词框共用就地清空按钮：中性橡皮擦位于框外已有操作区，全局正负词与复制并排，角色正向词位于卡片顶栏保存／引用等按钮旁，角色负面词和编辑模式正负词位于各自标题行；每个按钮只作用于对应文本，不嵌入输入框、不另造工具栏或为按钮挤占文字空间。按钮始终常驻，空框、只读或锁定时灰显禁用，不因文本为空消失；清空后可撤销时原位切换为可操作的「撤销清空」并恢复输入焦点，不增加确认弹窗。不删除角色、改变参数或风格模块开关。清空进入当前框的编辑历史，Tag 辅助或翻译关闭时仍可撤销／重做这次清空；新的编辑或外部替换不能恢复过时内容。清空同步退出标签删除、选择和补全，窄屏保留44px触控区。
- Tag 权重类型使用带明确选中态的「括号／数值」二选一，默认括号，选中已有同类权重时显示对应类型；切换类型不改原文，添加／转换由「添加权重」执行。中间统一显示倍率，括号类型只读、数值类型可编辑；按 [NovelAI 官方规则](https://docs.novelai.net/en/image/strengthening-weakening/) 将每层花括号换算为 ×1.05、方括号换算为 ÷1.05，多选按倍率比较，等价写法显示同一个数，不同倍率显示「不同权重」。显示最多六位小数但不据此比较或自动改写，未实际编辑的数值框失焦／回车不修改原文，明确转换使用完整换算值；数值包装保留最多十二位小数以消除浮点尾差，不再截为两位。已有权重加减按各组原值独立走一步，普通词按所选类型起步，不合并或统一倍率。括号加减每次调整一层，两个方向均经过无权重：`{{tag}} → {tag} → tag → [tag] → [[tag]]`；多词组连续经过无权重时临时保留组范围与整组选中，继续加减仍包裹整段，多个组各自独立并保留内部子组。无权重原文不写入隐藏标记或数值包装；取消该组选择、直接编辑、外部换内容、撤销／重做、删除模式或显式重新包装后清除临时分组，不作为持久数据。数值保持 ±0.1，Shift 为 ±0.01，实际编辑数值后回车／失焦应用。添加数值权重仍将多选词合并成组，添加括号仍按词分别包裹，移除权重、删除模式与撤销入口保持原位。
- Tag 翻译区直接编辑同一份提示词，末尾可输入、粘贴新词，并复用原文输入框的词库补全；候选只关联当前输入位置，跟随滚动与尺寸变化，不抢输入法确认或 Tab，选中候选后回车或失焦追加。Tag 列表可拖动右下角调整高度，底部工具栏保持在滚动区外，不持久化高度；正常点选仍用于权重调整，原说明与完整对照入口改为无文字的旋转箭头撤销。垃圾桶入口使用浅红底与红色图案，降低静止态的视觉强度；进入删除模式后原位隐藏权重语法与权重控件，组内每个词可独立多选、标红及取消。撤销留在左侧，取消与红底白字「删除 n 个 Tag」确认按钮并排靠右；确认后才改原文，取消或 Esc 不改内容，不增加工具栏行或确认弹窗。删除保留剩余词的原有权重、重复词按位置处理、空组连同包装移除。撤销覆盖输入、追加、权重与删除，支持 Ctrl／Cmd+Z、Ctrl+Y／Cmd+Shift+Z 重做；标签选中时 Ctrl／Cmd+C／X 复制或剪切对应原文（保留权重）、Ctrl／Cmd+V 追加、Ctrl／Cmd+A 全选，输入字段内保留原生操作。编辑记录仅属于当前输入框，外部换内容清除旧记录，只读或执行锁定时不可改写；四模式与全局／角色正负词共用同一组件，不自动调用模型翻译。
- 参数来源与步数收费边界均可点按查看；参数详情的完整值与翻译失败原因使用共用说明浮层。说明操作不改变参数或取消已选 Tag，不发起模型翻译。

## 7. 创作参数与官方费用依据

- 成员网关接入绑定在保管箱 Key 条目，不设全局网关开关；成员 Key 必须显式绑定 HTTP(S) 地址，生成、订阅／成员余额和 Vibe 编码使用同一目标，桌面、局域网与独立 Android 同步。旧官方条目缺少地址时沿用官方与既有公共队列设置；成员接入优先于该 Key 的旧队列地址，设置中不展示第二个路由入口。Medium 使用实际模型 ID 与有效参数，不改写为其他档位、不维护第三方模型白名单。成员生成直接请求普通 ZIP，无实时预览、不尝试流式再补发；未配置或损坏接入拒绝，不回退官方，不跟随重定向。余额／额度明确标注成员来源，费用与张数仍是官方规则估算，不能承诺网关实际扣费或耗尽后的付费路径。本次复用既有 settings 条目，未引入资料迁移。
- V5 Full 的 High／Medium 作为同一模型的生成档位显式选择，默认沿用 High；四模式共用档位与限制；支持档位的型号将模型和 High／Medium 下拉排在同一行，档位按内容留宽，不支持档位的型号仍使用全宽模型下拉、不预留空位。Medium 的固定步数、采样器和负面预设显示实际值并灰白禁用，不支持的全局／角色负面词及 CFG Rescale 同样禁用；CFG、尺寸、种子及正向词保持可用。固定设置跟随官方运行时，旧缓存按已确认限制回退。切换只改模型档位，保留 High 的参数和负面词草稿，切回即可恢复；费用、真实请求与结果历史使用当前档位的有效值，不能把保留的草稿当作实际生效参数。官方所述默认消耗降低比例不作为固定费用折扣。
- 公共队列设置按 Key 保存，兼容 st-chatu 协调协议与通用 NovelAI 生图中转。填写完整 /ai/generate-image 或 /ai/generate-image-stream 地址交给该服务生图；其他地址作为 st-chatu 队列基础地址，不靠域名猜测。公共任务索引由 Key 指纹与 taskId 共同组成，同 Key 在途重复 ID 明确拒绝，不覆盖 controller；只清理过期终态，不因 TTL 丢弃活动记录。成图先交付，不等待 complete／leave 往返；内部独占保留到公共清理结束，清理失败由任务终态单独提示，不重发生图。中转会接收当前 Key、提示词及参考内容，界面明确提示；个性语仅对 st-chatu 生效，中转不虚构人数。「停止等待」只中断连接，服务端是否取消由中转决定；失败不自动重发或回退官方，官方费用估算不冒充第三方结算。
- 已移除低消耗模式及其设置接口、参数收敛与前后端拦截。四模式、普通／聚焦重绘及模型支持的参考能力直接可用，历史／灵感导入遵循用户选定模式，不因旧开关改道；旧设置原样保留且不读取，不迁移或清理私人数据。
- 生图偏好的免费步数锁仍是独立偏好；局部重绘保持新草稿默认聚焦，可随时手动切换，已有草稿保留明确选择。实际生成遵循用户明确选择的参数与图生图输出尺寸，不额外压低步数、缩小尺寸或暂停参考。
- Vibe 同次最多使用 16 个；手动新编码仍确认费用。已有编码按图片、模型与 Information Extracted 组合永久复用并支持失败恢复；在途付费请求仅在同 Key、同接入地址下合并，避免跨 Key 共用请求与本地记账。参考图每次生成的附加费用提交前可见。
- 常规参数保持免费边界内的探索偏好，未明确要求付费高步数时不擅自放宽。尺寸默认优先贴近官方免费面积的 64 倍数，兼顾竖／横／方构图；现有竖横预设为 832×1216／1216×832，方图为 1024×1024，官方边界变化时一起审计。Scale 提示简写为「宽 × 高 · 免费像素范围内／超出免费像素范围」，去掉「当前输出」及像素总数算式，仅表达像素边界；提示紧挨标题右侧，倍率输入靠右，三者始终同排。空间不足时只在提示内部折行，不按宽度断点将整个提示移到标题下方，也不于滑块下方另设状态栏与分隔线。
- 文生图、图生图、普通／聚焦重绘及扩图共用官方计费依据：按实际请求尺寸、步数、活跃订阅、模型受限状态与参考配置判断免费资格；图生图使用缩放提交副本后的尺寸，聚焦使用裁剪后请求尺寸，扩图使用最终请求画布。
- 生成入口费用提示同源：零 Anlas 且模型不消耗 Opus 时显示「免费」，受限模型显示「消耗 Opus 额度」，付费估算明确 Anlas 单位；模型受限清单继续随官方运行时更新。订阅未知时显示费用确认中／未知且不阻止操作；已有快照后台刷新时继续显示该快照的估算。
- 免费资格、免费张数、模型倍率、最低费用、编码／参考附加费及公式系数由官方运行时同步，前端提示、确认、助手与网关估算同源；不能在局部控件写死价格。模型专属的步数项系数在首次向上取整前生效，不能混为整张费用折扣；模型能力按返回对象归组，变体继承基础模型的额度与能力，不能串入其他 switch 的标签。官方数值变化自动生效，结构未识别或字段损坏时保留最近完整规则并示警；旧快照缺少计费字段或沿用错误参考判定时须重新同步。验证按 `AGENTS.md` 执行，联网自检同时执行官方实际费用调用与基础计价函数；官方共用判定函数在费用、重试等不同调用处的输入不可混同。
- 实验室保持打开时继续订阅运行时更新。Key 激活与启动不等待官方常量同步。手动／Agent、四模式、ZIP／SSE 复用已有订阅快照并后台刷新，不额外联网校验，不附加费用上限拦截或同步异常确认；新 Vibe 编码保留原费用确认，不追加网关二次拦截。成功后只按该请求的生成前快照记账，订阅尚未取得时不猜测本地扣费；ZIP、SSE 与付费编码的记账异常均保留成功产物并单独提示，不能触发自动付费重试。
- 启动没有近期完整规则快照时立即后台同步，不附加固定等待；健康快照先复用，把带宽留给页面。等待同步时共享驱动短间隔读取本地网关状态，完成后恢复分钟轮询，隐藏时暂停；不借此加密账号额度查询或重复抓取官方 bundle。未知／失败状态按真实健康记录展示，不能为缩短转绿时间撤销告警。
- 额度查询与官方规则同步分别反馈：已知额度显示真实百分比和额度颜色，规则同步异常使用独立琥珀点并提示估算可能过期，不把它画成 Key／额度失效；额度查询失败保留红叉及上次快照说明。侧栏折叠／展开、设置与手机资源详情共用该语义。
- 本地预算和个人 Anlas 统计使用估算口径，历史参数不展示为官方实付价格。免费编辑不误扣 Anlas，只有受限模型的成功免费档请求计入 Opus；修正规则不自动回填、返还或改写旧预算与历史。
- 订阅 `active: false` 不据此判 Key 失效；非活跃 Opus 不沿用残留 usage 免费资格，可确认使用保留 Paid Anlas，由官方验证。官方余额不覆盖手动本地预算。
