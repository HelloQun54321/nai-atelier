# 产品决策记录

本文按模块保留影响后续维护的已确认约定与明确拒绝的方案，2026-10-04 从原产品宪法整理。修改相关模块前阅读对应节；长期原则见 [VIBER_INTENT.md](../VIBER_INTENT.md)，维护规则见 [AGENTS.md](../AGENTS.md)。用户新决定直接修订对应条目，历史过程查 CHANGELOG 与 Git，不在这里累计每次修改。

## 1. 共用界面、窗口与分享

- 当前发布重点是 Windows 独立安装版。用户已暂停独立 Android APK，认为其适配复杂度暂不符合个人项目的使用价值；不继续构建或将其作为交付承诺，保留[独立 Android 方案评估](./ANDROID_STANDALONE.md)供未来重新决定。手机仍可使用既有局域网入口；它不等于独立 APK。若未来恢复，需手机本地持久层独立保存资产与凭据，不能以局域网客户端代替。桌面现有数据保护与存储定位规则继续生效。

- 同类按钮保持紧凑、一致的高度、基线和间距；保存用绿色，一般主操作用主题色，危险操作用红色，完成／禁用回归中性灰。抽卡是浏览动作，初次、再次与执行中均使用中性样式。
- 卡片与图片预览的悬浮辅助操作在触屏静止态全部隐藏，包含编辑、收藏、复制／下载、删除、设封面、上传、翻图、灵感选择与板管理；不常驻「更多」入口。长按约 450ms 按电脑端相同位置与顺序原位显露，松手后保留，消耗本次释放点击；点外部、另一个对象或滚动时收起。超过 10px 位移、系统接管手势或离开取消等待，输入／选择器与已显露操作不启动长按。鼠标悬停、键盘可见焦点与 Agent 语义悬停仍可显露，混合设备按实际指针区分，触摸产生的粘滞 hover／普通焦点不能显露。主要生成、返回、保存与异常恢复入口保持直接可达；重要说明与被截断的完整值继续点按查看。
- 外观偏好覆盖按钮、输入、选择器、弹层、详情、启动门禁、错误态与滚动；主题、主色、圆角、密度、字号、材质和动画一致生效。来源／分类、用户自选色、作品像素、画布坐标与触控底线保留含义。
- 资料管理、预设选择、反推、导入与设置使用居中、共用固定外框的小窗口，随视口收缩、内容内部滚动，详情不改变窗口大小；短表单／确认框紧凑，大图与大画板保留完整查看语义。资料默认值须明确保存，与本次参数分开标注；本次参考选择与参数即时生效，简短提示归到完成按钮，不另占说明行，关闭／完成按钮不标为「应用」。
- 筛选弹层默认与触发按钮居中对齐，边缘可避让；模态打开时工作区与侧栏统一遮罩、虚化并停止背景操作。全屏返回按钮与危险操作拉开距离，左右翻图对称、按共用显露规则可达，不被侧栏遮挡。
- 简短操作菜单与只读说明使用共用锚定浮层，点外部、关闭按钮或 Esc 收起；透明命中层拦截背景误触，内容受视口约束并内部滚动，保留主题、安全模式、焦点与文本选区，不撑高原卡片。菜单卸载并归还焦点后再打开详情、编辑或确认窗口。
- 图片管理操作在左上，复制、下载、设封面在右上；小图与全屏保留同组管理能力，全屏左上用返回箭头。安全模式不遮品牌，大图查看明确豁免。
- 列表缩略图由共用组件按可见范围加载，激活后直接开始取图；布局变化不隐藏同地址的已加载图片，失败重试重新启动加载。手机同地址的旧请求清理不能取消新请求；需要代理的远程图在原图回退时仍走代理。
- 图片清洗由全局可选开关决定，默认关闭；分享处只提供「复制／下载」，不新增「分享版／原图」旁路。开启后生成清洗副本，覆盖普通与隐藏参数，失败不能静默输出原图；原始资产与完整信息保留。
- 默认记住最后使用的 Key，尊重记住偏好；预算与官方余额可紧凑展示，但展开／收起均可辨认来源与完整数值，保留未知、旧值和失败说明。排队人数为 0 也显示，未知不冒充 0；生成完成反馈不延迟下一次操作。
- 桌面侧栏保留预算／余额与 Opus；手机实验室四模式在底边中央将 `Anlas 本地预算/官方余额` 与 `Opus额度 百分比` 作为一组紧凑小字显示，两项只留小间距，不分别贴左右角，不使用独立卡片、圆环、钻石或收起说明，用小上箭头、点划线与按压反馈表达可展开。图片查看与生成继续并排独立操作；底部资源面板与设置「NovelAI 与 Anlas」共用完整资源视图，点数按本地预算／官方余额、Opus 按剩余额度／估算张数排成两列，明细和异常归到对应分组，刷新图标明确可操作。资源面板限制阅读宽度，订阅与同步时间的值紧邻标签、不拉向右边缘，相同数值与时间只显示一次；未知用占位、异常用颜色与符号，详细原因放入展开面板。图库／历史等浏览页不增加全站常驻资源条；各入口复用同 Key 的订阅驱动，点按余额刷新按钮或 Opus 行同步刷新。
- 首次使用明确并列 EXE 安装与源码本地部署，任选一种；普通 Windows 使用者优先获得安装包入口，部署工具与命令行步骤只归源码版，两种方式共用应用内词库下载与创作流程。Windows 提供可分发的 x64 安装版，面向 Windows 10／11，安装向导允许选择程序目录，有桌面／开始菜单入口及系统卸载登记，内置窗口、Node 和完整本地后台；使用者不需要 Node、npm、Git 或开发构建。安装版程序与数据分离，工作区位于 `%LOCALAPPDATA%\NAI Atelier\workspace`，不自动接管源码数据，卸载保留个人数据；重复打开回到原窗口，关闭窗口收进托盘，退出工坊才停止后台。源码部署仍在安装依赖后创建指向根目录 BAT 的快捷方式，启动／重启成功时检查修复，不生成桌面脚本副本；历史模板清理只限源码部署，自定义文件保留。构建、验证与分发边界见 [Windows 安装版](./WINDOWS_DESKTOP.md)。
- 源码完整本地启动默认自动重启本项目已运行的服务，会结束原实例未完成任务；启动中合并重复点击，让先启动者继续。构建前即取得单实例占位，不能只等 3000 端口就绪才查重；必须核对项目目录、唯一监听 PID 与入口，身份不明、其他项目或端口未释放时停止本次启动，不按 Node 进程名批量清理。成功结束的多余桌面启动器不保留按键等待。安装版保留其他工坊的进程，冲突时选择新端口，并同步内部代理、词库、启动检查与 Pixiv 回调地址。

- Windows 安装器在解包和旧版本卸载前原生检查系统运行库，缺失时指向微软官方下载页；安装／卸载不依赖 PowerShell 下载执行辅助脚本。分发后台采用独立依赖白名单，前端库不重复安装，只清理无需运行的调试映射、类型声明和多余窗口语言资源，保留原生模块、业务能力与许可证。
- 账户资源详情的常规刷新使用已有刷新图标与圆环的原位动画反馈，不额外增加「正在同步…」文字行，避免手动刷新或后台轮询改变卡片高度。

## 2. 风格串、收集与筛选

- 顶栏按「搜索、筛选 ｜ 智慧姬同步 ｜ 收集模式、批量导入、新建风格串」分组。收集是高频功能，保留直接入口；智慧姬同步仅在设置开启后显示。不额外常驻通用图片反推或手动刷新。
- 收集开关按 Windows 本机监听能力开放，窄窗口收起文字但保留可点击图标；局域网手机不远程启停电脑剪贴板监听，不因响应式补齐而扩展为手机收集功能。
- 模型、排序、收藏、待实测与用户标签集中在统一筛选面板。标签只用于用户自己的分类，不自动附加 NAI／AITag 类型、来源或照搬外部标签；多标签要求同时包含，编辑后选项即时更新，随资料扩展支持滚动／搜索。
- 风格串／自定义角色将编辑、删除、组合详情／复制按原桌面顺序排列在封面右上，收藏沿用原位置，触屏统一长按显露；窄卡片必要时按同一顺序换行，不缩小触控命中。访客只能查看与复制，同步挑选时不显示资料编辑操作，删除继续确认。批量导入候选移除也由长按显露，仅移出本次列表并释放预览，不删除原文件。
- 「待实测」属于风格串，实际生成成功后摘除；收集中／已暂停属于监听器，来源、时间、内部目录标记各自表达，不能混成资产分类。
- 置顶收集窗可拖动、折叠、显示进度，跟随主题和动画，后台更新不抢焦点；折叠仍可辨认状态。已有控制窗时，不在开关旁重复放状态菜单。
- 收集失败给出简短具体原因，长文本可查看完整内容；不增加已拒绝的手动重试或为少量重复建立重复率面板。服务重启后收集保持关闭，不自动恢复剪贴板监听。
- 智慧姬展开操作栏的具体重排仍搁置，不能把未定案示意图当成全产品布局模板。

## 3. 画师／角色目录

- 目录用于浏览、搜索、收藏、排序、抽卡，以及复制或送往实验室；角色库额外维护自定义角色。选中操作区只保留清空、复制、送往实验室，画师权重与角色站位在工作台配置。
- 不加入画师基准测试、预览生成、生成任务队列、复制历史、测试配置或原图／基准图切换，也不将这些已拒绝的功能收进更多菜单。数万 Tag 不逐一生成模型预览，换代不要求重做目录；已有图片与自定义资料保留。
- 封面使用全部评级的公开精确候选，不加 SFW 检索限制；代表图偏好只影响优先级，初次展示实际使用代表图。角色插画优先于照片、拼贴与梗图，不能以最高评分代替辨认适合度。
- 真正无图与连接、限流、图片加载失败分别反馈；缺少公开地址不伪造候选，查询有界、错误可恢复。

## 4. 外部图库、灵感与图片反推

- 灵感板按板名、编辑、删除排列，桌面侧栏与手机筛选面板复用同一列表行；点按板名选择，触屏长按显露右侧编辑／删除，手机列表内部滚动。编辑后回到原筛选；删除仍需确认，板内灵感回到未整理，不删除灵感原件。灵感卡片选择入口遵循共用长按规则，已勾选标记保留明确状态。

- Danbooru 网站验证、403 拒绝、429 限流与临时连接失败分别反馈，原始状态、错误码和等待时间贯穿网关／Worker／封面批次；验证与拒绝不伪装成限流。临时网络故障最多尝试三次，仍经过共同联网预算，离开页面立即取消；封面组件不叠加后台已完成的重试，等待中的排队项及时报错而不静默转圈。保留应用身份和证书验证，沿用不轮换端点或身份绕过上游限制的边界。
- Pixiv／Danbooru 详情直接提供「图片反推」，Pixiv 绑定当前页，不把单个功能藏进更多菜单；通用反推不常驻资料列表顶栏。灵感在标签区识别，AITag／历史已有原始提示词时优先使用，缺失才给识别入口。
- 原站标签与模型反推 Tag 分区、分别复制，取用时明确来源并追加到实验室；Pixiv 原站标签主要用于检索，不直接当作生图提示词。Danbooru 原站角色／普通 Tag 可直接使用，不强制重复识别；WD 预测不能冒充原始 Prompt 或画师身份。
- 反推结果可选择、编辑，关闭／跳转保留会话草稿；长期保存通过「加入／更新灵感库」明确完成，保存原图、原站标注、模型结果与所选提示词，Pixiv 多页按页隔离。
- Danbooru／Pixiv 原帖入口在固定标题栏关闭钮左侧；图下反推与本地灵感保存紧凑同行，不强制半栏宽或为单个来源另起一排。Pixiv 作者名进入全集，站内收藏在操作行右侧以心形表示，区别于本地保存；窄栏收次要文字、保留名称提示。
- 本地反推模型在设置集中管理，下载与「使用」分开，默认保留轻量模型；较大模型显示大小与等待代价，进度、校验、失败可见，暂停后手动续传。缓存及选择跨页面／服务重启一致，图片入口不重复放模型管理控件。
- AITag 列表封面优先使用已缓存的本地首图，包括详情刚完成的本地缓存；新地址就绪后重新选择，无关的收藏／比例更新保留当前候选。候选耗尽显示失败、重试与原页入口，不能静默停在灰块。

## 5. 历史浏览

- 顶栏按「时间、只看收藏、更多筛选 ｜ 排序、随机浏览」排列；模型、生成方式、来源与可选关键词收在更多筛选，不常驻通用搜索框。始终单行，不平均拉宽填满；剩余空间不足时将时间收回筛选并压缩图标。
- 随机与重新洗牌共用位置，新图提醒不增加一行，多选操作替换固定顶栏。生成时间、收藏时间与随机发现分别表达；随机覆盖当前筛选全部结果，同次洗牌跨页、翻图及返回保持稳定。
- 后台新图不打断旧图浏览，取消收藏／删除当前图后继续邻图；返回恢复列表位置和卡片。列表按真实比例完整呈现，大图、下载与编辑使用原图。
- 历史卡片长按统一显露原位操作，不再进入多选；批量选择从「管理 → 批量选择图片」进入，多选期间单图辅助操作隐藏。
- 大图参数可收起，缩放拖动与滑动翻图避免误触；输入、前景窗口与确认不被快捷键抢占。历史收藏与灵感长期整理保持不同语义。
- 大图详情先显示操作，再显示提示词与参数；翻图回到详情顶部。「导入到实验室」统一提示词恢复与底图编辑入口，默认明确进入文生图，可选择图生图／局部重绘／扩图，低消耗只显示文生图与局部重绘。有匹配操作的历史蒙版时可主动选择复用，默认清空旧蒙版；「加入灵感库」短表单直接显示，不折叠。

## 6. 统一创作工作台与编辑模式

- 风格串／自定义角色与自由实验室共用工作台、模式导航、公共工具与参数／预览；新打开预设从文生图开始，后续按条目恢复会话模式，独立于自由实验室。四模式各自保存 Prompt、负面、模型与编辑参数，隐藏不清底图／蒙版。
- 自由实验室刷新或重新打开时恢复文字、参数及模式，四模式的结果预览先留空，编辑模式的底图、蒙版、选区、扩图范围与旧来源关联一起清空；历史不自动选中或充当占位。同次打开内切模式保留各自底图和新结果，编辑生成／翻图／重置不覆盖文生图预览；「文生图最新」仍由用户主动取用。风格串／自定义角色工作台保持既有历史与编辑资产恢复，历史原图不受影响。
- 预设顶栏的身份／模式区只保留返回与模式导航；名称在卡片展示，信息编辑在卡片铅笔入口，手机长按卡片后可点，仅更新名称、描述、标签。工作台使用最新信息并保留草稿；保存菜单区分「保存修改／另存为新串」，自由实验室为「保存到库」。
- 工作台顶栏始终单行，按实际可用宽度与字号收纳，不只判断浏览器宽度；Agent 挤窄工作区时，公共工具进入「更多操作」，桌面使用按钮锚定菜单，手机使用底部面板。预设保存仍直接可达，自由实验室的「保存到库」随工具收纳，拉宽后恢复整排动作。
- 预设文生图重置恢复已保存内容；编辑模式重置只清当前模式底图／蒙版并保留当前风格，不删除落库资产。仅完整保存模式资产时提供入库，不制造半套配置。
- 左侧负责「底图与导入」，右侧以作品预览为中心；图生图不显示蒙版画笔，局部重绘保留准确蒙版、选区与回贴，默认开启「聚焦重绘」：新建、重置与没有重绘模式信息的图片导入沿用该默认值，已有草稿／历史明确保存的普通重绘选择继续恢复；界面名称、提示与画布操作统一用中文，普通模式仍可手动切换，实际费用按当前账号与参考配置判断。扩图默认重绘新增区域及沿扩展侧向内 32 像素接缝，手动蒙版显式开启，不套用聚焦重绘语义。
- 编辑模式保留、展示并发送结构化角色，单角色和空全局文本仍有意义；定位随真实扩图、裁剪及尺寸规范化转换，局部坐标不能污染整图历史。默认自动构图，手动配置显式保留；角色可排序、停用但不删除内容。
- 定位区默认收起，按当前画布／底图比例展示；V4／V4.5 使用 5×5 格点，V5 自由定位，能力跟随官方。请求只含启用且有正向词的角色，正负配对、顺序一致，上限按有效角色计；停用项留在草稿／预设，历史记实际角色，目录不配置站位。
- 整图识别与 Tag 辅助在工作台顶栏各保留一个入口；结构化角色提供就地「粘贴反推」，直接追加、不强制筛选、不自动区分动作或限制单人。参考小图可放大／移除，只作编辑对照，不自动成为 Vibe、角色参考或底图；读取生成信息与引用预设为不同操作。
- 空结果统一显示「暂无生成结果」，底图来源、快捷键与坐标帮助使用简短就地提示，不另占教程行。图生图／重绘／扩图统一「上传图片／文生图最新／粘贴」；从浏览处复制原图后就地粘贴，不重开历史或灵感选择器。图生图上传、拖入、粘贴或取用文生图最新只替换底图，保留当前全局正负词、角色正负词、位置与参数；空提示词切走再回来也不自动回填或选底图。完整配置通过顶栏「导入图片或 JSON 配置」、引用预设或历史详情「导入到实验室」主动读取。局部重绘／扩图继续随项目内图片带入完整配置，包括空全局文本、角色正负词、位置与参数；普通无信息图保留当前配置。
- 剪贴板重编码时可在当前标签页关联最后一次主动复制的配置，须核对实际像素；不建复制历史、不附加私有分享信息、不持续监听、不劫持文字粘贴。换图清旧蒙版、选区、扩图范围与结果，保留原历史／灵感资产和旧草稿来源兼容。
- Tag 辅助、反推、元数据及预设导入作用于当前模式；安全模式、手机、主题、Key、费用与异常恢复覆盖全部模式和入口。
- 快速导入、预设来源、步数收费边界与强制随机的原种子均可点按查看；参数详情的完整值、Tag 权重帮助／完整中英文对照与翻译失败原因使用共用说明浮层。说明操作不切换导入开关、不改变参数或取消已选 Tag，不发起模型翻译。

## 7. 低消耗策略与官方费用依据

- 低消耗在全局设置显式开启：V5 最多 23 步，V4／V4.5 最多 28 步，保留更低步数；约束实际生成请求，关闭后恢复原草稿／预设，不自动改模型或 Strength。
- 仅展示文生图与免费的聚焦重绘；隐藏图生图、扩图、角色／精确参考、付费放大与普通重绘切换，但保留配置。关闭后恢复完整能力，图生图／扩图不另设低消耗费用上限，预算不重置、不划分付费编辑额度。
- 已有 Vibe 编码同次最多使用 4 个；手动新编码仍确认费用。编码按图片、模型与 Information Extracted 组合去重、并发合并、失败恢复，永久复用；参考图每次生成的附加费用提交前可见。
- 常规参数保持免费边界内的探索偏好，未明确要求付费高步数时不擅自放宽。尺寸默认优先贴近官方免费面积的 64 倍数，兼顾竖／横／方构图；现有竖横预设为 832×1216／1216×832，方图为 1024×1024，官方边界变化时一起审计。
- 上述步数是用户低消耗策略，免费门槛、编码／参考费用及公式系数以官方运行时同步为准；不能将某个默认系数当永久事实或在局部控件硬改。同步保护与验证按 `AGENTS.md` 执行。
- 订阅 `active: false` 不据此判 Key 失效；非活跃 Opus 不沿用残留 usage 免费资格，普通模式可确认使用保留 Paid Anlas，由官方验证。低消耗坚持零 Anlas，须关闭后再确认付费；官方余额不覆盖手动本地预算。

## 8. 内置 Agent 界面与业务形态

运行行为、中文与生图 Prompt 策略直接维护在 [PROJECT_AGENT.md](../PROJECT_AGENT.md)；页面／文件工程契约见 [能力覆盖](./AGENT_WORKSPACE_CAPABILITIES.md)，这里仅保留产品形态与交互决定。

- 读取当前页面及前景范围，聊天简短显示读取到的页面，用量直接可见；不常驻旧草稿横幅与撤销按钮。权限在输入区，过程展开在聊天菜单，API 下方集中生图协作偏好。
- 上下文圆环保留鼠标悬停与键盘聚焦读取，点按可固定／收起，点击外部、失焦或 Esc 关闭；手指离开不触发鼠标式收起，触屏扩大命中区域，数值与未知状态沿用原语义。
- 思考强度滑块的圆钮使用对应明暗主题的不透明底色，透光面板不能让填充轨道透过圆钮；最高可用档保留紫色与粒子效果，标题、触发器和无障碍文本均显示真实强度，不能将不同模型的最高档统一改名为 Ultra。点击、拖动与键盘调节共用释放吸附规则；保存时保持滑条可操作与焦点，只允许一个设置请求在途，后续快速调节保留最后档位，旧响应不能回拉当前预览。较慢保存才显示加载图标，保存期间暂缓发送，失败恢复最后成功档位并显示原因。
- 保持固定业务系统提示词、实时项目状态与原始对话调用工具；不提供额外注入、注入模式、预设管理或酒馆 Agent 预设适配。旧注入字段不生效，不为移除功能清理私人文件。
- 不提供任务转向、后续追加或排队控件；执行时可保留下一条输入，结束／停止后由用户发送。展开思考／工具过程跟随最新输出，主动上翻暂停跟随，返回末尾或重新展开后恢复。

## 9. 智慧姬同步与外部资产

- 默认关闭，用户在设置开启后才显示入口并同步；关闭保留资料、待同步任务与接收记录。工坊精选发送主动勾选的 V4.5／V5 风格串及封面，酒馆风格串全部接收；Vibe 与组合继续互通。
