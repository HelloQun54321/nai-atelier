# 🎨 NaiPromptManager — 个人本地改造版

> 基于 [kirafishy/NaiPromptManager](https://github.com/kirafishy/NaiPromptManager) 深度改造的 NovelAI 个人工作台。

本项目最初来源于 `kirafishy/NaiPromptManager`，现在已经作为独立项目维护：Git 历史以本项目的 `main` 为准，不再与原仓库保持远程关联。项目保留原作者来源说明，并继续遵循与原项目相同的 [MIT License](./LICENSE)。

当前版本不再定位为可公开部署的多用户网站，而是一套运行在个人电脑上的 NovelAI 提示词、画师、角色与生成图片管理工具。电脑保存全部重要数据，同时可以作为家庭局域网服务器供手机访问。

## 这个版本重点改了什么

| 方向 | 原项目思路 | 当前个人版本 |
| --- | --- | --- |
| 使用方式 | 账号、游客、角色和权限体系 | 启动后直接进入，完全个人使用 |
| 数据位置 | 面向 Cloudflare D1 / R2 部署 | D1 / R2 兼容运行时保留，但数据统一落在本机 `local-data` |
| 生成历史 | 依赖浏览器 IndexedDB | 历史记录、参数和原图迁移到电脑本地存储 |
| 手机访问 | 以桌面网页为主 | 家庭局域网访问、四位密码、独立手机 UI |
| 手机图片 | 手机直接加载完整图片 | 电脑生成 320/640 WebP 小图，详情才读取原图 |
| NovelAI 网络 | 浏览器直接请求 | 手机请求由电脑转发，可使用电脑的系统 VPN |
| Tag 数据 | 原有资源入口和有限数据 | 31 万余条中英 Tag、本地分片、在线更新、中文搜索 |
| 画师资源 | 第三方静态画师数据 | 约 14.6 万画师 Tag，自维护目录、热度、抽卡、按需预览 |
| 角色资源 | 简单角色串 | 约 9.9 万角色 Tag + 手工外貌还原角色的混合角色库 |
| AITag | 没有完整的本地资料工作流 | 远程作品检索、本地缓存、离线浏览和参数复用中心 |
| 页面交互 | 以桌面端和浏览器原生交互为主 | 手机独立布局、项目内确认面板、安全模式和精细化图片浏览 |

## 主要改造内容

### 1. 完全个人化

- 删除登录页、账号注册、游客模式、用户角色、权限判断和退出流程。
- 所有画师串、角色、灵感和生成历史都视为本机所有者的数据。
- 移除不再需要的访问日志与后台日志页面，减少与个人工作流无关的系统功能。
- 旧数据中的用户 ID 仅作为兼容字段保留，不再承担账号功能。

### 2. 重要数据不再依赖浏览器

- 生成历史由浏览器 IndexedDB 迁移到本机 D1 + R2 兼容存储。
- 历史图片、Prompt、负面 Prompt、Seed、尺寸和生成参数一同保存。
- 首次升级时会先完整复制旧历史，全部保存成功后才清理浏览器副本。
- 清空浏览器缓存不会删除电脑中的画师串、角色、灵感或历史原图。
- 重要数据集中在 `local-data`；可再生成的小图缓存单独放在 `local-cache`。

### 3. 电脑作为家庭局域网图片服务器

- 桌面启动器一次启动本地 Worker、图片网关和 Tag 更新服务。
- 电脑通过 `http://localhost:3000` 免密访问。
- 同一家庭网络中的手机通过电脑局域网 IP 访问，首次输入持久化四位密码。
- 连续输错五次会暂时锁定；授权设备默认保持 30 天。
- 手机列表只请求 320px 或 640px WebP 缩略图，打开详情、下载和读取元数据时才使用原图。
- 电脑缩略图缓存上限 1 GB；手机小图缓存默认上限 100 MB，均可自动淘汰并随时重建。
- 手机生图请求经电脑网关转发到 NovelAI，可使用电脑当前的系统 VPN；手机不需要重复开启 VPN。
- 不提供公网访问能力，也不建议配置路由器端口转发。

### 4. 手机端重新设计

手机端不是简单压缩桌面布局，而是单独设计的触控界面：

- 底部导航、资源库二级入口、全屏详情和底部抽屉适配手机安全区。
- 图片列表支持瀑布流、竖向卡片、方形，以及自动或 1/2/3 列显示。
- 画师串、角色库、画师 Tag、历史、灵感和 AITag 分别采用适合内容的密度。
- 打开详情后使用页面内全屏视图，返回时恢复原来的搜索条件和滚动位置。
- 历史页提供日期筛选、分页、管理、批量删除和单图重试。
- Android 返回键优先关闭抽屉、详情和设置层，不会直接退出当前业务页面。
- 所有主要触控区域按至少 44px 设计，并处理软键盘遮挡和底部手势区域。

### 5. Tag 补全与本地中文词库

- 收录 31 万余条 Danbooru 中英对照 Tag，并合并 NovelAI V4.5 专属 Tag。
- 输入英文或中文都可以查找，候选显示英文原名和中文解释，插入时使用 NovelAI 可识别的英文 Tag。
- 词库按前缀拆分为本地分片，不需要一次加载完整数据库。
- 补全菜单支持鼠标滚轮、触摸滑动、键盘上下选择，以及手机端双击确认，减少滑动误触。
- 全局设置中可查看词库版本、来源和数量，并直接检查更新。
- 更新失败会自动重试并在 GitHub Raw / jsDelivr 之间切换，失败时保留当前可用词库。

### 6. 画师 Tag 页面

- 不再依赖长期未维护的 `twoearcat/nai-artists` 静态图片数据。
- 使用本地中英 Tag 快照维护约 14.6 万画师目录。
- 支持中文名、英文 Tag 搜索，以及热度、名称正序和名称倒序。
- 热度使用 Danbooru 关联作品数量，而不是手工划分“热门/冷门”。
- 目录按 500 条滚动加载，不会一次渲染全部画师。
- 缺少预览时，可使用 NovelAI V4.5 按统一测试 Prompt 生成并保存本地预览。
- 支持收藏、权重组合、批量选择和随机抽卡。
- 抽卡支持 6/12/24 位、完全随机、热门画师和惊喜混合，并避开最近五批重复结果。

### 7. 角色库

- 将原来的角色串页面升级为“角色 Tag + 自定义还原角色”混合角色库。
- 收录约 9.9 万角色 Tag，支持中文名、英文 Tag、作品名、括号变体和多关键词搜索。
- 支持“原神 胡桃”“碧蓝档案 泳装”一类组合查询，并按相关性排序。
- NovelAI 已收录的角色可以直接复制官方 Tag。
- 没有官方 Tag 的角色可以保存手工组合的外貌、服装和特征 Prompt，例如自定义“穆宁雪”。
- 支持收藏、随机抽卡、生成本地预览、导入实验室和跳转 Danbooru。

### 8. 生图实验室与预设引用

- 实验室保留基础画风、模块、主体/变量、多角色、负面 Prompt、参数和预览结构。
- 手机端按“全局、角色、参数”组织内容，生成按钮避开软键盘。
- 引用按钮提升为编辑器全局操作，可以引用画风、人物、模块、角色和参数。
- 每个板块分别记录自己的预设来源，不会把人物预设错误显示在基础画风旁。
- 追加多个预设时可以同时显示多个来源；手动修改后标记为“已修改”。
- 支持从 NovelAI PNG / JSON 元数据导入 Prompt 和参数。
- 生成结果自动写入本地历史，可下载原图、设为封面、发布到灵感或再次导入实验室。

### 9. 安全模式

- 开启后，项目中的内容图片默认添加模糊与压暗效果。
- 点击图片可临时显示；鼠标离开对应图片区域后立即重新模糊。
- 切换页面、窗口失焦、页面隐藏或按下 `Esc` 时会重新隐藏已显示的图片。
- 调色盘 Logo 等品牌资源明确排除在安全模式之外。
- 手机端安全模式入口放在全局设置，避免长期占用导航空间。

### 10. AITag 作品与参数资料库

AITag 不是普通图片列表，而是连接 [aitag.win](https://aitag.win/) 的独立 AI 作品检索、缓存和参数复用系统：

- 从 aitag.win 读取带 Pixiv 作品信息与 AI 生成元数据的作品目录，每页 60 条。
- 支持按作品 ID、作者 ID、标题、Tag、日期和模型搜索，并提供单独的 Prompt 元数据全文搜索。
- 支持筛选 NAI、Stable Diffusion 和 ComfyUI 作品。
- 支持“最新”与“月榜”两种目录，并可选择当前月份、历史月份或更早作品。
- 作品卡片显示 AI 类型、图片数量、浏览量、收藏量和本地缓存级别。
- 缓存状态使用不同卡片色区分：未缓存、已缓存首图、已缓存完整详情与全部图片。
- 本地索引默认可渐进抓取 500 页，每批少量同步，避免一次请求占满网络或阻塞页面。
- 可按“收藏、已缓存首图、已缓存全部”过滤；收藏状态和缓存索引保存在本机。
- aitag.win 暂时不可用时自动回退到本地缓存，已缓存的作品、详情和图片仍然可以浏览。
- 打开作品后按页展示全部图片，并从元数据识别模型及文生图、图生图、局部重绘、Vibe Transfer、角色参考等生成方式。
- 对 NovelAI 图片会解析正面 Prompt、负面 Prompt、尺寸、Seed、Steps、采样器和其他可识别参数。
- 每张图片均可执行三条复用路径：
  - **导入实验室**：把解析出的 Prompt 和参数直接带入生图实验室。
  - **保存到画师串**：把图片、Prompt、负面 Prompt 和参数保存成可继续编辑的画师串。
  - **收藏到灵感**：把图片及完整生成配置保存进本地灵感库。
- 保留 aitag.win 与 Pixiv 原作品入口，方便回到数据来源核对作品。
- 桌面端使用作品列表 + 详情双栏；手机端只显示作品列表，点击后进入全屏详情，返回时恢复页码、筛选条件、选中项和滚动位置。
- 列表继续通过电脑图片网关读取缩略图，详情才加载需要查看的完整图片，避免手机直接下载全部远程大图。

### 11. 历史与灵感

- 历史页面支持即时刷新、日期范围筛选、分页、跳页、批量管理和本地原图查看。
- 灵感库保留为独立页面，可保存标题、Prompt、负面 Prompt、参数和图片，并重新导入实验室。
- 历史图片可以发布到灵感，AITag 图片也可以直接收藏到灵感，形成统一的个人参考资料库。
- 所有列表统一使用按需缩略图、失败重试和离屏请求取消，减少手机流量和内存占用。

### 12. 统一的项目交互

- 删除、清空、重置、放弃未保存修改等操作统一使用项目内确认面板，不再调用浏览器原生弹窗。
- 手机端确认面板从底部弹出，桌面端使用居中弹窗。
- 主题切换、NovelAI API Key、Tag 词库、安全模式、图片显示和手机缓存集中到全局设置。
- 应用、浏览器标签和桌面快捷方式统一使用 Microsoft Fluent Emoji 调色盘图标。

## 当前页面

| 页面 | 用途 |
| --- | --- |
| 画师串 | 保存和组合常用画风、模块、参数与封面 |
| 角色库 | 浏览官方角色 Tag，或维护自己的角色外貌还原 Prompt |
| 画师 Tag | 搜索、收藏、排序、抽卡并生成画师基准图 |
| AITag | 检索 aitag.win/Pixiv AI 作品，本地缓存元数据和图片，并导入实验室、画师串或灵感 |
| 灵感 | 保存值得复用的图片、Prompt 和参数 |
| 实验室 | 组合提示词、引用预设、调用 NovelAI 并预览结果 |
| 历史 | 管理电脑本地保存的生成原图与生成参数 |

## 快速启动

### 日常使用

Windows 桌面双击 `NaiPromptManager` 调色盘快捷方式即可。启动器会：

1. 检查项目和当前 Git 分支。
2. 仅在源码有变化时重新构建。
3. 启动本地服务。
4. 自动打开 `http://localhost:3000`。
5. 已有实例运行时直接打开页面，不会重复启动服务。

### 命令行启动

```bash
npm install
npm run dev:local
```

开发时需要监听源码变化：

```bash
npm run dev:local:watch
```

完整工程检查：

```bash
npm run build
git diff --check
```

## 手机访问

启动窗口会显示局域网地址，例如：

```text
http://192.168.0.105:3000
```

手机与电脑连接同一家庭网络后，在手机浏览器打开该地址并输入窗口显示的四位密码。密码和会话密钥保存在 `local-data/lan-access.json`，不会提交到 Git。

如果电脑使用 VPN，请确保它是系统代理或系统 VPN。仅安装在浏览器里的代理扩展通常无法被 Node 本地服务使用。

## 数据、缓存与备份

| 路径 | 内容 | 是否重要 |
| --- | --- | --- |
| `local-data` | D1 数据、R2 原图、历史、局域网密码 | 重要，应该备份 |
| `local-cache/thumbnails` | 电脑按需生成的 WebP 小图 | 可删除，不必备份 |
| 浏览器缓存 | 手机小图和少量界面偏好 | 可删除，不是数据主副本 |
| `public/tag-data` | 可重新生成的 Tag 快照 | 已纳入项目版本管理 |

备份时优先完整复制 `local-data`。不要把 `local-cache` 当作图片原始数据，也不要只备份浏览器目录。

## 更新 Tag 词库

日常可以在“全局设置 → Tag 补全词库”中点击更新，也可以运行：

```bash
npm run update:tags
```

脚本从 [ffdkj-Danbooru_Tag-Chinese-English-Translation-Table](https://github.com/ffdkj/ffdkj-Danbooru_Tag-Chinese-English-Translation-Table) 获取中英数据库，并结合 NovelAI 官方 Tag 生成本地分片。

## 技术架构

- 前端：React 19、TypeScript、Tailwind CSS、Vite
- 本地后端：Cloudflare Workers / Wrangler 本地运行时
- 数据库：本地 D1（SQLite）
- 原图存储：本地 R2 兼容对象存储
- 图片网关：Node.js + Sharp
- 压缩与传输：按需生成 WebP 缩略图
- 局域网认证：四位密码、签名 Cookie、失败次数限制
- 生成请求：浏览器 → 本地网关 → NovelAI API

## 重要说明

- 当前版本是个人本地工具，不建议作为公开网站部署。
- 不要将 `local-data`、NovelAI API Key 或局域网密钥提交到公开仓库。
- 项目不会自动把重要数据同步到 GitHub；Git 仓库保存的是代码和可公开的静态资源，不是生成历史备份。
- 完整修改记录见 [CHANGELOG.md](./CHANGELOG.md)。
