# 智慧姬同步扩展 (npm-bridge)

本扩展连接 **SillyTavern**（配合 `st-chatu8`）与 **NAI Atelier**：工坊精选发送，酒馆全部接收，已有内容增量复用。

---

## 核心功能

1. **精选风格串与配图互通**：
   - Atelier 仅发送主动勾选的 V4.5／V5 Full／Curated 风格串；V4 与其他模型不发送，酒馆的风格串仍全部进入 Atelier；
   - Atelier「智慧姬同步」分为「挑选风格串」「待同步」「同步记录」，筛选勾选后「加入待同步」；手机入口在筛选面板，任务与记录重启保留，移出队列不删除原件；
   - 自动同步画师卡片封面配图（采用 SHA-256 内容哈希去重，杜绝重复写入，自动清理旧文件）；
   - 保存后回读酒馆服务，核对正文与封面才确认接收；成功项移到记录、不重复导入。失败项显示原因、等待手动重试，部分副本不覆盖工坊待发送原件；
   - 对方删除后标记「智慧姬中已移除」，不自动补回；显式重新加入才能再发。只有有效、完整且当前会话的快照可确认移除，旧页面、未保存设置和连接失败保留上次核对；
   - 在 st-chatu8 的预设选择弹窗中注入“有配图”筛选浮层。
2. **Vibe 风格与组合同步**：
   - 双向同步 NovelAI Vibe Transfer 数据文件及强度设置；
   - 自动同步 Vibe 预设组合，内容未变时保留原条目。
3. **生图历史无缝接入**：
   - 将 st-chatu8 生成的原图自动接入 NAI Atelier 的生成历史库，无需复制图片文件，零占用额外磁盘。

## 安装方法

### 方式一：直接复制目录
将本目录（`npm-bridge/`）完整复制到你的 SillyTavern 扩展目录下：
```
SillyTavern/public/scripts/extensions/third-party/npm-bridge/
```
目录结构如下：
```
SillyTavern/
└── public/
    └── scripts/
        └── extensions/
            └── third-party/
                └── npm-bridge/
                    ├── manifest.json
                    ├── index.js
                    ├── style.css
                    └── README.md
```

### 方式二：从 NAI Atelier 一键安装或导出
在 NAI Atelier 的「全局设置」→「数据与维护」→「智慧姬同步」中，先开启开关（默认关闭、重启保留）：
* 填写酒馆安装根目录后点击 **“一键安装 / 更新扩展”**，系统将自动写入到上述目录；
* 或者点击 **“选择目录导出”** / **“下载 ZIP 扩展包”** 手动导出到对应目录。

## 使用与配置

1. 安装完成后，**刷新或重新打开 SillyTavern 网页**。
2. 点击右上角扩展按钮（积木图标），进入扩展设置面板，找到 **`智慧姬同步`**：
   - **折叠标题**：默认只占一行，显示简短状态；点击展开配置，记住开合选择，状态更新不会自动展开；
   - **服务地址 (Base URL)**：填入你的 NAI Atelier 访问地址（默认：`http://localhost:3000`）。若部署在自定义端口或局域网，直接在此修改保存即可；
   - **Atelier 总开关**：在「全局设置 → 数据与维护」开启「智慧姬同步」后，才会收发风格串、Vibe 与历史索引；关闭不删除已有条目或已选范围。连接器先检查开关再读取待发送资料。
   - **自动同步**：勾选后，将在启动、窗口获得焦点以及风格串修改后自动同步；关闭后这些触发均停止；
   - **立即同步**：接收 Atelier 待同步任务并反馈逐条确认，也可手动重试已失败项；统计显示导入、更新、接收确认及待确认数量，一行结果可悬停查看完整原因。

已经全量同步到酒馆的条目不会因更新或移出队列而自动删除，可在酒馆侧手动整理。待发送任务以本次工坊选择为准，其余已关联资料仍以酒馆内容为准；旧风格串未记录模型时沿用工坊原有 V4.5 默认语义。旧版范围先进入待同步，实际接收后进入记录。请同时重启 Atelier 本机服务、更新本目录连接器并刷新酒馆页面；连接器版本与缓存参数由项目版本脚本统一生成。

## 常见问题与注意事项

* **依赖说明**：本扩展需要 SillyTavern 已安装并启用 `st-chatu8` 扩展。
* **生图历史读取路径**：NAI Atelier 服务端会自动在探测到的 SillyTavern 路径、`D:\SillyTavern`、`../SillyTavern` 以及环境变量 `SILLY_TAVERN_ROOT` 指定的位置寻找 SillyTavern 的数据文件。如果你的 SillyTavern 安装在非标准目录，请设置环境变量 `SILLY_TAVERN_ROOT` 指向该目录。
