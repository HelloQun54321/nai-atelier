# 智慧姬同步扩展 (npm-bridge)

连接 **SillyTavern**（需已安装并启用 `st-chatu8`）与 **NAI Atelier** 的配套浏览器扩展：

- **精选风格串与配图互通**：接收工坊「待同步」队列中勾选的 V4.5／V5 风格串与封面（SHA-256 去重），并将酒馆中的风格串同步回工坊；还在 st-chatu8 预设弹窗中注入了实用的「有配图」筛选开关。
- **Vibe 与组合双向同步**：双向同步永久 Vibe 编码、强度及预设组合。
- **生图历史零拷贝接入**：工坊自动索引酒馆原图路径（如未安装在常见路径，可通过环境变量 `SILLY_TAVERN_ROOT` 指定酒馆根目录），无需复制图片文件。

## 安装方式

- **工坊内一键安装（推荐）**：在 NAI Atelier「全局设置 → 数据与维护 → 智慧姬同步」开启开关，确认酒馆根目录后点击 **「一键安装 / 更新扩展」**。
- **手动安装**：将本目录完整放入 `SillyTavern/public/scripts/extensions/third-party/npm-bridge/`（确保其下直接包含 `manifest.json`、`index.js`、`style.css`）。

## 使用说明

1. 安装或更新扩展后，**刷新 SillyTavern 网页**。
2. 打开酒馆右上角「扩展（积木图标）」面板，展开 **`智慧姬同步`**：
   - **服务地址 (Base URL)**：默认 `http://localhost:3000`，若工坊使用其他端口或局域网地址请对应修改并保存；
   - **自动同步**：开启后在页面加载、窗口切回前台及预设变更时自动同步；
   - **立即同步**：手动拉取工坊待同步任务并回报落盘结果。
